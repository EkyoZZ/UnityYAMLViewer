# Unity YAML Viewer v1.1.7

本次更新改善音视频播放与 FFmpeg 安装体验，并加入系统代理更新、最近记录设置及独立系统弹窗，保留已有 Unity YAML 查看、编辑、Spine 和模型预览功能。

## 新增与改进

- 视频支持全屏播放：点击进度条右侧全屏图标或按 F11 进入，F11 / Esc 退出。
- 全屏采用纯黑背景，上方悬浮显示缩放模式与比例，下方显示播放控件与进度条；鼠标静止 1 秒后自动隐藏，移动后恢复。浮层黑底为约 50% 不透明度。
- 视频提供适应窗口、原尺寸和自由缩放三种模式；自由缩放支持滚轮缩放、拖动画面，以及轻点播放 / 暂停。移动达到 5 个逻辑像素才判定为拖动。
- 音频、视频与全屏均支持空格键播放 / 暂停，输入文字时不会接管空格。
- 音频电平条增加白色峰值拖尾：上升即时跟随，下降以每秒 5 dB 缓慢回落。
- 改善视频像素对齐，减少居中位置造成的额外插值模糊。

## 设置、联网与弹窗改进

- 最近打开记录数量可设为 10～50 条，默认 30，支持数值输入、滑块和清空；立即保存，降低上限会淘汰最早记录，提高上限不恢复已删除历史。
- Windows 系统手动代理支持覆盖更新检查、附件下载和说明图片；未支持 PAC / 自动代理发现。
- 自动及手动检查结果显示在设置底部；未检查不显示，最新版本不显示链接，失败提供手动更新链接。有新版本时手动检查与 New 共用软件更新窗口，自动检查不主动弹窗。
- 设置、关于、更新、加载、编辑确认 / 提示及颜色 / 渐变面板使用独立系统窗口；保留确认保护，内容溢出时滚动。统一多语言设置边距，关于 / 更新窗口按内容高度收缩。
- 关于窗口补齐七语言历史摘要，默认只展示当前 1.1.7 与上一版 1.1.6，其余折叠；维护要求写入 AGENTS.md。
- 解码器就绪状态明确显示“FFmpeg 已安装”，七语言同步。

## 修复

- 改善 FFmpeg 安装后的即时识别，重新检测读取最新 PATH 并查找 WinGet 实际安装目录。
- FFmpeg 安装 / 检测成功后，关闭设置会自动刷新当前显示错误的音视频页，无需再点重试。

## 使用说明与已知限制

- 音视频播放需要外部 FFmpeg 与 ffprobe，可在设置中的视频解码区域安装。安装需要联网。
- 音频电平为源音频近似峰值；字幕渲染、HDR 输出及精确声卡时钟同步暂未支持。非整数缩放仍有插值。
- 用户已通过临时测试版验证系统代理更新及本轮交互改进，未完成全部功能的全面回归。合并后的 1.1.7 Release 已构建，尚未重新上传发布。
- 详细支持范围和验证状态见 [1.1.7 功能记录](../versions/1.1.7.md)。
