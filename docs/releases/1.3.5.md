# v1.3.5

状态：最新发布候选已完成构建，尚未正式发布。

## 更新内容

- 新增电视／电台播放列表：按分组展示台标卡片，支持同频道多源切换、台标本地缓存，并记住上次观看的频道与来源。
- 播放列表支持网络频道、上一项和另存为；读取频道名称、分组和台标参数，保存时保留频道信息及所有来源，补充 RTP／RTSP 和 IPv6 地址支持。
- 播放底部显示媒体接收速率，便于比较来源；电视台模式下左右键切频道，Ctrl+左右键循环切源，上下键继续调音量。
- 修复切台读取或播放报错时列表消失的问题；频道按固定大小动态排列，分组默认折叠。
- 画面支持原始、16:9 和 4:3 比例，可与适应窗口、原尺寸及自由缩放组合使用。
- 改进 YouTube 提取运行时发现及登录验证错误提示；油猴助手的“没有打开？”说明默认折叠，可展开查看下载和重试入口。

## 使用限制

- 网络播放依赖 FFmpeg，网页提取依赖 yt-dlp；频道能否播放取决于来源可用性、网络及访问条件，失效或含省略号的地址无法自动补全。
- 未知时长频道不支持拖动进度条或跳过片头片尾；显示的网速为媒体接收速率，并非整机网络速度。
- 频道列表暂不提供 EPG 节目单；台标取决于列表提供的图片地址。DRM 内容不支持，YouTube 登录提示不保证消除站点风控。
