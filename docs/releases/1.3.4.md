# v1.3.4

状态：已正式发布。北京时间 2026-11-06 11:25:21。

[GitHub Release](https://github.com/EkyoZZ/UnityYAMLViewer/releases/tag/v1.3.4)

## 更新内容

- 新增 Windows 网页 HLS 嗅探助手，可从浏览器发现的媒体或当前网页唤起软件播放；第三方支持提供油猴插件和脚本的安装入口。
- “打开 URL”可查找网页源码中的 HLS：单个结果直接播放，多个结果可选择；无法直接打开的网页尝试通过 yt-dlp 提取并自动播放。
- 修正网页视频播放的 Cookie 传递与转义解码，保留不同编码、码率和语言的音频选项。
- 播放页缓存进度显示更紧凑，支持取消、定位视频与音频缓存；完成的缓存任务也可定位文件。
- 粘贴链接时还原 Unicode 转义并保留百分号编码；方向键调音量显示居中百分比提示。

## 安装嗅探助手

1. 下载并正常启动 Windows 版 v1.3.4 或更高版本一次，完成本机播放协议登记；移动程序位置后重新启动一次。
2. 在“第三方支持 → 网页浏览器HLS嗅探助手”点击“安装油猴插件”，从 [Tampermonkey 官网](https://www.tampermonkey.net/) 安装浏览器插件，再点击“安装脚本”，打开 [Greasy Fork 脚本页面](https://greasyfork.org/zh-CN/scripts/604041-unityyamlviewer-hls-%E5%97%85%E6%8E%A2%E5%8A%A9%E6%89%8B) 完成安装。
3. 刷新目标网页，使用助手打开网页或媒体；浏览器提示时允许唤起外部应用。

## 使用限制

- 媒体处理依赖 FFmpeg，网页提取依赖 yt-dlp；直播、DRM 及部分站点仍不支持。
- 软件内置 HLS 查找只扫描网页源码；浏览器脚本可监听所在页面的请求，但跨域帧、Worker 和脚本隔离等情况可能漏检。
- 助手只传地址与来源页，不传浏览器 Cookie；登录、额外请求头、短时签名或过长地址可能影响播放，不保证所有网页均可使用。
