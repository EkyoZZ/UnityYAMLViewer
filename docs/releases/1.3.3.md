# v1.3.3

状态：本地发布准备稿，新候选已构建，尚未发布。

## 更新内容

- 新增音视频工程保存与恢复（.uyap / .uyvp），可继续未完成的编辑；工程页签支持打包普通 ZIP 并收集引用素材，方便分享。关闭未保存的编辑时确认是否放弃。
- 音视频编辑支持队列排序、勾选参与导出的条目、逐条导出及独立参数的合并导出；视频统一分辨率、居中等比缩放并补边。
- 网络视频直接交由 FFmpeg 在线播放，完整文件通过“缓存到本地”显式后台保存。分离音视频可独立复用，提取播放优先使用匹配的本地下载。
- 新增后台任务中心，统一查看缓存、下载、工程保存和导出，支持定位成品及任务状态提醒。
- 改进毫秒时间码、暂停帧预览、区间播放、空格播放暂停、起止边界锁定及撤销操作。视频支持画布扩展、填充色和十六进制颜色输入，预览同步。
- 修复列表重叠与拖放、各窗口列表宽度联动、弹窗唤醒、失效路径提示等问题；减少 yt-dlp 重复检测开销。

## 使用限制

- 原始素材通常按路径引用；工程不保存撤销历史，素材缺失需恢复路径。合并不支持图形字幕、GIF 和 PNG 序列，可使用队列导出。
- 网络提取依赖站点及会话状态，不支持直播和抖音提取。媒体处理需 FFmpeg，网页提取需 yt-dlp。
- 自动检查与本地构建状态见版本记录。真实站点播放、工程往返及各项 GUI 交互仍需验证，不宣称全面回归通过。
