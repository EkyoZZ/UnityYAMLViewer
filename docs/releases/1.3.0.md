# v1.3.0

已于北京时间 2026-11-03 22:20:43 正式发布：[v1.3.0](https://github.com/EkyoZZ/UnityYAMLViewer/releases/tag/v1.3.0)。

## 新增与优化

- 文本与代码预览可记住字号、行间距和段落间距。
- Markdown 支持排版／源码切换，完善常见 HTML 居中、SVG 徽章、图片缓存、蓝色下划线链接、代码着色与复制；修复代码框重复边框和框内间距。
- Windows RTF 改为 RichEdit 原生直读，支持缩放与复制全文，不再依赖 PDF 转换。
- 图片显示源位深、尺寸、文件大小、DPI 与 iTXt 大小；支持完全不透明 PNG 去 Alpha、iTXt 清理、自动刷新与会话撤销／重做，不修改 .meta。
- 内置下载器替代 Scoop／WinGet，按需下载安装 FFmpeg Windows x64 GPL Shared、LibreOffice；PDFium 保留直接下载。显示下载进度、SHA-256 校验与错误地址，FFmpeg 可加入用户 PATH。
- 第三方组件状态与操作集中到标题行；修复 Hierarchy 选中限制、表格固定行号分割线，CSV／TSV／PSV 行号从 1 开始。

## 支持范围与验证

- Markdown 不支持完整 HTML／CSS；RTF 复杂排版与嵌入对象不保证完全还原。
- PNG 去 Alpha 仅用于已确认完全不透明的图片，APNG 暂不支持；撤销记录仅在当前会话内保留，不代替永久备份。
- DPI 优先读取文件记录；缺少已解析记录时可显示 Windows 图像组件的读取值，其可能为系统默认值，来源见悬停提示。
- 已通过代码检查与 Windows x64 release 构建；用户已确认 RTF 常用格式与中文显示。最新图片清理／撤销、完整组件安装与 PATH、Markdown 布局仍待完整运行回归，未执行全部测试程序。
