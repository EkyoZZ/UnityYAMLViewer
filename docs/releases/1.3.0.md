## 新增与优化

- 文本／代码预览支持记住字号与间距；Markdown 排版、常见 HTML 居中、SVG 徽章、蓝色下划线链接、语法着色与复制体验完善。
- Windows RTF 直接只读预览，支持缩放与复制全文，不再依赖 PDF 转换。
- 图片显示源位深、文件大小及水平／垂直 DPI；完全不透明 PNG 可去 Alpha，iTXt可清理，支持原位替换、自动刷新及会话撤销／重做。
- 内置下载器替代 Scoop／WinGet；按需下载安装 FFmpeg Windows x64 GPL Shared、LibreOffice，保留 PDFium 直接下载，显示进度、校验与诊断地址。
- 第三方组件状态与按钮同排；FFmpeg 完整解压，优先自动检测 PATH，可手动加入用户 PATH。
- 手型开关只限制预览选择；修复表格行号分割线，CSV／TSV／PSV 从1编号；清理主程序编译警告。

## 支持范围与验证

- Markdown 不是完整浏览器，复杂 HTML/CSS 和完整字体字重不保证还原；RTF 为固定 A4 RichEdit 渲染，复杂排版有限制。
- PNG Alpha仅在所有像素完全不透明时可去除；APNG不支持去Alpha。DPI仅显示已读取的数据，会话撤销不作为永久备份。
- 用户已截图确认RTF常用字符格式与中文；代码检查与本地构建不等同于完整运行回归。最新图片清理／撤销、完整下载安装及PATH、Markdown最新布局仍待实际验证。
- 构建信息见版本记录和 HANDOFF；未创建标签、Release 或上传附件。正式发布标题仅使用 v1.3.0。
