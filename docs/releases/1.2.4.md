# Unity YAML Viewer v1.2.4

本版扩展视频编辑与导出，加入多音轨 / 软字幕支持，并新增 CSV、TSV、PSV 表格查看、编辑、类型检查和查找。

## 视频编辑与导出

- 独立编辑窗口、可调宽导出面板、固定另存为与范围操作；专用帧 / 时间轴支持缩放、横向浏览、范围拖动和平滑橙色游标。
- 叠加画面裁剪框，支持拖动与像素输入；画面大小可独立设置或叠加裁剪，百分比 / 像素切换，锁链控制等比或独立宽高，预览同步宽高比。
- MP4、WebM、MKV、MOV、AVI、FLV、MPEG-TS、3GP、NUT、GIF，容器与后缀独立，支持 .bytes 等自定义后缀。
- 按容器筛选 H.264、H.265、VP8、VP9、未压缩 RGB24、MJPEG、MPEG-4、ProRes 422、AV1、MPEG-2。质量 / 目标码率、帧率及兼容编码的 2 pass 可选，默认单遍。
- 按容器选择 AAC、Opus、PCM16、MP3、AC-3、FLAC、Vorbis、E-AC-3；默认 48000 Hz，可选 44100 Hz 等兼容采样率。
- GIF 可选颜色数与五种抖动方式，无音频并无限循环。音频、视频及 GIF 导出完成 / 失败均弹窗提醒。

## 音轨与软字幕

- 已有音轨和字幕默认加入列表，可追加、取消、移除及设置语言，按容器检查数量和兼容性。
- 外挂文字字幕可转换为兼容的内嵌软字幕；播放器支持内嵌文字字幕和外挂 SRT / ASS / SSA / VTT。
- 字幕可跟随音轨语言，无法唯一匹配时提示手动选择；可设字体、字号、颜色、边距，描边和投影可分别或组合启用。
- 播放样式不烧录画面或写入软字幕轨。转换可能损失样式；播放器暂不显示图像字幕，无 OCR、逐轨偏移或混音。

## CSV / TSV / PSV 表格

- 表格 / 原文切换、列宽调整、双向常显滑条及全文悬浮提示；列标 A、B…AA，行 index 从 0 开始。
- 保存 / 放弃编辑、修改高亮、Ctrl+Z 与未保存提醒；顶部内容栏显示 E15 等地址，与单元格双向同步。
- 类型检查先采样 3 行，不确定扩展至 5 行；识别整数、数值、布尔值、JSON 对象、数组和文本，错误标红、计数并可前后定位。
- Ctrl+F 聚焦，匹配淡绿标记并可前后定位；小表实时、中表延迟 250 ms、大表回车触发后台查找。
- 支持引号内分隔符 / 换行和转义，仅编辑已有单元格，无行列增删或 XLSX / ODS。类型检查为辅助提示，不代替业务校验。

## 操作与本地化

- 播放列表菜单显示退出编辑，保存成功后自动退出。
- 顶部搜索展开隐藏指令查看；完善表格工具栏、编辑地址对齐和选中边框。
- 清理废弃文案，保持七语言及实际使用的关于历史摘要。

## 使用与验证

Windows x64 单文件 EXE。音视频处理及字幕播放需要本地 FFmpeg / FFprobe 和相应编码器 / 滤镜；第三方引擎不打包进主程序，部分新编码或扩展 FLV 的播放兼容性取决于播放端。

本版不支持视频合并、批量队列、硬件编码、HLS 流媒体、MXF / Ogg；不保证 HDR / 所有元数据保真。大表加载及类型检查仍可能有界面开销。

Release 构建和编译检查已完成；完整 GUI、所有语言 / DPI、多轨字幕端到端导出及大表性能尚未全面回归。详情见[版本记录](../versions/1.2.4.md)。
