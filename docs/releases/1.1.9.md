# Unity YAML Viewer v1.1.9

本次更新重点为播放列表、音视频使用体验与界面优化。

## 播放列表

- 支持本地 M3U8 / M3U，按目录全部同类媒体或文件名前缀创建，预览、排除与排序后保存；支持命名修改与同名覆盖提示。
- 一份列表只占一个页签，最近打开只记录列表；与普通媒体页签的播放器、播放进度独立，重新打开恢复当前条目与位置。
- 视频编号网格 / 名称列表，音乐名称列表；侧栏可调宽、滚动条靠右，音频支持顺序、随机和单曲循环，标题显示当前模式。列表使用矢量 Next 按钮。
- 每份视频列表独立设置跳过片头片尾，单位 s；快捷按钮从当前位置取值，支持重置。最后一集结束暂停并显示确认提示。
- 全屏列表半透明悬浮，不挤占视频；左侧圆角、右侧贴边，居中对称调高，最大宽度为窗口宽度三分之一。箭头由媒体区域鼠标移动唤醒，一秒静止后隐藏。

## 音视频与界面

- 音视频打开即播放并恢复上次位置；改善常见音轨名称、语言本地化，显示音频及视频所选音轨码率，缩小波形底部留白。
- 文件直链后台下载打开；查找栏自适应、最近记录删除 / 清空与宽度修复、长页签截断及路径提示。
- 格式支持及 Windows 默认程序引导；缓存占用查看和安全清理，保留设置、最近记录及用户列表文件。
- 独立弹窗再次唤醒时重新居中并请求前置聚焦；长设置文案在右列换行，七语言同步。

## 限制与验证

- 播放列表仅支持本地路径 / file URI；不支持 HLS、网络媒体条目和递归目录。每份最多 10,000 条、8 MiB。
- 列表设置与进度保存在本机，移动 / 改名不跟踪；强制退出可能丢失最新进度。缺失码率显示未知，续播不保证任意资源帧级精确。
- HTTP / HTTPS 仅文件直链，最大 1 GiB、五分钟总超时，不支持网页解析、认证或边下载边播放。
- 用户已验收并授权正式发布；编译、测试源码编译及七语言目录检查通过，测试断言未执行，不代表全部资源、显卡、多 DPI 和语言全面验证。
