# v1.2.7

发布准备稿，尚未发布。相对已发布 v1.2.6 的新增与优化。

## 序列工具

- 新增序列拆分与制作，支持网格／Unity Sprite meta 拆分、智能行列识别、四方向忽略补边、跳过透明空帧和自定义编号。
- 多图制作支持拖入、同组自动加入、自然排序、调序、裁剪缩放、透明间隔与居中，可导出合成 PNG 和可选 Unity tpsheet。
- 制作与拆分支持取色去底、容差预览、边缘柔化及去色边；取色提供光标、色值和取消提示。
- 支持单帧播放及撤销／重做，包括 Ctrl+Z 撤销误拖入的图片。

## GIF 与视频

- 序列可转 GIF／视频，沿用预览 FPS，通过缓存 PNG 提供首帧、定位及播放预览。
- GIF 可转视频；视频和 GIF 可导出 PNG 序列，沿用时间选区、裁剪、缩放与帧率。
- 完善 GIF 独立帧率、循环次数、颜色压缩、缩放滤波和透明处理，默认 Bicubic＋Sierra2 4A。
- 修复选区末尾预览显示下一帧的问题；音视频／GIF 导出可确认覆盖，成功编码后再替换原文件。

## 其他

- 单独查看 R／G／B 时可应用 Alpha；可手动指定并保存 FFmpeg、FFprobe 和 PDFium 路径。
- 修正四方连续图预览顶部对齐，精简补边标签及序列布局，同步七语言。
- 去水印入口暂时隐藏，保留实现供后续完善；序列去底色正常开放。

## 限制与验证

- 用户已确认本版新增和优化验证无问题；未声明全部自动测试执行通过。
- 去底色可能影响同色主体；PNG 序列不携带时长、循环、音频或字幕；tpsheet 需对应 Unity 导入器。
- 构建信息见 [版本记录](../versions/1.2.7.md)。Git 由用户提交，收到后续发布通知后再创建 GitHub Release；发布标题仅使用 v1.2.7。
