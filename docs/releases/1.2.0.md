# Unity YAML Viewer v1.2.0

本次更新新增 Material 与 Shader 的 Node-based UI（节点式界面）预览，支持在节点内临时调参、替换纹理，并查看 2D / 3D 输出。

## Material / Shader 节点预览

- `.mat` 与 `.shader` 使用统一“预览”按钮打开独立节点面板；材质载入实际参数与纹理，Shader 使用 Properties 默认值。Inspector 保留属性 / YAML，Shader 源码可单独查看。
- 数值、颜色、向量和纹理直接在 Property 节点内调整，RGBA / XYZW 分量逐行显示。颜色视图参考属性声明与可识别的源码上下文，可手动切换；支持单节点或全部输入重置。
- 修改仅影响当前预览，不写回文件。支持选择图片或将单张本地图片拖到 2D 纹理 Property 节点临时替换，保留 Tiling / Offset；其他落点仍正常打开文件。
- Vert、Frag、辅助函数及 Vertex Input / v2f / Varyings 分组展示，显示源码语句、可识别的调用与参数 / 分量连接。画布可平移缩放，节点与分组可拖动。

## 输出与交互

- 实时输出嵌入画布模块，可拖动标题移动，右下角拉伸，支持“定位输出”。2D 可切换棋盘格 / 纯色背景；3D 提供球体、圆柱体、立方体，可拖动旋转并重置姿态。
- 预览与 Inspector 随主窗口可用宽度按比例调整，手动拖动分隔线后保留新比例。节点连线按距离和画布缩放调整贝塞尔控制柄，Frag 输出端口固定于组框顶部附近。
- 预览缓存尺寸超限时继续直接渲染，裁剪为零像素的区域跳过当前帧，避免缓存尺寸问题阻断预览。
- 播放列表标题增加顶部间距，管理菜单使用矢量扳手图标；应用图标补齐 13 档尺寸，直接使用对应 PNG。
- 相关说明与关于窗口摘要同步七语言；关于窗口默认展示当前版与上一版，其余历史默认收起。

## 当前限制与验证

- 当前为预览与源码结构展示，不支持创建运算节点、编辑连线或生成 Shader，也不保证完整还原函数间数据流、复杂宏和子图。
- 实时渲染限受支持的 Built-in 单 CG Pass；URP / HDRP、多 Pass、非 2D 纹理、部分 uniform / 顶点输入及缺失依赖可能无法渲染，显示具体诊断。材质需要可解析的 Shader GUID 和项目索引。
- 3D 为预置凸网格的正交预览，完整深度、复杂位移 / 透明相交、场景光照 / 蒙版、HDRI / PBR 和自定义模型导入仍有限制或未实现。Varyings 的 TEXCOORD 通道不等同于模型 UV 通道。
- 拖图需来源提供本地文件路径；支持单张 PNG / JPG / JPEG / TGA / BMP / WebP，不解析 Unity 私有拖放格式。单张纹理最大 4096×4096 / 64 MiB，预览纹理总预算 128 MiB。
- 用户确认测试通过并授权正式发布；Release 构建、编译检查、测试源码编译、七语言目录及 EXE 图标资源核对通过。测试断言未执行，不代表全部资源、显卡、DPI 和语言组合均已全面验证。
