# v1.3.7

状态：已正式发布。北京时间 2026-11-25 19:52:50。

[GitHub Release](https://github.com/EkyoZZ/UnityYAMLViewer/releases/tag/v1.3.7)

- **Image 和 Tile 编辑**。新增分层像素 Tile 工程、菱形网格与跨格绕回。文字、路径和矢量形状可参与绘制，并支持多格渐变连续和逐格 PNG 导出。
- **PSD 互通**。图像编辑可读写支持的分层 PSD 和横排文字，保留受支持的 Photoshop 附加数据与合成预览。
- **Prefab 动画预览**。Animator 和 Animation 可打开独立的时间轴窗口。支持关键帧／曲线、播放和定位。可展开受支持的 FBX 骨骼，预览内嵌 Clip、骨骼挂点和蒙皮动作。
- **GPU 场景预览**。含网格的场景共用固定 2D 和可旋转 3D 预览。支持的普通粒子按渲染排序与模型合成，Canvas 中的 UIParticle 走 UI 路径。
- **编辑体验**。改进曲线页与 Inspector 实时预览性能，优化 Tile 文字改色，统一拾色器、渐变编辑窗口和确认按钮顺序。
- **录屏与视频编辑**。调整录屏倒计时和边框，改进音轨波形、试听和字幕轨切换。

## 使用限制

- FBX 内嵌 Clip 预览为只读。源曲线减键留待下一版本。Animator 状态机自动运行、过渡和 Blend Tree 仍有限制。
- 粒子预览支持现有模拟器可处理的 Billboard 类型。3D Canvas 平面暂不支持。
- Photoshop UXP 插件及其安装器走独立发布渠道，主程序附件为 Windows x64 EXE。
