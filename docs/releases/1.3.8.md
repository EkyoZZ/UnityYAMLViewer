# v1.3.8

状态为待发布。本地 Windows x64 候选包已核验。

- **独立 FBX 预览**。可在模型页识别同目录的贴图和外部动作，也可手动选择或拖入。材质槽可独立切换透明／不透明和双面／单面，动作列表支持批量添加。
- **动画时间轴**。独立 FBX 动作可在当前模型播放，支持暂停、循环、定位和查看关键帧与曲线。FBX 时间轴显示文件中实际保留的关键帧。
- **关键帧优化**。Prefab 动画和独立 FBX 动作可生成减键草稿，查看关键帧数和误差，并左右同步对比原动作与草稿。支持的二进制 FBX 和独立 Unity .anim 可原位替换或另存为。
- **模型取景**。2D 和 3D 原预览在动画播放时固定取景，模型预览可拉远观察位移较大的动作。

## 使用限制

- FBX 减键适用于支持的平移和缩放曲线。独立预览使用外部动作的第一个 Take，要求骨骼可匹配。手动贴图和材质设置用于预览。
- 原位替换保留现有 .meta。Unity 重新导入后的 Clip fileID 和 Animator 引用仍需在实际工程中核对。
