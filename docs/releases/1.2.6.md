# v1.2.6

状态：发布说明草稿，尚未发布。相对 v1.2.5 的修订版本。

## 图片与预览

- 修复普通图片放大模糊，以及四方连续图预览把小图插值放大、非方图拉伸的问题；高倍棋盘格对齐源像素。
- 图片、SVG、九宫格、连续图、场景 / Prefab、模型和 Spine 统一背景模式与自定义颜色，并在重启后恢复；首次自定义颜色为黑色。
- 图片通道、背景与排序轴统一主题 Tab；图片工具按钮移到文件名后，辅助线开关改为紧凑布局。
- 四方连续图与九宫格另存支持覆盖；九宫格存在同名 meta 时额外确认，保留现有 GUID / Border 并提醒可能不匹配。
- 九宫格边界标签移至图片外；连续图另存按钮缩为 120 × 40、字号 16，紧随标题与尺寸两行文字。

## 媒体与通用界面

- 视频 / 音频顶部保留基础摘要并提供详细入口，按文件、视频、音轨和字幕分组显示参数，补充音乐标签。
- 字幕样式支持搜索 Windows 已安装字体，窗口更紧凑，应用 / 取消 / 重置按钮放大并底部居中。
- 透明 GIF 及解码后保留 Alpha 的视频以棋盘格衬底显示；效果不写入源文件或导出。
- 最近打开列表限高滚动，清空记录固定在底部；关于窗口增加作者 EkyoZZ (Ekyo · Cheung)。

## 限制与验证

- 预览背景不改变输出背景；另存覆盖不建立备份，写入失败可能留下不完整文件；九宫格另存不自动同步目标 meta 的 Border。
- 透明视频和字幕字体实际效果依赖 FFmpeg / libass；未增加透明 WebM 专门解码器选择，图片字幕仍不支持显示。
- 本地构建和验证结果以 [版本记录](../versions/1.2.6.md) 为准；完整 GUI、多语言与 DPI 回归仍待验证。
