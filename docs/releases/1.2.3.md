# Unity YAML Viewer v1.2.3

本版新增音频编辑、PDF / SVG / GIF 预览与第三方支持管理，完善文件页签和媒体操作。

## 音频编辑与转换

- 独立音频编辑窗口，切换或关闭来源页签后继续保留，支持多文件独立试听。
- 头尾剪切、删除中间区间、选区增益、淡入淡出，七种预设与可编辑贝塞尔曲线；支持撤销 / 重做。
- 波形滚轮缩放、水平浏览及播放游标居中跟随。临时 PCM 保存中间结果，另存为 MP3 / WAV / FLAC / M4A（AAC）。
- 视频保留基础范围导出 MP4，并非完整视频剪辑功能。增益可能削波；缓存占用磁盘，崩溃可能残留；不支持多轨、交叉淡化和样本级编辑。

## PDF 只读预览

- PDFium 多页渲染、适应窗口 / 宽度、固定倍率、缩放与拖动；按系统 DPI 渲染并对齐物理像素。
- 底部页码 / 缩放浮层及圆形翻页按钮；上 / 左上一页，下 / 右下一页。
- F11 黑底全屏，F11 / Esc 退出；自动翻页、可调秒数与循环，单页隐藏设置。
- 过渡可选无、淡入淡出、左右滑动、推页、擦除、缩放淡入。新页就绪前保留旧画面，加载超过 1 秒才显示等待提示。
- 只读，不支持 PDF 编辑、文字选择 / 搜索、密码输入、OCR 或交互表单。文件最大 128 MiB，渲染单边最大 4096 像素。

## SVG 与 GIF

- SVG 静态只读预览，支持棋盘格 / 灰色 / 自定义背景、缩放、拖动与重载；文字需转轮廓，不支持外部资源、内嵌位图和动画，文件最大 16 MiB。
- GIF 使用 FFmpeg 播放，支持文件循环设置、一次、无限和自定义总播放次数。显示调色板最大容量，隐藏音量 / 音轨控件。
- GIF 按实际帧时长显示刻度、当前 / 总时间与帧号，以及当前帧的 s/f；f 和 s/f 固定不翻译。

## 第三方支持与操作体验

- 设置新增独立第三方管理窗口：FFmpeg / FFprobe、PDFium、LibreOffice。
- PDFium 按需下载 Windows x64、不含 V8 的组件，核对 SHA-256；组件位于独立目录，不被缓存清理删除。FFmpeg / LibreOffice 经 WinGet 安装，LibreOffice 可能需要管理员确认。
- 缺组件直达管理窗口；安装后检测或重新检测完成时同步主窗口。LibreOffice 目前只有管理入口，Office / 苹果办公文档预览和编辑尚不支持。
- 同后缀超过 3 个文件自动堆叠，支持整组拖拽、数量显示、单项 / 全部关闭及未保存提醒。
- 页签、堆叠文件项及预览文件名右键可在资源管理器中选中文件，或复制完整地址。
- 视频与 GIF 的整个预览框（含留白）可单击播放 / 暂停；自由缩放拖动和控制条操作保持独立。

## 使用与验证

Windows x64 单文件 EXE。PDF 需要先在“设置 → 第三方支持”下载 PDFium；GIF / 音视频播放及音频编辑需要 FFmpeg / FFprobe。不会把第三方引擎打进主程序，下载或安装由用户点击触发。

用户已确认最新整框播放操作及此前文件定位 / 复制地址、页签堆叠显示；已完成 Release 构建、编译检查及记录中的针对性自动测试。尚未完成所有语言 / DPI、复杂资源、组件安装与 PDF 动效的全面运行回归，已知功能限制保留。
