# Unity YAML Viewer v1.2.1

- 替换 AppIcon。
- 优化 Material 和 Shader 预览操作体验。

节点与函数分组的选择、拖动、折叠及预览按钮更易操作；支持 R/G/B/A 单通道相关运算预览，可见节点以约 60 帧/秒为目标持续更新，收起或离屏后暂停。

预览仍受已支持的 Built-in Shader 范围限制，实际刷新率取决于 GPU 和同时展开的节点数量。
