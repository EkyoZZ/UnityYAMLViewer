# Unity YAML Viewer v1.2.2

## 九宫格图片精简

- 精确比较完整 RGBA，自动选择横向、纵向或同时精简，以及拉伸 / 重复；中心、边界和保留循环倍数均可调整。
- 独立窗口对照裁剪与结果，斜纹显示删除区域，展示节省面积及原因详情；默认保留透明边缘、对齐 4 倍数，补白不计入 Unity Border。
- 支持确认后原位替换或另存 PNG；可同步受支持的单 Sprite `.meta` Border / Full Rect，保留 GUID。原位替换无备份，请使用 Git 管理资源修改。

## 命令行与用法

```powershell
unity_yaml_viewer.exe slice9 "button.png"
unity_yaml_viewer.exe slice9 "Assets\UI" -r --dry-run
unity_yaml_viewer.exe slice9 "a.png" "b.png" --preview
```

- 批量及目录递归自动处理，JSON 结果与退出码便于脚本调用；默认原位替换，有可读且支持的 meta 时写回，无收益不修改。
- `--preview` 打开可编辑预览，不自动保存；最多同时 10 个窗口，重复路径复用、超出提示。原来的单个 / 批量打开指令保持兼容。
- 主窗口新增“指令查看”，包含可复制用法、示例与引号规则；也可使用 `--help` / `slice9 --help`。
- 修复普通鼠标点击或任务切换恢复弹窗焦点时意外重新居中。

原位支持 PNG / TGA / BMP / 静态 WebP；动画、多 Sprite 和其他不支持的 meta 有限制。输出为 8 位 RGBA；Unity UI 的 Sliced / Tiled 需手动设置。面积节省不等于文件或显存节省。GUI 多窗口与 Unity 导入的完整运行回归仍待验证。
