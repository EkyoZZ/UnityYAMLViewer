# Unity YAML Viewer v1.1.8

本次更新重点接入场景与 Prefab 的 GPU Shader 预览，改善模型和 Spine 材质显示，并加入基础粒子实时播放。

## 渲染与材质

- Sprite、普通 Mesh 和 Tilemap 可读取 Renderer 材质，执行受限的 Built-in CG/HLSL Shader 预览，支持颜色、纹理、时间参数及常见混合状态。
- Shader 引用支持 Assets、Packages 和 Library/PackageCache，兼容部分 Include、数学函数、片元 clip 和不依赖实例化分支的 Shader；失败时提供可复制的诊断。
- 普通网格支持多材质槽：额外材质按槽顺序叠加到最后一个子网格。
- 场景与独立 Spine 3.8 预览接入原始网格、图集和材质的 GPU Shader 绘制；从场景进入独立预览时携带材质覆盖及初始皮肤，独立动画更新网格。
- 静态单蒙皮 FBX 改善轴向、导入单位与可唯一确认的根骨骼均匀缩放覆盖；PF3D2 材质兼容主色与透明度，按名称匹配多个外部材质槽。

## 粒子与预览交互

- 二维场景与 Prefab 共用基础粒子实时预览，支持播放、暂停和可重复的固定种子重播，使用 ParticleSystemRenderer 材质进行 GPU 绘制。
- 支持持续发射、Burst、常见初始属性、大小 / 颜色 / Z 旋转生命周期变化，以及部分基础形状。
- 支持预算内循环预热、缓存重播、Billboard 独立宽高和静态 ConeVolume；尚未支持的模块提供诊断。
- 展开的 Prefab 实例根节点可在 Inspector 标题旁打开源资源页签。打开源资源不复制场景实例覆盖。
- 场景点选嵌套 Prefab 可定位、展开祖先、滚动并高亮对应 Hierarchy 节点。
- 完成首次 GPU 渲染后，鼠标离开画面或应用失去焦点时冻结预览；返回后继续更新，窗口缩放保持画面比例。

## 资源与修复

- 项目索引优先读取磁盘缓存，再后台刷新；支持手动重扫及 Packages / PackageCache 资源索引。
- 提高嵌套 Prefab 展开预算，并优先保留预算诊断。
- 对象名称中的 Unicode 转义显示为实际文字，不改写源 YAML。
- 本地 fileID 引用的有效空 Mesh 正常跳过绘制，不再误报资源缺失或超预算；损坏数据仍报告错误。
- 同步七语言关于摘要，默认展示当前版本与上一版本，其余历史保持折叠。

## 使用范围与限制

- 预览不是 Unity 完整运行时。URP / ShaderGraph、完整光照与场景深度、任意多 Pass、运行时脚本和完整动画场景仍未还原；Stencil 遮罩忽略并提示。
- 粒子目前面向二维世界预览。UI Canvas / 3D、Mesh / Stretch Renderer、Custom Vertex Streams、纹理动画、碰撞、子发射器、轨迹及部分复杂模块仍未支持；每场景最多 128 系统、每系统 4096 粒子、每帧最多 65536 可见粒子。模拟与随机分布不保证和 Unity 完全一致。
- Spine 特殊混合、双色染色、缺失材质映射或不支持的 Shader 保留回退；仅略过明确的 ShadowCaster Pass。
- 单蒙皮 FBX 仍以静态姿态为主，其他骨骼覆盖和动画未完整还原；线拓扑 Mesh、LineRenderer、TrailRenderer、Terrain 暂未接入。
- 编译和针对性回归已通过，部分真实资源已有用户反馈确认；未完成所有资源、显卡和七语言界面的全面回归。

## English

This release adds limited GPU material/shader rendering for scenes and Prefabs, including Tilemaps and Spine, improves static FBX axes, scaling and transparency, and introduces basic real-time particle playback with pause, replay and bounded prewarm. Expanded Prefab roots can open their source assets in separate tabs. Project index caching, package references, nested-instance navigation, preview freezing and empty-mesh diagnostics are also improved.

Rendering remains a preview subset rather than the full Unity runtime. Advanced particles, UI Canvas / 3D particles, custom vertex streams, URP / ShaderGraph, full lighting/depth, arbitrary multipass shaders and runtime scripts remain unsupported or limited. Unsupported resources retain diagnostics or fallback. Targeted checks passed; comprehensive visual verification across all resources and GPUs is not claimed.
