## 界面与 URL 打开（2026-10-14）

- 按用户图示移除文件菜单右侧路径及查找下方提示；放大镜按钮展开 / 收起查找输入框，矢量 X 按钮清空查找。按钮为 28×28 正方形；输入框随第一排剩余宽度缩短，不足 160 点时移至第二排，保留查找匹配与清空后的定位行为。

- 文件菜单新增打开 URL 独立弹窗，长输入框及确定按钮；HTTP / HTTPS 文件直链在后台下载完成后打开，支持已有文本、Unity 序列化资源、图片、音视频及模型查看器。网络 / HTTP / 文件类型 / 保存错误显示具体原因；最大 1 GiB，连接超时 15 秒、总超时 5 分钟，重定向使用 reqwest 默认策略。
- 直链文件缓存在系统临时目录 UnityYAMLViewer-network；失败下载清除临时文件，成功文件由系统临时目录管理，当前无应用内清理按钮。不加入最近打开和恢复页签、不修改本地打开目录。网页解析、登录认证、流媒体播放及边下载边播放未实现；下载后解码失败由现有查看器提示。关闭 URL 窗口不取消已开始下载，完成后仍会打开或显示错误。
- 新控件、错误提示及关于摘要同步七语言；README 中英同步实际能力与限制。
