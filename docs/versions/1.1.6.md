## 外部 FFmpeg 音视频播放

- 常见音频（MP3、WAV、OGG、FLAC、AAC、M4A、WMA、Opus、AIFF）及视频（MP4、MKV、WebM、MOV、AVI、WMV、FLV、MPEG、TS、MTS、M2TS、3GP）接入独立资源页，打开、拖入、最近文件和资源引用沿用统一入口，不按 YAML 解码媒体文件。格式能否播放取决于外部 FFmpeg 构建与文件本身。
- 使用外部 ffprobe 读取媒体信息、FFmpeg 后台解码，rodio 仅负责 PCM 音频输出，关闭其内置格式解码功能；不内嵌或自动安装 FFmpeg。缺失时提供视频解码设置入口及重试。
- 播放 / 暂停 / 停止、时间进度与跳转、音量；暂停、跳转和解码方式切换以停止并重新启动解码实现。切换页签停止播放与波形扫描并释放视频纹理，关闭文件释放任务；仅结束应用自身启动的解码进程。
- 视频按原始分辨率解码，不再固定转换为 24 fps；使用输入实时读取与帧率 passthrough，保留源帧率。实际显示流畅度受解码、RGBA 传输、GPU 纹理上传和界面刷新速度影响，尚未实现 GPU 零拷贝或基于音频设备时钟的精确同步。
- 视频默认等比适应窗口，宽或高先抵达可用预览区边界，另一边留空；支持原尺寸 1:1 显示与滚动，以及左右 / 上下镜像组合。
- 视频页提供自动 / 软解 / 硬解切换，硬解使用 Windows D3D11VA，运行中切换从当前进度重新开始；自动由 FFmpeg 选择可用加速，未宣称自动模式必定使用 GPU。硬解不可用或无解码输出时提示，可切回软解。
- 纯音频页后台生成固定 2048 个峰值列的波形，单声道一条，双声道上下 L / R 两条，显示播放位置；视频不显示波形。波形经 8 kHz 重采样，为预览近似包络，不作为采样精确的音频分析；多声道降混为双声道。
- 限制：仅首个音频流与首个非封面视频流，未接入字幕、多轨选择、网络流、逐帧编辑或音频设备选择。单边视频尺寸不超过 8192、单帧不超过 32 Mi 像素；视频队列 2 帧，音频队列分块限额，长音频波形扫描耗时仍随长度增加。
- 验证：cargo check --offline --locked --tests 与 git diff --check 通过（测试代码仅编译未执行）；FFmpeg 实际解码 1 秒 60 fps 测试视频得到 60 帧 RGBA，PCM 音频输出正常；双声道测试左峰值 32768、右峰值 0，确认解码输入声道分离。尚未运行应用验证实际声卡播放、音画同步、硬解、暂停 / 跳转 / 镜像交互；未重新生成 EXE。Spine Runtime 保留 158 条已有警告。
