## 更新内容

### 替换 AppIcon

- 使用当前应用图标资源，包含 16～256 的 13 档 Windows 图标及高清源图；保留原始颜色，构建时打包对应 PNG。
- 图标生成脚本支持从 1024 / 512 源图生成小尺寸 PNG，Windows 图标缓存可能影响资源管理器显示。

### 优化 Material 和 Shader 预览操作体验

- 常见表达式拆分紧凑运算节点，函数具名输入 / 输出边界与分量连接，折叠 / 展开保留布局；可拖动与拉伸分组，常量成员随组移动。
- 统一左键选择 / 框选与节点 / 分组多选拖动、Shift 增减、右键平移和滚轮缩放；修正连续拖动与输出离屏导致的移动 / 框选失效，下拉菜单优先处理滚轮。
- 函数折叠 / 展开提供直接绘制的减号 / 方框及按钮边框；预览采用带框矢量眼睛按钮，修正图标空白与节点拖动区域抢占点击。
- RGB / RGBA、R/G/B/A 单通道、RG 及其后续运算支持按需预览；单通道显示灰度，非颜色 UV / 位置 / 法线不强制作为颜色。
- 展开且可见的节点预览以约 60 帧/秒为目标持续使用当前 Shader 时间刷新，收起或离屏暂停；复用准备场景和贴图，每节点最多一个在途采集。输入应用后重建，仍提供手动刷新。

## 限制

- 预览仍限受支持的 Built-in Shader；复杂控制流、不确定 Helper 调用上下文、无法识别的类型等可能无法预览。不支持编辑连线或生成 Shader。
- 节点预览使用 192×192 GPU 读回、最多 64 条缓存；60 帧为刷新目标，实际受 GPU、主线程、垂直同步和展开数量影响，不承诺每节点稳定达到 60 帧。外部文件变化不自动同步。
