## 1.1.4（已封版，待正式发布）

2026-10-11：用户确认当前版本封版。以最近成功构建的 Release EXE 为封版候选，未创建发布提交、Git 标签或上传发布附件。以下摘要为最终版本行为；后文逐轮记录保留过程和验证历史，已被后续修改取代的规则以此摘要及最新记录为准。

### 封版内容摘要

- 场景与 Prefab 静态 2D 预览支持 SpriteRenderer、Tilemap、常见 UI 图片和文字；Tilemap 按 Grid、矩阵、颜色和排序重建，提供结构化属性及格子/引用表格。
- 大文件后台读取、解码与对象解析，延迟显示分阶段进度和取消；纯场景后台资源加载与 CPU 合成，最长边 1024 像素，两路加载及跨任务纹理/切片缓存。修正小尺寸 PNG 解码预算不足。
- 预览固定状态行提供暂停/继续/退出，完成后隐藏任务按钮；平移缩放即时变换缓存画面，操作连续停止 0.5 秒后按覆盖范围及相对缩放阈值更新合成。节点显隐改变会重新构建预览。
- 棋盘格/灰色/自定义背景、XYZ 排序轴、默认关闭的辅助线开关；辅助线绘制在内容背后，棋盘格下采用柔和灰色。适应窗口后提供 50%/100%/200% 按钮，底部浮动显示当前比例；静态预览 100% 为默认适配视角。
- “展开嵌套Prefab”位于 Hierarchy 标题旁，无需开启预览即可后台展开引用。Hierarchy 与预览共用结果；当前文件直接 PrefabInstance 超过 20 默认关闭，允许手动开启。引用节点属性只读，常见覆盖、Variant、移除及源修改刷新已接入。
- Hierarchy 仅显示节点，组件集中于 Inspector；眼睛/手固定在左侧，悬停、焦点或选中时显示，关闭或继承关闭状态时持续显示。默认只展开 Transform/RectTransform，组件标题增强辨识；修正窄窗口预览/Inspector 布局。
- 新增 ParticleSystem/ParticleSystemRenderer 属性入口、MeshRenderer/SpriteAtlas 属性；粒子模块可折叠，已确认字段使用控件，复杂或未确认字段保留原始数据。
- UI 字体引用与回退、按需字形距离场描边；识别同对象名称含 Outline 的启用组件，读取颜色、宽度和垂直偏移。修正图片预乘及 UI 透明度颜色空间问题。
- 脚本/文本/图片引用查看、基础语法高亮与图片通道；最近十个文件、快捷主题、SVG 图标和可复用滑动开关；修复语言切换闪退及 UNITY_EDITOR 脚本字段识别。

### 界面与操作

- SpriteRenderer / Tilemap 的预览数据解析、引用查找和矩阵重建移至后台线程；按源文本、可见性/可选状态、资源索引与排序轴缓存结果。纯场景（不含识别出的 uGUI 图形）进一步改为后台资源读取、CPU 画面合成及像素命中索引，界面仅上传和显示最长边不超过 1024 像素的透明预览画面，拖动/缩放异步重绘，旧视角结果丢弃；保持排序、颜色 Alpha 相乘及镜像。完整源贴图 CPU 缓存上限 256 MiB、单图最大 8192×8192，超限资源列入问题提示；缩放后重新合成当前视角，超出画布分辨率的细节显示为预览近似。CPU 合成可能需要等待，不保证比 GPU 路径更快；真实大场景耗时和内存峰值待验证。
- 预览新增暂停/继续及退出预览按钮。暂停在 Tilemap 解析、实例重建、资源之间、像素转换及合成行的检查点等待，保留当前画面和进度；继续复用已完成工作。单次文件读取、图片解码或排序不能立即中断。退出立即关闭预览面板、恢复 Inspector 类型列，取消后台任务并释放预览文档引用，实例/命中/像素等大缓存由后台释放，避免主线程集中析构；打开的场景正文和 Inspector 数据仍保留。CPU 场景资源的磁盘改动需通过文件重载或退出重开刷新。
- 修复预览每帧为不存在的 UI 参数扫描完整 Tilemap YAML；非 UI 场景跳过 UI 布局及查询，UI 类型探测限于 64 KiB/128 行的组件头并缓存场景是否含 UI，派生 UI 字段超出该范围时不识别。含 uGUI 的预览仍走原有布局/网格路径，资源加载使用约 4 毫秒的软预算、每帧最多一次贴图上传，但 GPU 上传及 UI 布局仍在主线程；混合大场景的完整后台渲染、编辑预览文本重解析及 Inspector Tilemap 首次列表解析尚未后台化。
- 文件加载不再提前解析所有 Tilemap 列表；Inspector 展开 Tilemap 时才建立列表缓存。后台预览解析不创建原始 YAML 行范围索引，完成后释放解析中间数据；Tile flags 改为 u32，预览实例使用 6 个 f64 的 XY 投影代替 16 个 f64 矩阵。完整场景文本及对象分段仍驻留内存，不能保证接近 1 GB 场景的内存峰值。
- 静态预览增加 X/Y/Z 排序轴切换，默认 Y。SpriteRenderer / Tilemap 先按 Sorting Layer 索引、再按有符号 SortingOrder，从小到大绘制；相同值时按所选世界坐标轴从大到小绘制，坐标越小越后绘制。UI Image/Text 维持层级顺序；相同坐标仍用稳定顺序。SortingGroup、相机透明排序距离及运行时脚本修改排序暂未模拟。


- 文本/YAML 文件打开、会话恢复及只读重载改为后台线程顺序加载：读取、UTF-8/GBK 解码、Unity 对象解析不阻塞界面；单个加载任务超过 1 秒才显示状态弹窗，区分读取与解析，支持取消。取消在读取块及对象扫描之间检查，不保证正在执行的系统读取或单次正则匹配立即中止；取消及失败时不替换当前内容。
- 加载弹窗按居中状态标题、分隔线、下排进度条与右侧取消按钮布局，无独立标题栏；读取中按字节更新，解析中按对象扫描阶段更新，切换阶段时进度重新计量，属于阶段进展而非剩余时间预测。文件路径可悬停状态标题查看。
- Unity 对象行号改为按文件前进单次累计，不再为每个对象重复扫描整个文件前缀；记录对象字节偏移供节点状态查询。标签共享原始文本及对象文本，避免切换标签复制整份大场景；层级宽度缓存，超过或等于 2000 个对象时层级默认收起（已有展开状态仍保留）。
- 大文件仍采用完整读取与内存对象索引，尚未实现磁盘分页或内存映射；接近 1 GB 的文件仍可能占用数 GB 内存，编辑、保存及复杂属性的其他同步处理尚未完成全流程后台化，实际极大场景性能待验证。
- Hierarchy 仅显示 GameObject 层级，所属组件集中在 Inspector 中显示，每个组件可独立展开或收起。
- 节点 Inspector 默认仅展开 Transform/RectTransform，其他组件默认收起；用户已调整的展开状态保留，直接定位/选中某个组件时仍展开该组件。
- Inspector 组件折叠标题增加圆角底色框，采用“预览”按钮悬停/按下时相同的主题底色，展开与收起均显示，便于辨认组件分区。
- Inspector 组件标题底色框右侧增加 8 像素留白，深浅主题一致，避免文字紧贴右边缘。
- 组件标题底色进一步提高与面板的对比度：浅色主题使用 RGB (210,225,244) 蓝灰色，深色主题使用 RGB (65,76,96) 蓝灰色。
- Hierarchy 仅在节点具有当前搜索条件下可显示的子 GameObject 时显示展开三角；叶节点保留对齐空位，不再因 Inspector 中的组件显示空展开按钮。
- 主界面右上角增加紧凑的浅色、深色、系统主题切换；设置入口改为齿轮图标。
- 顶栏“文件”使用蓝色填充矩形按钮，更新提示 New 使用红色填充矩形按钮；两者与主题切换统一为 24 高度及相同文字内边距，宽度随文字适配。
- 修复切换语言时翻译表尾部空行触发 panic 导致程序退出的问题；翻译表加载忽略空白行，增加有效行语言数量及重复键回归检查。
- 接入 SVG 图标，替换设置、层级可见性和可选状态图标。
- “打开”改为“文件”菜单，提供打开文件和最近打开记录；保留最近 10 个文件，显示文件名，悬停可查看完整路径。
- 文本预览滚动区域填满可用空间，使滚动条靠近视图边缘。

### 脚本与图片查看

- 修复整个脚本类位于 #if UNITY_EDITOR 时文件可打开但 Inspector 无法识别类/字段的问题：以编辑器上下文解析 UNITY_EDITOR 与 !UNITY_EDITOR 分支；未知宏、复合表达式及 elif 分支仍保守忽略，不执行 C# 编译或自定义代码。
- 内部资源引用可直接打开常见脚本、文本和图片；脚本、文本和图片也支持拖入窗口查看，原有打开文件对话框的 Unity YAML 类型筛选保持不变。
- 常见脚本提供基础语法高亮，补充 ShaderLab/HLSL 等着色器高亮；`.lua.txt` 按 Lua 高亮。
- 图片支持 R、G、B、A、RGB、RGBA 通道查看。
- 图片默认居中，支持拖动平移和滚轮缩放，以及适应窗口、50%、100% 和 200% 快捷显示；固定缩放按钮直接使用百分比标签，点击后将图片重新居中。
- 图片底部居中显示尺寸、通道及当前缩放比例，使用半透明背景以便辨认。
- 修正图片及静态 Sprite/UI 预览的半透明颜色预乘：与 egui 的 Gamma 空间混合保持一致，避免云等浅色透明边缘及重叠区域过亮；纹理 Alpha 与着色 Alpha 相乘，Sprite 之间仍使用普通覆盖混合。暂未还原 Unity 自定义 Shader 或 Linear 项目的完整渲染效果。

### Unity 资源属性与预览

- 静态预览入口开放到 .unity 场景文件，包含 Tilemap、SpriteRenderer 或支持的 UI Graphic 时显示预览按钮；只读预览复用已解析对象及共享文本，避免打开预览时再次复制和解析整个大场景。仍仅提供静态 2D 近似，不支持完整 Unity 场景渲染、3D、自定义 IsoMap 脚本或未展开的嵌套 Prefab。
- Tilemap、TilemapRenderer 与 Grid 增加只读结构化属性；Tilemap 的格子、Tile/Sprite 引用、矩阵及颜色数组以折叠列表显示，格子列表与原始 YAML 使用可见行绘制，缓存解析结果。源 Prefab 引用检查不再为大组件每帧解析全部嵌套 YAML。
- 修正 Tilemap 属性值列过窄导致 FileID、向量和颜色被拆成多行的布局问题：属性使用双列不拆行显示，过宽内容可横向滚动；格子与引用列表设置最小显示高度并保留滚动区域。
- Tilemap、Grid、TilemapRenderer 属性表补齐类型列：预览展开时隐藏，收起后显示；类型列开关独立刷新表格与滚动布局，包含 Vector3Int、Vector3、Color、引用及常见标量/枚举类型，未知结构保留通用类型标记。
- Tilemap 系列标量与引用属性使用只读文本框，向量拆成 x/y/z 文本框，Color 和颜色数组以 RGB 色块及 Alpha 条显示；Tiles 改为带独立 Index/X/Y/Z/Tile/Sprite/Matrix/Color/Flags 列的可调整列宽表格，表头固定，按可见行绘制，支持横向滚动。Tile/Sprite 引用列表也使用只读文本框，暂不支持编辑写回。
- Tilemap 系列属性区及 Tiles 表格取消交替行底色，与 SpriteRenderer 等组件使用一致的面板背景和文本框样式。
- 静态预览接入 Tilemap：优先解析保存的 TileSpriteArray，缺失时后台读取 Tile 资源的 m_Sprite；按父级 Grid 的 CellSize、CellGap、CellLayout、CellSwizzle，以及 TileAnchor、每格矩阵/颜色、Tilemap 方向矩阵和层级 Transform 重建。支持矩形、等距菱形、Isometric Z as Y；六边形及未知布局提示不支持，不进行错误替代绘制。
- 大地图共享纹理与 Sprite 切片缓存，每轮资源检查对同一路径只检查一次，剔除画布外图块，并在保持绘制顺序的前提下合并连续同纹理网格；大量图块选中时使用整体范围框。尚未实测帧率，不能视为已确认消除卡顿。
- Tilemap 预览为静态近似：不执行 RuleTile/自定义 Tile 脚本、动画、实例化 GameObject、自定义材质 Shader 或 Unity 的完整 TilemapRenderer 排序；缺失资源会显示诊断。格子及数组暂只读，原始数据可通过 YAML 查看。
- 静态预览画布改用与图片预览一致的 12 像素灰白透明棋盘格；浅色与深色主题采用相同底色，背景不随场景缩放或平移。
- 静态预览新增背景色切换：棋盘格（默认）、灰色（#808080，RGB 128/128/128）、自定义，分段按钮沿用主题切换样式；末尾色块通过 RGB 调色板编辑自定义颜色，背景始终不透明，不提供 Alpha 控制。选项与颜色保留在当前预览会话中，不写入 Unity 文件或跨重启保存。
- 增加 MeshRenderer 的结构化属性显示，包括材质列表和常见渲染设置；复杂或未识别字段保留原文查看。
- SpriteAtlas 增加结构化属性和列表表格显示，包括打包对象、已打包 Sprite、名称列表及平台设置。
- UI 文本预览尝试通过工程 GUID 引用加载字体，包括可定位到源字体的 TMP 字体资源；找不到或不支持时回退到软件默认字体。
