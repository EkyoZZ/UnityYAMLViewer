## 材质与 Shader 节点预览

- `.mat` Inspector 增加“节点预览”，保留属性和 YAML；`.shader` 增加节点 / 源码切换，默认节点模式。共用输入节点 → Shader → 平面输出的画布，支持拖动画布、滚轮缩放、选择输入节点。
- `.mat` 从项目索引解析 Shader GUID，读取 Properties 默认值后覆盖材质浮点 / 整数、颜色 / 向量、纹理绑定及缩放偏移；`.shader` 使用 Properties 默认值。索引 / Shader 缺失显示原因，可重载重试。
- 输入面板允许临时调整数值、颜色 / 向量、整数以整步调整、更换 2D 图片、调整纹理缩放偏移；“重置输入”恢复载入时状态，“重新载入预览”清除临时状态，按当前已载入文本重新准备（材质依赖 Shader 从磁盘重读）；文件级“重载”才重读当前文件。临时值与文件编辑会话隔离，不调用写文件或保存编辑接口；不同文件独立保留预览输入，关闭 / 重载文件清理；切换到其他节点预览时释放非活动预览的解码图片和待接收渲染结果，保留临时参数。
- 资源准备在后台进行，输入变更使用修订号丢弃旧任务结果，准备期间不继续显示旧参数渲染。Shader 与材质源各限制 2 MiB，最多 128 项 Properties，单张纹理最大 4096×4096 / 64 MiB，纹理总量最多 128 MiB。
- 复用严格 Built-in 单 CG Pass 翻译和 GPU 渲染，以白色顶点的 UV 平面预览，棋盘格背景显示透明区域；不包含场景光照、蒙版及自定义顶点流。独立 Shader 可使用内置兼容 include；其他 include 仍要求项目资源目录并使用既有边界检查。临时数值同时用于引用参数的渲染状态解析；纹理传入 ST 和 TexelSize，读取纹理 meta 的 Repeat / Clamp，镜像采样显示不支持。
- 不支持 Shader Graph 运算节点逆向还原与连线编辑。连线仅为实际参数绑定，不推测内部数据流。URP / HDRP、多 Pass、复杂宏 / 顶点输入、整数 / 非四分量向量 Shader uniform、非 2D 纹理、内置 Shader GUID 与缺失依赖可能无法渲染，显示诊断；GPU 编译失败不以普通纹理回退冒充结果。现有场景 / Spine 回退规则保留。
