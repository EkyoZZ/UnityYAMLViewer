## 功能概览

- Windows 独立 HLS 油猴助手与协议唤起；“打开 URL”支持网页静态 HLS 候选选择和视频提取兜底自动播放。
- 改进网页视频 Cookie 传递与解码、完整音频格式选择及方向键音量提示。
- 播放页支持紧凑缓存进度、取消及缓存文件定位；粘贴链接还原 Unicode 转义并保留百分号编码。
- 第三方支持提供油猴助手安装引导和 Greasy Fork 脚本页面入口；安装由用户在浏览器中完成，应用不检测浏览器扩展或脚本安装状态。
- 清理项目自身代码警告；第三方 spine38 警告仍保留。
