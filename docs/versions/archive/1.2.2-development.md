## 发布后新增：图片九宫格精简（2026-10-16，源码修改）

- 采用与设置等弹窗相同的 native_window 独立系统窗口，支持独立移动 / 调整尺寸、再次点击入口唤醒；原图与精简结果固定两列同屏显示，透明棋盘背景，四边九宫格线标注距边界的原始像素距离；同时显示原始 / 目标尺寸、总像素面积、节省面积与节省百分比。细长图的标注允许延伸到图片外侧，避免因图片只有几像素高而完全裁掉标注。
- 明确提供横纵双轴、仅横向（左 / 中 / 右三段）及仅纵向（上 / 中 / 下三段）模式；禁用不参与处理的边界和中心输入，并按实际结果突出标记双轴缩小、仅缩宽、仅缩高或没有缩小。自动扫描全图所有相邻完整列和行，逐像素比较 RGBA 四通道（透明像素的隐藏 RGB 同样参与），为无已有边界的图片选择最长连续完全重复区域；保留已读取的有效边界，可点击自动识别重新设置。
- 取消此前的近似采样方案。四角保持解码后 8 位 RGBA 像素不变；仅删除已证明 RGBA 完全相同的连续完整行列。手动边界同样必须通过检查，否则相应方向退回原尺寸并清零该轴边界，明确提示未删行 / 列；保存前再次独立核验像素安全性。渐变仅允许沿完全重复的另一个轴精简，非连续重复花纹不处理。可展开拉伸回原尺寸预览。编辑器统一使用 RGBA，异步生成结果，丢弃过期参数的预览；单个编辑器最多一个预览生成任务。
- 仅成功读取图片同目录、同名 UTF-8 .meta（最多 4 MiB）时显示相关信息；可识别的单 Sprite 边界带入编辑器。读不到或不存在时不提示修改，不创建 .meta。已读取的多 Sprite 图集、其他纹理类型或未识别格式明确标记不支持原位替换。
- 确认面板列出目标路径与尺寸，确认后原位覆盖图片；支持 PNG / TGA / BMP / WebP，JPEG 不进行有损原位编码，可另存新 PNG；APNG / 动态 WebP 拒绝原位覆盖，另存仅输出当前静态帧。重新编码不保留源图的高位深、ICC / EXIF 等附加信息。可读取且受支持的 .meta 一并更新根级 spriteBorder（x / y / z / w = 左 / 下 / 右 / 上）和 Full Rect（spriteMeshType = 0），保留 GUID、换行、BOM 与其他字段。Unity 重新导入后读取切片信息；不更改场景 / Prefab 的 UI Image Type，仍需使用 Sliced。不承诺自定义物理轮廓 / 图集等几何数据随图片缩小而正确。
- 按用户最终要求不创建备份，不新增工程旁临时文件。完整输出先写入软件记录目录的 image_edit_temp / 独立任务目录；替换前独占打开目标文件（Windows），核对原图解码像素和 .meta 文本是否与预览时一致。无法写入、锁定或外部更改时拒绝覆盖；发生可捕获写入失败时尝试用内存中的原始内容回滚。双文件写入不是断电事务，突然终止、断电或回滚失败需通过 Git 检查恢复。
- 完成或可捕获失败后清理任务临时文件；清理失败明确显示路径。缓存清理纳入残留 image_edit_temp，保存与清理共用互斥锁。不存放历史备份。替换后使当前页签的原始像素 / GPU 纹理失效并异步重载，重置平移与适应窗口；任务通过上下文刷新消息通知页签，保存期间全局重载或关闭后重开也读取磁盘结果。
- 另存 PNG 只创建新图片，拒绝覆盖现有图片或已有同名 .meta；不自动导出新 .meta。输入仍沿用单边 8192 像素和 256 MiB 解码分配限制；解码、精简、编码与替换在后台进行，GPU 上传仍在主线程。面积节省不等于压缩文件或 Unity 压缩显存的节省。
- README 中英文、当前版本关于摘要和新提示同步七语言；关于仍默认展示 1.2.1 / 1.2.0，旧版默认收起，重新打开恢复收起，保留历史摘要。

### 图片精简交互补充：透明边缘、4 倍数、Repeat 与三视图（2026-10-16，源码）

- 方向改为简洁的“同时 / 横向 / 纵向”tab（Both / Horizontal / Vertical）；新增“拉伸 / 重复”（Stretch / Repeat），默认拉伸。拉伸中心宽 / 高默认 4 px，允许手动调整，自动识别按钮恢复 4 px；安全区域不足时保留可用像素，不强行放大。显示实际保留中心尺寸。
- “保留边缘透明像素”“边长为 4 的倍数”默认勾选。保留透明边缘时，原始外圈 Alpha=0 行列不参与精简，全透明图不删除像素；取消后仅沿活动方向裁去 Alpha=0 外圈，隐藏 RGB 随外圈丢弃。边界输入投影到裁剪矩形，并约束在保留边缘内，极端数值不导致溢出。
- 对齐宽高时优先多保留完整重复像素 / 周期；不足以满足 4 倍数时，最多在右 / 下各补 3 个透明像素，纳入对应 Border。尺寸可能增加，面积增加时明确标示；不会通过重采样缩放像素。源高位深、ICC / EXIF 等附加信息仍不保留；裁去外圈或补白可能改变 UI 留白与对齐，须在 Unity 检查。
- 重复模式把完整行 / 列转为精确等价符号：哈希只用于查找候选，同哈希仍逐像素确认 RGBA，避免哈希碰撞误判。自动寻找含至少两个完整周期的连续区域，选取节省量最大的候选；随后用前缀函数求选定区域的最小周期。可独立设置横向 / 纵向保留倍数；不足一个周期的尾段归入固定边缘。对齐可能增加实际倍数，区域大小也可能限制输入倍数，均显示实际周期像素尺寸与实际保留倍数。
- 不通过检查的手动区域保留该方向全部像素及手动边界，不近似压缩。逐像素一致性仍包括透明像素的 RGB 与 Alpha。原位写入前重建相同请求的计划与像素，再核验磁盘资源未改变。重复区域自动搜索最多对单轴 8192 个符号进行二次复杂度比较，后台单任务执行，大图可能需要等待。
- 顶部左侧参数、右侧原图（只有透明棋盘背景，不画标线 / 遮罩）；下方左侧裁剪展示、右侧结果展示。裁剪图标注本次切分线及来源（像素自动识别 / 沿用已有边界 / 手动），可选叠加已成功读取的原始 .meta Border，绿色与本次黄 / 蓝线区分，列出原始数值。没有可读 .meta 时不显示修改 / 叠加提示，不创建 .meta。
- 裁剪展示半透明覆盖实际待移除像素，交叉区域只叠一层，不改变图片内容。默认从八个候选色按待移除区域采样的亮度 / RGB 对比评分选色，透明像素按棋盘平均背景估算；这是候选色中的平均对比优化，不是每个像素的理论最大对比。关闭自动选色后使用半透明红色（Alpha 135）。
- Repeat 裁剪保留前 N 个完整循环，白色框标出保留区域，内部白色虚线标记周期边界；其余连续冗余区域由半透明遮罩显示，不画成交替条纹。固定边缘 / 四角与不完整尾段保留。大量循环时每轴最多绘制约 64 条周期线，省略部分标记以限制预览负载。
- 还原预览在后台按 Stretch / Repeat 的实际映射生成有尺寸上限的静态预览，不为所有循环创建 UI 网格。Unity 中分别使用 Sliced / Tiled，仍只同步 .meta 的 Border / Full Rect，不改 Scene / Prefab Image Type。实际 Unity 网格数量取决于图集、Border、渲染规则等，不保证固定面数。
- README 中英文及当前关于摘要同步更新，保留默认当前 / 上一版与历史折叠逻辑；807 行七语言列数 / 非空值 / 唯一键 / 新界面覆盖与关于版本顺序、重开折叠静态核对通过。新增 / 更新 11 条回归测试覆盖最小周期、多倍循环逐像素还原、透明边缘、4 倍数与补白、RGBA 差异、极端边界、默认 4 px、遮罩不重复叠加、候选色对比、元信息保持与替换清理。
