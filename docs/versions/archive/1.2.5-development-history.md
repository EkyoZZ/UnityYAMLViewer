## 四方连续图（2026-10-20，本地源码，尚未发布）

- 图片预览新增独立“四方连续图”窗口，与九宫格精简入口相邻；SVG / GIF 不接入。两种模式共用原图、循环单元和 3×3 平铺预览，支持开关单元边框与 PNG 另存。
- 提取模式完整比较 RGBA，包括零 Alpha 下的 RGB；按行列前缀函数寻找能整除原图尺寸的最小矩形循环，不缩放或修补像素。错位和多图案顺序作为整体循环保留；不包含完整循环或无可缩减周期时明确提示，不自动修复接缝，不做近似判重或斜向晶格输出。
- 制作模式含原图最多 16 个图案，可追加或移除；提供单图案、A/B 交替、棋盘预设，或按编号自定义矩形排列（最多 16 × 16 格）。自定义只使用引用的图案，添加图案后需选择预设或修改编号；移除后编号顺次重排，非法编号阻止生成。
- 普通排列、逐行横向错位或逐列纵向错位，支持 1/2、1/3、1/4 逐行 / 逐列递进偏移；排列行列数与错位分母取最小公倍数，跨边界像素环绕到对边和角点。生成结果再次精确提取最小矩形循环。
- 支持统一 1%–400% 缩放（100% 保持像素；其他比例使用 Lanczos3）、横纵独立 0–2048 px 间距、按 Alpha 裁去透明边缘、透明 / 纯色背景。图案按最大尺寸居中于统一格子，间距为额外格子留白，不保证不同尺寸图案的可见边缘距离相同；错位轴格距向上补齐分母倍数，额外最多 3 px。无负间距、独立图案变换、自由拖放或自动接缝修复。
- 图案解码、生成及 PNG 写出在后台执行；生成期间禁止更改参数，修改后清除旧预览和可导出结果，来源重载时丢弃旧生成任务结果。输出单边最多 8192 px、总计 16777216 px，制作模式图案总像素同限；预览缩略图最长边最多 2048 px（原图对照 1024 px），导出保留实际尺寸。
- PNG 使用 create_new，仅允许写入新路径，已有目标（含原图及其硬链接）会报错；失败清理本次创建的不完整文件，不修改源图或 Unity meta。

- 验证：新增最小周期 / 隐藏 RGB / 非整周期、错位 / 图案顺序 / 边界环绕、间距 / 透明裁边 / 参数限制等回归用例；仅做 cargo check --tests --locked --offline 编译检查，不执行测试二进制。实际 GUI、七语言显示、历史展开收起及重开折叠、PNG 输出与真实素材效果均待运行验证。本轮未生成 EXE，未发布。
