# 1.3.8

已正式发布。Windows x64 附件采用姜饼人单面渲染实测通过的构建，已核对远端大小及 SHA-256。[发布说明](../releases/1.3.8.md)

- 2026-11-26 独立 FBX 单面剔除修复测试版已构建，版本和 SHA-256 已核验。用户实测姜饼人切到「单面」后，正面五官和装饰均正常显示。

- 修复独立 FBX 单面预览的正反面判定。坐标镜像后保留三角面索引顺序，使 Cull Back 剔除背面。编译检查通过，姜饼人正面细节已通过用户实测。

- 2026-11-26 材质槽对齐测试版已构建，版本和 SHA-256 已核验，界面对齐待实测。

- 独立 FBX 的材质槽按钮与贴图按钮使用同一行高，便于垂直对齐。「单面」对应 Cull Back，剔除背面。编译检查通过，实际对齐待实测。

- 2026-11-26 独立 FBX 左右对比测试版已构建，版本与 SHA-256 已核对。同步播放与切换动作关闭窗口待实测。

- 独立 FBX 优化草稿新增「左右同步对比」置顶窗口。原动作和草稿使用同一个模型、贴图和固定取景，左右按同一采样时间播放或单步定位，原模型预览暂停渲染。关闭后恢复当前位置，切换动作或移除草稿时自动关闭对比。编译检查通过，姜饼人实机对比待验证。

- 2026-11-26 材质槽按钮测试版已完成本地构建（版本 1.3.8）并核对 SHA-256。菜单及切换效果待界面验证。

- 2026-11-26 包含独立 FBX 播放控件和时间轴滚动区修复的本地测试版已构建，EXE 版本及 SHA-256 已核对。关键帧和曲线页的底部布局待实测。

- 时间轴轨道区固定在独立绘制范围内，曲线缩放或轨道滚动时，左右纵向滚动控件留在轨道区，底部横向范围条单独占位。编译检查通过，窗口实际布局待实测。

- 修复独立 FBX 时间轴弹窗底部被裁掉的问题。轨道区为顶部刻度和底部范围条预留高度，关键帧页使用常驻滚动条，曲线页保留右侧纵向范围控制。编译检查通过，窗口缩放和拖动待实测。

- 独立 FBX 动作列表新增与 Prefab 相同的图标播放控件，入口改名为「查看时间轴」。列表和时间轴共用播放、暂停、循环、定位和停止状态。编译检查通过，界面待实测。

- 独立 FBX 的设置箭头改为居中绘制，随模型工具栏移动。动作列表有文件时可直接打开「动画预览」。未选择动作时优先使用 @idle，其次使用列表首项。编译检查通过，界面待实测。

- 2026-11-26 包含独立 FBX 关键帧优化的本地测试版已构建，EXE 版本和 SHA-256 已核对。独立动作预览及实际保存待实测。

- 独立 FBX 模型的「动画预览」时间轴新增关键帧优化，目标为动作列表中选中的外部 FBX。后台生成草稿，显示实际减键数和最大曲线误差，可切换原动作与草稿的模型姿态和关键帧显示。绿色「原位替换」需确认目标路径并校验源 FBX 和可选 .meta 快照，现有 .meta 保留。蓝色「另存为」输出新 .fbx，拒绝覆盖现有目标。处理第一个 Take 的受支持平移和缩放曲线，独立预览按 FBX 文件单位换算平移误差。编译检查通过，姜饼人界面和实际写回待实测。

- 2026-11-26 独立 FBX 预览测试版已完成本地构建及版本和 SHA-256 核对。打开模型时自动扫描同目录，设置区的「识别同目录素材」按钮可再次扫描。姜饼人套件的实机验证待执行。

- 独立 FBX 模型页的左侧箭头可向右展开贴图与动作设置。按模型材质槽选择或拖入 TGA 等图片，点击已绑定的文件名可替换，减号移除。左键点击 mat0 等材质槽按钮可设透明／不透明和双面／单面，默认透明、双面。无光照主贴图用于预览。
- 自动识别同目录的同名或 _t 贴图及同名前缀的 @动作 FBX。动作支持多选加载、批量拖入追加、单文件拖到已有行替换、右键替换和减号移除。选择动作直接在当前模型上播放，独立「动画预览」用同一播放位置显示只读关键帧和曲线，提供播放、暂停、停止、循环和拖动定位。
- 外部动画 FBX 使用第一个 Take，按骨骼路径绑定。对平铺在根节点下的骨骼允许唯一同名匹配，并使用动作层级的世界姿态。坐标轴不匹配、所需蒙皮骨骼缺失或变换非法时显示错误并回到静态模型。外部设置仅用于预览。已核对姜饼人模型和四个动作的源文件层级，实际蒙皮、拖放、渲染和原生时间轴窗口待实测。

- 用户实测 FBX 原位写回通过，文件体积约由 870 KB 降到 533 KB，减少约 39%。截图显示 Unity 中已载入角色。Clip fileID 与 Animator 引用是否一致、另存为结果，仍待单独确认。

- FBX 时间轴显示源文件或候选文件中实际保留的位置、欧拉旋转和缩放关键帧。原始时间轴独立保留，关闭草稿预览或放弃草稿时直接切回。模型播放仍使用原有姿态采样。曲线视图按 FBX 原始键值显示，重叠时间合并，连线用于示意。编译检查通过，界面待实测。

- 修复 children@chase 等默认导入的单 Take FBX 无法打开的问题。Unity 已启用动画导入且没有显式 Clip 切分和 ID 映射时，预览与草稿沿用引用中的 fileID，并使用唯一 Take 的完整范围。多 Take 或存在显式映射时仍要求明确匹配。已核对源 .meta 与 Controller 引用，界面待实测。

- 修复 children@flying 等二进制 FBX 在文件尾已经对齐且仍含完整 16 字节填充时无法生成草稿的问题。已核对 flying 与 listen 的原始文件布局，界面保存待实测。

- 模型预览与左右同步对比的正交相机扩大近远裁剪范围，缩小时进一步延长可见深度。滚轮最小缩放从 5% 降到 1%，便于查看位移较大的动作。实际场景待验证。

- 2026-11-26 包含 FBX 原位替换、另存为和独立 .anim 保存的本地测试版已构建，版本和 SHA-256 已核对。实际保存及 Unity 重新导入验证待执行。

- AnimationClip 时间读数统一显示五位小数，并按动作时长预留宽度，避免播放时右侧的关键帧筛选按钮左右跳动。界面效果待实测。

- 左右同步对比的「预览问题详情」移到工具栏右上角，详情用浮层显示，避免提示变化时挤动下方画面。界面效果待实测。

- 原预览播放模型动画时，2D 正面视图与 3D 视图沿用已有的取景中心和比例。初次成功显示场景时建立取景，之后姿态变化不再触发自动居中和缩放。2026-11-26 本地测试版构建和 SHA-256 核验通过，影子实际播放效果待验证。

- AnimationClip 预览新增关键帧优化入口。可以设置阈值，生成内存草稿，比较预览关键帧数、最大曲线误差及同一时间点的模型动作。可关闭草稿预览或放弃草稿。
- Unity Clip 支持线性标量位置和缩放轨道，以及可确认切线为零的恒定轨道。FBX 从选中 Take 可验证的原始平移和缩放曲线减键，在误差阈值内以线性段近似。旋转、其他属性、跨 Take 共享曲线及超出 Clip 范围的曲线保持原样。
- 独立 Unity .anim 草稿支持绿色「原位替换」和蓝色「另存为」。原位替换需确认，保留原 .meta 并校验源文件和对象索引。另存为生成新的 .anim，已有目标文件会拒绝覆盖。编译检查通过，Unity 重新导入与界面待实测。
- 二进制 FBX 草稿用写回候选文件重新加载和预览，核对对象 ID 与关键帧数。绿色「原位替换」保留源 .meta，并在提交前检查 FBX 和 .meta 均与生成草稿时一致。蓝色「另存为」生成独立 .fbx，拒绝覆盖现有文件，由 Unity 为新资产分配 GUID。写入仅涉及目标曲线数组及二进制偏移和对齐。
- children@listen.FBX 的原始曲线已核对，405 条曲线各有 81 个键，间隔 1/30 秒。原 .meta 的 listen Clip internalID 为 1827226128182048838，new_children.controller 当前序列化引用同一 fileID 和 GUID c5e067bbbf80b4a44870d649c632e469。新增本地样本测试仅通过编译检查。原位替换、另存和 Unity 2022.3.62f3 重新导入后的实际引用仍待验证。
- 对照在后台采样原版和草稿，报告受控层级节点与已识别 FBX 挂点的最大世界位置偏差，并可通过播放和逐帧定位观察动作。误差统计基于采样时间点。
- 用户已在测试版中观察到草稿关键帧减少，提出需要同屏观察原动作已有的抖动。生成草稿后可打开置顶的「左右同步对比」独立窗口，两个画面的左上角分别悬浮显示「优化前」「优化后」。播放、暂停、循环、按原始采样帧步进与拖动时间轴都作用于同一帧，两个画面共用固定取景、旋转、缩放和平移。
- 对比窗口打开期间暂停原预览的场景绘制。手动关闭后原预览接回当前播放位置，切换动作时自动关闭旧对比。单独预览有草稿的动作时，左上角按实际显示的姿态标记「优化后 · 草稿」或「优化前」。
- 左右对比使用模型和精灵平面预览，Canvas UI 图形及独立粒子模拟不参与此窗口的动作对照。两个姿态同时就绪才显示，复杂场景准备较慢时，逐帧播放可能慢于原速。优化结果仍为内存草稿。
