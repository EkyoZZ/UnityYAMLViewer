## 九宫格图片精简

- 独立原生编辑窗口逐像素验证完整 RGBA（包括透明像素隐藏 RGB）；自动比较横向 / 纵向 / 同时与 Stretch / Repeat 六种组合，按实际输出面积选择，可手动调节边界、中心及循环倍数。
- 中心默认 4×4，默认保留透明外圈、宽高对齐 4 倍数。对齐优先保留额外重复像素 / 完整周期，必要补白两侧分配，奇数多加右 / 下；补白不计入 Unity Border。
- 设置 / 信息、裁剪 / 结果左右等宽，参数高度紧凑、信息独立滚动；裁剪区半透明对比色与斜纹标出移除区，Repeat 保留循环框 / 周期线，像素尺寸位于边界标签下方圆角底衬。展示面积收益及默认收起的诊断详情，异步计算期间保留上次预览并禁用保存。
- 确认后原位替换，无持久备份；软件记录目录临时文件处理完成清理，原页签自动重载。另存 PNG 拒绝覆盖已有目标。
- 同位置 .meta 可读且为支持的单 Sprite 时同步 Border / Full Rect，保留 GUID 与无关设置；缺失 / 不可读不创建 meta，可读不支持则禁用原位替换。写前复核磁盘图片与已读 meta 未被外部修改。

## 指令与预览

- slice9 支持单张、多张、目录、-r 递归、--dry-run、中心 / 循环倍数 / 方向 / 模式 / 透明外圈 / 对齐参数、JSON 报告与退出码；默认仅在面积减少时原位替换，单张失败继续其余批次。
- --preview 打开完整可编辑 GUI，并自动识别，不自动写入；最多同时 10 个窗口，路径去重，重复请求唤醒原窗口、不重置用户输入，超出提示不排队。与 dry-run / report / 显式方向、模式不同时使用，打开后窗口全部原有功能仍可操作。多窗口切换页签保持运行。
- 原有单文件 / 多文件直接打开指令不变；预览请求可转发已有 GUI。主窗口“格式支持”旁提供“指令查看”，不重复添加文件菜单入口；独立帮助含复制、打开示例和路径引号说明，--help / slice9 --help 与 README 同步。
- 普通鼠标 / 任务切换恢复弹窗焦点不再重新定位；首次打开或程序按钮唤醒仍对齐主窗口。

## 限制

- 原位支持 PNG / TGA / BMP / 静态 WebP；动画拒绝，JPEG 可在编辑器另存静态 PNG。8 位 RGBA 输出，不保留额外图像元数据；输入单边最多 8192，解码分配 256 MiB。精确重复搜索为单轴二次复杂度，大图和多窗口可能耗时并占用较多内存。
- 裁透明外圈或补白会改变留白；面积节省不等于 PNG 文件大小或 GPU 压缩显存节省。Unity UI 的 Sliced / Tiled 需手动设置，不改场景或 Prefab；实际网格数不保证。
- 图片与 meta 双文件写回非崩溃原子，批次无整体回滚；失败时停止该图片并报告，必要时通过 Git 恢复。CLI 无收益不写 meta，报告写失败可能已有部分资源处理完。
- 命令行帮助正文为英文，GUI 标题 / 操作提示七语言；Windows GUI EXE 在 PowerShell 中可靠等待与获取退出码使用 Start-Process -Wait -PassThru，示例见 README。
