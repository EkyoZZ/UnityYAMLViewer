## 新增功能

- **本地自动字幕与实时识别**：SenseVoice 支持普通话、英语、日语、韩语和粤语，可生成本地视频 SRT；播放时提供 SenseVoice 分句识别与 Zipformer 中英流式识别。实时 SenseVoice 默认自动语种，翻译跟随实际识别语言。
- **离线／实时字幕翻译**：统一使用 M2M100 INT8，支持中英日韩之间翻译与双语显示；文件翻译保留时间码，实时原文和译文独立更新，可切换是否显示原文。最终版本已移除 Moonshine 和 OPUS-MT 入口。
- **实时字幕缓存与提前处理**：已确认字幕可缓存、导出 SRT，并在匹配的点播会话复用；本地视频及经核验的 HLS 点播支持约 20 秒窗口内提前识别、提前翻译，到对应播放时间再显示。
- **独立字幕编辑器**：支持 ASS／SSA／SRT／WebVTT 原格式编辑与保存、常用格式转换、查找替换、批量平移、句子拆分／合并、基础样式、视频预览和时间轴对时；内嵌文字字幕可按原格式提取，也保留默认 ASS 提取入口。可交接字幕草稿进行画面烧录。
- **Windows 录屏**：支持单屏、多屏和指定区域，窗口吸附或鼠标拖拽选区；直接按预设质量编码 MKV／MP4，自动以时间戳命名保存到系统下载目录，无序列帧缓存。默认可录制系统声音，不采集麦克风。
- **录屏操作与历史**：自绘悬浮工具条、绿色选区、区域移动与八个缩放手柄；可记忆的停止／选区快捷键，录制前 Esc 退出。全屏录制隐藏工具条，结束恢复并提供编辑与打开目录。独立历史默认 20 条、上限可设 20–50，文件缺失标红，移除记录不删除视频。
- **共用错误日志**：error.log 汇集录屏阶段、声音／编码错误、后台任务失败、已接入的运行库警告／错误和 panic；录屏错误窗口持续显示，可复制错误或打开日志。

## 对已有功能的优化

- **字幕显示与样式**：自动发现同目录字幕并按语言匹配；样式可记忆、预览和取消恢复，支持统一样式／原生 ASS、顶部／底部定位及独立 X/Y 投影。修正边距字段、宽度测量和换行，长句分段显示；切换字幕时保留画面，修复全屏时实时翻译停止更新及日语被错误当成国语透传。
- **字幕导出与编辑体验**：MKV 单项／队列导出可保留 ASS 样式，也可烧录到画面。编辑器提供横屏／竖屏布局，优化播放控制、选中定位、控件间距与窄窗口换行；字幕时间轴浏览条与视频／音频编辑共用比例滑块。
- **视频播放与编辑性能**：播放和视频编辑复用 GPU YUV／RGBA 渲染，支持透明预览；适应窗口时按实际显示尺寸限制普通视频预览帧，提前丢弃过期帧。持久化帧时间索引加快重复打开，修复播放终点取帧越界；暂停时左右键逐帧，Ctrl+左右键平移时间轴。
- **图片预览**：默认平滑采样与多级缩小过滤，也可选择像素模式；100% 按屏幕物理像素一对一显示并对齐像素，修正高 DPI 下额外放大。
- **AI 组件与资源使用**：识别运行库可独立安装 CPU／GPU 版本并选择使用；统一 GPU 优先与 CPU 回退线程设置，补齐共享 GPU 动态库。改进模型下载续传、校验、阶段提示、日志编码和占用时修复流程；实际 GPU 使用仍取决于组件和设备支持。
- **录屏稳定性与工具条**：修正系统声音写入暂时不可用（10035）被误判为失败的问题；保留待写数据并重试。修复工具条透明外圈黑底，收紧宽度、改善图标清晰度、字段与提示字号，并统一历史上限滑条样式。

## 限制与暂缓事项

- **中央大数字倒计时**：已存在实现，但用户在最新构建中未看到数字；按用户要求暂不调整，不列为已验证功能。本轮不修改倒计时代码。
- 录屏需要 FFmpeg／FFprobe，捕获排除依赖 Windows 10 2004+；缺组件时提示并引导到第三方支持。暂不支持麦克风录音、录制暂停／继续或自动跟随系统音频设备切换。
- AI 运行库和模型需按需安装，首次下载需联网；识别及翻译质量需要人工校对。Zipformer 当前限中英，M2M100 当前开放中英日韩；点播缓存复用有媒体身份与 HLS 清单限制，直播不按点播方式跨会话复用，自动合并／校正字幕仍暂缓。
- WebVTT 预览不完整还原 CSS／定位；其他格式暂不转换为旧 SSA，复杂 ASS 特效主要通过原始标签编辑。图像字幕 OCR、字体附件提取和完整高级特效可视化尚未实现；合并 ASS 轨与跨裁剪点动画存在原记录所列限制。
- GPU 渲染不等于所有格式硬件解码或零拷贝，不承诺固定 CPU 降幅；共用日志也尚未接入每一条旧错误分支，不能保证记录强杀或原生崩溃。
