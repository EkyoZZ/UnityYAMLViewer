## 主要新增：目录浏览模式

- 拖入目录或通过“文件 → 打开目录”加入左侧目录树，支持多个根目录、刷新与移除；展开时后台读取子目录，目录优先、名称不区分大小写排序。跳过符号链接、目录联接及其他 Windows 重解析点，不实时监视文件系统变化。
- 根目录标题有适配深浅主题的淡底色与小号设置齿轮，同时保留右键菜单。可为每个根目录独立设置忽略显示规则，如 `*.meta;*.tmp`，支持 `*`、`?`，文件名匹配不区分大小写，作用于该根目录及其所有子目录；只隐藏文件，不删除文件，不影响其他根目录或已打开标签。
- 根目录列表、顺序及忽略规则自动保存，启动恢复；离线或找不到的目录保留记录，展开时提示读取失败。移除全部根目录后侧栏隐藏，下次启动也不恢复已移除项。展开状态、滚动位置和侧栏宽度暂不跨重启保存。
- 默认宽度 230 逻辑像素，可拖动分割线调整，最小 140，手动上限为窗口宽度 80%；长名称单行截断，悬停显示完整路径，不因最长名称自动撑宽。
- 目录预览使用独立页签，固定最左侧并显示实际点击所属的根目录名称；普通文件名继续显示在查看区。连续打开目录文件复用预览，不累积标签；已有普通标签则直接激活。
- 未保存的属性修改或播放列表修改会将目录预览保留为普通页签，继续按既有同类型规则合并；下一目录文件使用新的独立预览。已有编辑会话也受保护，普通入口显式打开可将预览保留。
- 从目录树打开文件不新增或重排最近打开；普通文件打开入口仍记录。同目录切图保留多图列表、扫描任务、缩略图缓存与浏览模式；快速连续点击取消过期目录请求，不取消已有普通打开请求。

## 主要新增：多图浏览模式

- 图片可切换单图查看与多图浏览。底部固定缩略图栏与主图分区，支持点击缩略图、前后按钮以及四个方向键：左／上为上一张，右／下为下一张；首尾不循环，输入控件占用键盘时不切图。
- 主图悬浮信息显示当前序号／总数；透明缩略图显示棋盘背景，所有图片保持正常亮度，当前项使用向内绘制的 3 逻辑像素主题蓝色线框，悬停显示完整路径。浅色主题底栏使用面板底色。
- 非递归扫描当前目录的 PNG／JPEG／TGA／BMP／WebP／ICO／PSD；不包括 GIF／SVG。缩略图按可见需求后台加载，最多缓存 192 项，达到上限后逐项淘汰；错误项显示标记及悬停原因，不阻断其他文件浏览。
- “图片预览”设置新增默认多图浏览、默认适应窗口显示开关，两项均默认开启并持久化；关闭适应窗口后，新建普通位图／ICO／PSD 预览按 100% 打开。已存在预览的手动缩放不被修改设置强制覆盖。原预览设置更名为“Unity 资产预览”，末尾两项仍依次为撤销步骤与检查更新。

## 查看能力补充与优化

### ICO／PSD 只读预览

- ICO 可只读查看解码器选择的一幅内部图像，支持透明背景、缩放、平移、通道及多图浏览；暂不提供内部多尺寸切换。
- PSD 可只读查看文件保存的合成图，支持版本 1、8 位 RGB／灰度、Raw／RLE、最大 8192 × 8192；按合成透明度标记读取 Alpha。暂不支持 PSB、ZIP、16／32 位和 CMYK／Lab／索引等模式，不重建图层或应用 ICC 色彩管理。
- ICO／PSD 不开放九宫格、序列、四方连续图等图片编辑扩展工具，不加入材质纹理拖放类型；不写回源文件。PSD 缩略图需先解码合成图，大文件首次加载仍可能较慢。

### Spine 预览

- 默认动态预览，有动画时从首个动画的时间 0 开始，以 1 倍速循环播放；可暂停或切换静态，无动画时保留初始姿态。
- 普通预览新增默认开启的“预乘 Alpha”，位于辅助线之后；已预乘贴图直接提交，避免再次乘纹理 Alpha。关闭后按未预乘输入转换，切换不重读贴图或重置动画、相机。该状态按实例保留，新实例默认开启。
- Unity 材质 GPU 预览继续遵循材质 Shader 与混合规则，正常材质预览时该开关禁用；普通预览或 GPU／姿态回退时可用。保留源像素用于切换会增加内存，仍沿用既有贴图尺寸和像素总量限制；不改变场景烘焙行为。
- 修正 Windows 扩展路径、UNC 路径在 Spine 图集贴图拼接时混用分隔符导致的加载错误，保留 Unicode 与长路径前缀。
- 辅助线使用紧凑开关，紧跟背景色；材质／回退提示位于设置和重载下方、预览框上方，使用普通文本颜色并提供七语言说明。Spine 版本及特殊混合、双色染色等既有限制不扩大承诺。

### 布局、清晰度与交互

- 图片、SVG、PDF、模型、Spine 及静态预览的悬浮缩放比例可点击，向上展开半透明比例菜单（10%～300%）；菜单按实际文字宽度布局并与比例文字居中对齐。
- 修复图片棋盘背景裁剪后取整越界和窗口缩放时边缘露出的浅色细线，主图原点对齐物理像素，不修改源图像素或插值算法。
- 目录侧栏延伸至原页签区域，目录标题与页签等高，去掉多余分隔和间距；滚动区域延伸到底部，使用固定宽度滚动条，与侧栏拖宽命中区分离。
- 目录层级线只绘制可见部分，按物理像素对齐，改善长目录滚动时的线条闪烁；根目录设置说明、示例颜色与移除文案明确区分隐藏文件、移除浏览项和删除磁盘文件。
