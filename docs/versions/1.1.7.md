## 新增与改进

- 视频全屏播放：底部四角矢量图标、F11 切换、Esc 退出；纯黑背景，顶部居中悬浮三种缩放模式及比例，底部悬浮播放、停止、音量、进度与退出图标。
- 全屏鼠标静止 1 秒后隐藏悬浮控件和指针，移动后恢复；鼠标按住操作时保持显示。上下浮层为约 50% 不透明度的黑底，浅色主题下也使用深色控件。
- 视频支持适应窗口 / 原尺寸 / 自由缩放。自由缩放支持鼠标锚点滚轮缩放和平移，并以按下以来的最大位移区分点击与拖动：小于 5 个逻辑像素时松开切换播放 / 暂停，达到阈值后只平移，即使返回起点也不触发播放切换。
- 全屏所有倍率及普通窗口 100% 时将视频左上角对齐物理像素边界，减少居中时半像素偏移造成的额外模糊。
- 音频、视频及全屏支持无修饰键空格播放 / 暂停；输入控件需要键盘时不接管，忽略长按重复事件。
- 音频每个声道增加 2 个物理像素宽的白色峰值线：电平上升立即跟随，下降以每秒 5 dB 缓慢回落，暂停后继续回落至当前电平。
- FFmpeg 每次检测读取最新用户 / 系统 PATH，并搜索 WinGet Gyan.FFmpeg 的实际包目录，减少安装后必须重启才能识别的问题。
- 设置确认 FFmpeg 与 ffprobe 就绪后，关闭设置自动重新探测当前失败的媒体页；不重载正常播放的媒体或自动开始播放。

## 限制与验证

- FFmpeg / ffprobe 仍为外部依赖，不内嵌。媒体格式及硬解能力依赖安装的 FFmpeg 和设备；字幕渲染、HDR 输出、精确声卡时钟同步仍未实现。
- 电平及峰值拖尾来自既有重采样、分列的源音频近似峰值，不是声卡实时电平或响度分析，不受播放音量影响。
- 非整数缩放仍有插值；100% 沿用逻辑尺寸定义，高 DPI 下不宣称物理像素一对一。
- 用户已确认最近一次 FFmpeg 安装及关闭设置后自动刷新媒体页的流程正常。更早首次安装失败缺少日志，未确认唯一根因。
- 既有编译检查通过，部分 UI / 动画效果经用户试用调整；未执行本版完整回归或自动测试运行。不同 DPI、全屏切换及跨文件边界交互仍保留验证限制。
- 统一 Shader 渲染系统、粒子模拟与场景整体动画仍未实现；Spine / 模型范围沿用此前版本。
