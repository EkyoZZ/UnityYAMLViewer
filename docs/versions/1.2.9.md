## 本版主要能力与限制

- Windows 关联文件独立图标、打开方式名称与启动后台登记更新；默认程序仍由用户选择。
- 多图切换保留旧画面，邻近图片预加载与约 64 MiB 额外缓存；用户已验证实际浏览效果，异常与预算边界不视为全面验证。
- LibreOffice 只读分页预览、外部编辑入口和完整 PDF 另存；分页预览依赖 LibreOffice 与 PDFium，不能在内置预览中编辑或选择文字。原生 PDF 不显示该另存按钮。
- WinGet／Scoop 安装器切换、Scoop 按需安装、安装阶段显示、重复任务保护及已确认 WinGet 下载阶段的取消重试；Scoop 网络失败按实际错误提示，不能保证公司网络连接。
- XLS／XLSX／ODS 原生只读数据表格，多工作表底栏、搜索复制、公式／缓存结果、类型与可选必填检查；不重算公式、不还原完整样式、合并或图表。
- 行列坐标默认固定，可选冻结数据表头优先读取 XLSX 原冻结行列，否则首行回退；按需滚动条、边线、遮挡及底栏间距调整。原冻结元数据仅支持 XLSX；最新边线与保存交互仍待实际界面验证。

## 发布后源码优化：相邻图片预加载与缓存（2026-10-30）

- 多图浏览保留前后各最多 4 张的邻近图片，按距离优先、同距离先下一张的顺序预加载常见位图（PNG／JPEG／TGA／BMP／WebP）。完成解码、通道转换和纹理创建后，命中缓存的切换直接使用现成纹理，不必重新读文件、解码和上传。PSD／ICO 保持按需加载，但已访问的邻近图片可复用缓存。
- 邻近额外缓存按原像素、显示像素和 GPU 纹理合计约 64 MiB 控制，优先保留较近图片；当前图片、加载期间的旧画面、独立编辑工具和解码器内部临时内存不计入该预算，因此它不是整个程序的内存上限。后台先读尺寸，超出剩余预算的图片不预加载，用户选中后仍按正常预览限制加载。
- 同时保留一个后台预加载接收任务；切换到正在预加载的目标时复用任务。快速跳转后，过时预加载结果不展示；相邻范围外资源按原有编辑工具保留规则清理。预算跳过或预加载失败不作为当前图片错误，选中后可走前台加载；已缓存的外部文件修改需通过重载刷新。
- README 中英文能力与关于当前版摘要七语言同步。默认两版展示、历史展开／收起及重开折叠逻辑未改。
