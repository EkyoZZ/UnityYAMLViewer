# 1.1.3 功能记录

历史补录，依据 README、HANDOFF.md 和后续提交。区分初始发行功能与同版本后续源码修正，避免假设旧 EXE 已包含全部修改。

## 新增功能

- Prefab 静态 2D 预览：SpriteRenderer 源图与切片、pivot、PPU、颜色、翻转及层级变换。
- 部分 UI 预览：Image 普通、九宫格和横纵填充，RawImage、Text/TMP 静态文字，RectTransform 布局与 CanvasGroup 透明度。
- 预览选择对应组件，层级双击居中，节点可见和可选开关；支持拖动、缩放及适应窗口。
- 命令行多文件、中文及相对路径打开，Windows 已有实例接收文件并请求激活窗口。

## 同版本后续源码修正

- 更新发行说明中的 Markdown/HTML 图片预览与加载失败链接。
- 更新确认弹窗尺寸、说明换行与按钮布局，以及手动打开发布页面的失败入口。
- 这些修正是否包含在具体发行附件中，需以该附件实际构建为准。

## 限制与验证

- 以静态 2D 为主，不支持 Spine 与 3D；动态布局、遮罩等未完整支持。
- 历史记录显示 release 构建通过，部分预览已有用户截图验证；在线升级完整流程仍需实测。
