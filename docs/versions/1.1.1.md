# 1.1.1 功能记录

历史补录，依据 README 和 HANDOFF.md。

## 新增与改进

- 优化浅色、深色与系统主题配色、设置排版、滚动条位置和编辑状态提示。
- 支持简体中文、繁体中文、英语、日语、韩语、德语、法语，即时切换并保存偏好。
- 增加 AnimationClip 时间轴和曲线编辑：缩放、框选、多选拖动、按帧吸附、插值加帧、删除、切线及权重调整、撤销与保存。
- 动画分量配色和 End 标记；移动关键帧时按整体时间更新结束范围。
- 材质按 Shader Properties 声明区分 Color 和 Vector4。

## 修复与限制

- 修复 Context 数据嵌套锁导致的动画属性点击卡死。
- 独立存储的分量不再因同时间自动联选；实际共用运行时向量时间字段的分量仍联动。
- 删除关键帧不主动缩短 m_StopTime；ShaderGraph 和内置 Shader 类型尚未完整解析。

## 验证

- 历史记录显示编译检查和 release 构建通过，用户验证过部分交互。
- 测试源码仅做过编译检查，不代表断言已执行或全面回归通过。
