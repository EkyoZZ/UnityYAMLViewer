## 序列拆分与制作

- 新增独立序列窗口，提供拆分序列与制作序列；统一背景、缩放、平移、适应窗口、格子选择、单帧播放、帧率与循环设置。
- 拆分支持行列网格、透明间隔智能识别和 Unity Multiple Sprite meta 实际切片；整数边界保留所有像素。
- 可分别忽略上、下、左、右补边，采用“忽略补边：上、下、左、右”紧凑输入；可将帧居中透明补齐至宽高 4 的倍数。
- 支持跳过全透明空帧，默认关闭；预览、PNG、GIF／视频转换同步跳过并连续编号。仅最终 Alpha 全零判为空帧，微弱可见内容保留；相同 FPS 下跳过会缩短动画时长。
- 拆分可设置文件名前缀、分隔符、编号位数及起始值，实时检查非法文件名；导出至新目录并通知保存位置。
- 制作支持当前图片、拖入多图、自动加入同目录同组序列、自然排序、调序与删除；矩形优先或无空格排列，手动行列联动。
- 支持共同最小尺寸裁剪、宽高与百分比联动缩放、水平／垂直间隔、最终格子居中和右下透明对齐补白；初始尺寸为原图 100%。
- 合成 PNG 可同步导出 Unity tpsheet，记录实际图片矩形、名称和中心 Pivot；Unity 侧需对应 TexturePacker Importer。
- 制作与拆分均支持撤销／重做（Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z），包括拖入、删除、调序及参数修改；沿用撤销步数设置。撤销不删除已导出文件或改变已打开的转换快照。

## 去底色与动画转换

- 制作与拆分共用取色去底、容差、边缘柔化、底色去混合及容差遮罩预览；吸管提供操作提示、候选色值、取色光标与 Esc 取消，色块可打开调色板。
- 去底色适合纯色背景；相同颜色的主体也可能被移除，边缘去色不能恢复原先已丢失的细节。
- 序列可转 GIF／视频：先缓存处理后的 PNG 帧和无损中间视频，再复用视频编辑；默认 FPS 取序列播放设置。
- 首帧、定位和播放直接读取缓存 PNG，修复中间视频预览黑屏；透明区域显示棋盘格。转换使用独立快照，后续修改序列不影响已打开的编辑窗口。

## GIF、视频与 PNG 序列

- GIF 可以进入视频编辑并转为视频；GIF 与视频均可沿用时间选区、尺寸裁剪、缩放及帧率导出 PNG 序列。
- PNG 序列输出至新目录并连续编号，保留 RGBA；不携带音频、字幕、帧时长或循环元数据。中途失败可能保留已完成帧。
- 完善已有 GIF 导出：独立帧率、循环次数（0 为永远）、可选颜色压缩和缩放滤波器；帧率改变通过抽帧／补帧保持选区时长。
- 缩放滤波默认 Bicubic，抖动默认 Sierra2 4A；保留其他算法选择。GIF 导出、调色板和抖动选项在旧版本已存在，不重复记为新增。
- 完善透明调色板、透明补边及可选底色；当前不支持透明的导出视频编码通过底色合成。
- 修复选区终点预览边界：播放结束及跳到终点停留于保留片段最后一帧，不显示下一帧；原有 GIF 导出选区结果本身正确。
- 音视频／GIF 导出允许确认覆盖已有文件，先完成临时文件编码再替换；失败保留已有文件。PNG 序列仍要求新目录。

## 其他优化与暂缓内容

- R／G／B 单通道新增默认关闭的“应用 Alpha”，显示通道乘透明度的灰度，不修改源文件。
- 第三方支持可手动指定并保存 FFmpeg、FFprobe、PDFium DLL 路径，支持恢复自动，手动路径优先，无需修改 PATH。
- 四方连续图另存按钮高度改为 32，固定三列标题栏高度，使最小循环与平铺预览图片顶部对齐。
