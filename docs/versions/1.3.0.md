## 当前主要能力与限制

- 文本／代码预览可保存字号、行间距和段落间距，重载移至文件名后。
- Markdown 原生排版／源码切换，兼容常见 HTML 标题、强调、段落、居中与图片链接；蓝色下划线链接、标题分割线、多徽章与 SVG 文字、代码着色和复制、单边框及框内至少4像素内距。不是完整浏览器，不支持完整 CSS／HTML 布局；标题 strong 不是完整粗体字体系统。
- Windows RTF 通过 RichEdit 直接只读渲染，支持缩放与复制全文，不再依赖 LibreOffice／PDFium；固定 A4 分页，复杂排版、OLE 和页眉页脚等不保证完全还原，页面内不能选择／搜索文字。
- 图片源信息包含格式、尺寸、源位深、文件大小、可读水平／垂直 DPI 和 PNG iTXt 大小。仅确认所有像素完全不透明的 PNG 可去 Alpha；iTXt 大于0即可清理。原位替换、自动刷新与会话撤销／重做，不修改 .meta；PNG/JFIF以外密度不保证可读，不支持APNG去Alpha。
- 移除 Scoop／WinGet 接入，内置下载器按需获取 FFmpeg Windows x64 GPL Shared、LibreOffice；PDFium沿用直接下载。显示字节进度与阶段、SHA-256校验、失败可复制URL；Shared完整解压，自动查找优先PATH，手动路径优先，用户可点击加入用户PATH。
- 第三方组件标题行显示绿框已安装／红框未安装、绿框安装按钮及同排重新检测，PDFium移除和LibreOffice选择程序同排。
- 手型仅限制预览选中，Hierarchy／组件仍可选中；修复表格固定行号分割线，CSV／TSV／PSV从1编号。
- 清理主程序8条编译警告，第三方Spine仍有既有警告，不将编译通过视作全面回归通过。

## 发布后源码改进：Markdown 排版与图片缓存（2026-11-03）

- Markdown 默认以 CommonMark／扩展语法排版，保留源码切换；覆盖标题、强调、列表、表格、链接与代码块。增加常见 HTML h1～h6、p、div、br、a、img、b／strong、i／em 的兼容转换，注释不显示，代码中的标签保持字面内容。不是浏览器，不执行脚本，不支持完整 CSS、HTML 表格或所有网页布局。
- 图片按文档位置解析本地相对路径，HTTP(S) 图片后台下载；完整 URL 的 SHA-256 作为缓存键，保存在 network_cache/markdown_images，纳入现有清理缓存。相同网址优先读取缓存，不自动刷新；本地图片直接读取、不复制到下载缓存。每资源 16 MiB、每文档最多 32 个资源、最多四个同时加载，失败显示提示。重载重新读取本地资源并重试失败下载；已缓存网址内容需清理缓存后重开文档才能刷新。

- 排版视图继承阅读字号与段落布局设置；源码保留精确的行高调整。排版视图的自动折行行距不保证与源码行高完全一致。RTF 已由现有办公链路支持，只读分页依赖 LibreOffice 与 PDFium，本轮未新增原生 RTF 编辑器。
