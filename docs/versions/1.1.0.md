# 1.1.0 功能记录

历史补录，依据仓库 v1.1.0 标签的 README。本记录包含该版本已有能力，不将所有基础能力视为本版首次新增。

## 功能

- Unity 文本序列化资源查看：GameObject 层级、Inspector、多标签、搜索、GUID/fileID 复制及启动恢复标签。
- 常见资源结构化导航、YAML 列表表格、AnimationClip 曲线查看和 Animator Controller 只读关系图。
- 根据工程脚本字段声明显示 MonoBehaviour 属性，支持常见标量、枚举、向量、颜色及列表。
- 显式进入编辑模式，支持已识别属性和表格编辑、修改高亮、单项还原、撤销及保存。
- 保存前验证类型、引用与外部修改，通过临时文件替换写回 UTF-8；未知字段和原始 YAML 保持只读。
- 浅色、深色、系统主题与可配置撤销容量。

## 限制与验证

- 面向文本 YAML；复杂序列化、DLL 脚本及歧义字段不保证识别。
- 补录依据文档，未重新运行该历史版本验证。
