## 独立音频剪切与播放

- 主播放页顶部“剪切/格式转换”打开独立原生窗口，立即停止来源页签的播放并清除待自动播放 / 连播标志。新窗口从 0 秒暂停状态开始，初始音轨与音量来自来源，之后各自独立，不改来源播放位置、音量或播放历史。
- 窗口由应用全局维护，切换或关闭来源页签后仍保留；不同文件可以同时打开、独立播放。规范化完整路径去重，同一文件再次点击唤醒已有窗口，不重置输入。关闭一个窗口仅释放其播放 / 波形任务，不影响其他窗口；退出程序结束全部窗口。
- 音频标题“剪切/转换音频 - 文件名”，按语言本地化，中文不附加英文括注；窗口内容不再重复文件名或文件大小。
- 复用源音频信息、单 / 双声道波形、电平、时间尺及黄色播放游标。电平为源包络近似值，不是音频设备输出测量。
- 两条绿色细线标出保留范围，相向实心箭头与黄色箭头同尺寸；遮罩为 30% 不透明黑色。头尾模式遮住两端，左键设置起点、右键设置终点；边界和绿色箭头可拖动，头尾模式限制起点早于终点，最小间隔为 1 毫秒或媒体时长。区间模式见下方新增编辑功能。
- 波形普通点击不触发播放 / 跳转；黄色游标仍可拖动定位。绿色边界悬停 / 拖动时仅限制误操作，不隐藏时间刻度、网格、黄色播放竖线或箭头。
- 顶部工具条常显：导出参数；头尾 / 区间 Tab 和剪切、淡入、淡出、音量(dB)、撤销 / 重做；起止秒数与当前位置标记；重置范围、跳到起点 / 终点。范围数值行过窄时横向滚动，无展开 / 收起；其他工具行可随翻译换行。
- 底部固定为播放 / 暂停、剪切播放、停止、音量、时间轴；波形填满中间剩余空间并随窗口宽高变化，控制区与波形间只留标准间距，无额外分隔线。进度条填充且时间居中。
- 播放 / 暂停、停止使用主播放页同一按钮绘制函数；剪切播放图标沿用 Next 实心三角与右侧圆角竖线，仅增加同款左竖线，保持内容实际比例。剪切播放从绿色起点开始，到终点停止。
- 音量使用原播放页悬停弹出的竖直控件，点击切换静音，移开延迟关闭；只复用样式，音量状态独立且不影响导出文件。

## 头尾 / 区间、淡入淡出、dB 与编辑历史

- 头尾 / 区间使用 theme::compact_selector，与主题切换相同的分段 Tab 样式。头尾保留中间；两种模式均为左键设起点、右键设终点，箭头方向和拖动柄位置一致。区间允许边界交叉，使用 min(起点, 终点)～max(起点, 终点) 作为实际选区，遮罩覆盖该区间，剪切时删除中间并连接两端；不再按可能重叠的两端并集取值。淡入 / 淡出与时长限制也统一使用实际选区，不因起终点数值反向而禁用。边界重合等于不删除；拒绝删除全部音频，报告错误且不提交。
- 选择阶段仅显示遮罩，点击“剪切”后才异步生成新音频版本，移除相应波形并缩短时间轴。成功后回到头尾模式、全范围选中，避免已应用的区域继续显示为待删除。头尾剪切播放试听中间；区间剪切播放跳过中间试听两个保留区，已提交后普通播放读取新缓存。
- 淡入、淡出分别弹出独立设置窗口，提供时长与线性 / 平滑 / 等功率曲线。时长之和限制在当前选区内；选区外保持原幅度，未实现交叉淡化。中间区间在边缘淡至静音时可能与区间外声音产生跳变，不能等同于接缝平滑。
- 音量(dB)弹窗设置当前选区增益；未选范围时作用于本编辑阶段的整段当前时间轴（只包含剪切后的保留内容，不涉及原文件或已删除部分），范围 -60～+24 dB，± 按钮步进 1 dB，可手动输入和重置 0；不等同于底部仅试听音量。正增益提示可能削波，不自动归一化或限幅。
- 设置弹窗内实时更新包络波形预览，使用现有峰值采样近似；确认后异步刷新实际缓存音频和重新生成波形，取消 / 关闭设置窗恢复预览前参数。确认操作期间禁用新编辑；不承诺样本播放时实时更新效果。编辑完成或历史版本切换会停止当前试听，播放定位按新时长截断，未将播放游标纳入历史。
- 每个独立剪切窗记录不可变编辑状态。剪切、确认淡入 / 淡出、确认 dB 增益成功后各提交一个步骤；失败不提交并恢复此前状态。模式与边界选择也可撤销，连续鼠标拖动合并一步。Ctrl+Z / Ctrl+Y 和界面按钮恢复 / 重做缓存版本、范围、模式与处理参数；文本输入焦点内保留输入控件自身快捷键。撤销后新编辑清空重做链。
- 步数沿用设置中的“单个文件缓存撤销步骤”（默认 200，范围 50～1000）；不新增设置，不改变设置最后两项顺序。超出步数淘汰旧快照，仍被当前状态、历史或导出任务引用的缓存保持有效。
- 打开编辑器后在系统临时目录 unity-audio-edit-进程号-序号 下把选中音轨解码为 32 位浮点 PCM WAV，保留采样率与声道。每次确认编辑生成新的不可变 PCM 版本，删除中间时在无损编码缓存中拼接两端；未重复编码成 MP3 / AAC。浮点运算不保证高于 24 位有效精度的源逐位保真。
- 另存为从当前临时版本输出完整已提交时间轴，再一次性编码目标格式，保持原文件与原播放历史不变。中间文件占磁盘，历史较长 / 大音频可能显著增大占用，尚无磁盘额度或百分比进度。关闭窗口释放历史与播放，清理自身临时目录，Windows 解码句柄释放延迟时短暂重试；运行中的处理 / 保存持有缓存引用至结束，崩溃或权限问题仍可能残留。暂不支持恢复跨启动编辑会话或取消正在处理的任务。

## 格式转换与另存为

- 右上绿色“另存为”按钮，高度 40、宽度至少 120，并按翻译文本扩宽；文本水平 / 垂直居中，无障碍名称同步。
- 点击后弹出保存窗口，默认源目录与“原文件名_trim.所选扩展名”，可选文件夹和改名；确认后才转换，取消不启动任务。扩展名按所选格式统一，默认完整范围可仅用于格式转换。
- 默认 MP3、44100 Hz、双声道、192 kb/s。采样率与声道始终显示，按格式显示位深或码率，隐藏不适用的项。
- MP3 / M4A（AAC）提供目标码率 64 / 96 / 128 / 160 / 192 / 256 / 320 kb/s；实际码率可能浮动或受编码器限制。MP3 使用 32000 / 44100 / 48000 Hz，其余格式提供 8000 / 16000 / 22050 / 32000 / 44100 / 48000 / 96000 Hz。声道限单 / 双声道。
- WAV 提供 8 / 16 / 24 / 32 位整数 PCM，FLAC 提供 16 / 24 位；均不显示目标码率。切换格式遇到不支持的采样率回退 44100 Hz，不支持的位深回退 16 位。
- 使用外部 FFmpeg 在后台重新编码，仅当前音轨；提高目标位深 / 采样率不能恢复源精度，声道设置可能引入混音。未知时长禁用入口，非法头尾范围禁用剪切；音频另存为输出已经提交的完整时间轴，未点击剪切的选择范围不会自动删除。
- 目标同目录临时编码完成后，独占创建目标并复制；已有文件包括源文件均拒绝覆盖。复制失败尽量清理本次目标。非崩溃原子写入，进程崩溃可能遗留临时或不完整文件。
- 导出期间禁用参数与再次导出；关闭弹窗不取消已开始的后台导出。暂不支持取消、百分比进度、批量转换、任意片段重排 / 多轨编辑或无损流复制；区间删除后的两端拼接已支持。

## 视频当前范围与限制

- 目前可从主视频页入口打开独立原生窗口、输入保留范围、试听并另存 MP4（H.264 / AAC），只保留主视频和当前音轨，不含字幕、附件、额外音轨或源元数据。
- 奇数宽高补齐至偶数，输出 yuv420p，不保证 HDR / 源色彩精度保留；边界受帧 / 采样精度限制。
- 视频新剪切布局按用户要求暂缓，等待设计；未将音频波形编辑界面套用到视频窗口。
