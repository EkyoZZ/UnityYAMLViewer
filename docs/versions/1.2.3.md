## 音频编辑与转换

- 独立原生音频编辑窗口，打开后停止来源播放；不同文件可同时编辑，同文件唤醒已有窗口。切换或关闭来源页签不关闭编辑窗，各自独立播放、音量和时间轴。
- 头尾模式保留选区；区间模式删除选区并拼接两端。左键设置起点、右键设置终点，支持边界交叉，按较小 / 较大值解释实际范围；点击剪切后才修改当前缓存时间轴，不能删除全部音频。
- 淡入 / 淡出、选区音量 -60～+24 dB。无特定选区时增益作用于当前编辑阶段完整时间轴，不包含已删除音频。参数窗置顶，显示作用范围、预览包络，确认应用，取消恢复。
- 七种曲线预设及自定义分段三次贝塞尔曲线；最多 8 个锚点，可增加 / 删除内部点、拖动曲率手柄。淡入起点 / 淡出终点可上下调整幅度，端点时间固定，幅度限制在 0～100%。
- 每窗 Undo / Redo、Ctrl+Z / Ctrl+Y，沿用单文件缓存撤销步数上限；连续拖动合并步骤，撤销后新编辑清空重做。失败操作不提交新版本。
- 浮点 PCM 临时版本避免反复有损编码；另存为完整已提交时间轴，再编码为 MP3 / WAV / FLAC / M4A（AAC）。支持格式对应的采样率、单 / 双声道、位深或码率；拒绝覆盖已有目标及源文件。
- 主播放页与音频编辑支持鼠标锚定波形缩放和水平浏览。播放时缩放停止 0.1 秒后居中跟随游标，两端限制在实际时间轴；暂停不跟随。停止归零，暂停保留位置。修正波形填充在非整数 DPI 下的缝隙。
- 限制：无多轨、批处理、交叉淡化或样本级编辑；预览波形采用峰值包络，不是输出设备测量。正增益可能削波，不自动限幅；缓存占磁盘，关闭尽力清理，崩溃 / 权限等可能残留。编辑会话不跨启动恢复。视频目前仍为基础范围导出 MP4（H.264 / AAC），主视频和当前音轨、不含字幕，没有完整视频编辑器。

## PDF 只读预览

- 按需下载并验证 PDFium 后提供多页只读预览；打开、拖入、命令行、最近打开、会话恢复、文件关联 / 支持格式与 application/pdf URL 使用统一分流。
- 适应窗口 / 宽度、50% / 100% / 200%、滚轮缩放、拖动、重载。100% 以 96 DPI 逻辑像素为基准并叠加系统 DPI；物理像素对齐并启用屏幕文字抗锯齿，不保证与 Adobe 自定义显示设置完全一致。
- 底部浮层显示当前页 / 总页数及缩放，左右等高圆底按钮采用居中矢量三角。上 / 左上一页，下 / 右下一页；输入控件焦点内不抢方向键，边界不越页。
- 全屏按钮位于重载后；F11 进入 / 退出，Esc 退出。全屏黑底，隐藏页签和顶部工具栏，保留底部浮层与翻页；保留页码和缩放状态。
- 多页 PDF 文件名后提供现有样式的自动翻页 / 循环开关，间隔 1～3600 秒，默认 5 秒、默认关闭；单页及页数未知时隐藏整组。全屏继续，关闭循环时末页停止，开启时回到首页；手动翻页或修改间隔重新计时，渲染期间暂停计时。
- 循环后提供过渡菜单：无（英文 None，默认）、淡入淡出、左右滑动、推页、擦除、缩放淡入。动画 0.25 秒，手动 / 自动 / 全屏共用，不含翻书效果；不同尺寸页面在新页矩形中短暂适配旧纹理。
- 新页加载期间保持上一页画面和页码，就绪后替换；超过 1 秒才显示转圈。缩放 / 翻页不再切换重载按钮禁用样式，渲染中重载请求合并后延迟处理。
- 后台全局串行调用 PDFium；引擎 / 文档 / 页面 / 位图 / DLL 按依赖释放。当前页按尺寸渲染，文件上限 128 MiB、渲染单边上限 4096；过渡额外保留一张旧纹理。每次渲染重新打开内存文档，大型文件频繁缩放可能较慢。
- 限制：不编辑或保存 PDF，无文字选择、搜索、缩略图、密码输入、OCR、表单交互或脚本执行；加密文档不支持。超过渲染上限仍放大有限纹理，扫描图原始低分辨率不能恢复。

## SVG 与 GIF

- SVG 静态只读预览，适应窗口、固定倍率、滚轮缩放、拖动及重载；棋盘格 / 灰色 / 自定义背景，重载保留背景。不显示通道或九宫格入口，拒绝位图编辑路径。
- SVG 限制：16 MiB、单边渲染 4096；文字需转轮廓，不加载外部资源或内嵌位图，不执行脚本或动画。
- GIF 经 FFmpeg / FFprobe 解码，使用视频播放、暂停、停止、定位与全屏；不显示音量 / 音轨界面，显示全局 / 局部调色板的最大容量（不是实际使用颜色数）。
- GIF 循环模式：按文件设置、一次、无限及指定总播放次数；读取 NETSCAPE / ANIMEXTS 扩展，0 为无限、无扩展播放一次，正值采用 FFmpeg 总轮次语义。暂停保留计数，停止重置。
- 时间轴按实际帧时长分布，空间允许时显示帧刻度。进度与悬停格式为 h:mm:ss.mmm(f00)/h:mm:ss.mmm(f00) · 0.030 s/f；帧从 1 开始，f / s/f 固定不翻译。时长索引未就绪时显示 — s/f，不猜测时长。无 GIF 编辑 / 通道切换。

## 第三方支持

- 设置中的第三方支持打开独立原生管理窗口，集中管理 FFmpeg / FFprobe、PDFium、LibreOffice；缺组件按钮直接唤醒窗口。打开只检测，明确点击才安装 / 下载。
- FFmpeg 使用 WinGet Gyan.FFmpeg；PDFium 使用 bblanchon/pdfium-binaries 的 Windows x64、不带 V8 构建，限定附件与来源、核对下载大小和 GitHub SHA-256，保留许可，解压依赖系统 tar。提供进度、取消、检测、版本 / 路径及移除。
- PDFium 组件和暂存在 %APPDATA%/UnityYAMLViewer-components，位于配置缓存同级、排除缓存清理；使用中不能移除。崩溃可能残留未登记组件目录，缓存清理不擅自删除。
- FFmpeg 安装后检测、PDFium 安装后校验检测及重新检测结果完成后同步主窗口并重试失败预览；关闭窗口本身不触发检测 / 刷新，已启动后台任务仍可结束同步。
- LibreOffice 支持 WinGet 安装、路径 / 版本检测及手动选程序，可能需要管理员确认；未实现任何 Office / 苹果办公文档转换预览或编辑。不提供系统 FFmpeg / LibreOffice 卸载。
- 三个组件标题随深浅主题使用亮蓝 / 深蓝；设置最后两项仍为单文件缓存撤销步数、检查更新。

## 页签与媒体操作

- 同后缀忽略大小写，超过 3 个自动堆叠，显示最近激活文件及矢量堆叠数量。菜单单行截断、路径悬停提示、单项关闭及关闭全部，遵循未保存提醒。
- 页签与组均支持拖拽排序，整组移动保留成员顺序。逐项减少至 3 个时原位展开；关闭全部期间保持成组，取消停止后续关闭。
- 页签、堆叠文件项及预览文件名的右键菜单支持资源管理器选中文件、复制完整地址；缺失文件禁用定位，网络资源定位本地缓存，不复制原始 URL。
- 视频 / GIF 整个预览框（含留白）可左键播放 / 暂停，普通 / 自由缩放 / 全屏共用；拖动保留阈值，不误切换，进度条与播放列表浮层保留独立操作。
