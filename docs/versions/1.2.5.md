## 四方连续图

- 图片预览新增独立工具，提供最小循环提取与多图案制作；完整比较 RGBA，包括透明像素下的 RGB。提取不到更小循环时直接预览和平铺原图，保留原像素与尺寸，不把回退写成提取成功。
- 制作支持含原图最多 16 个图案，文件选择或拖入本地 PNG / JPEG / WebP / BMP / TGA，列表逐项移除、自动维护编号；重复路径跳过，目录不递归导入。单图案、交替、棋盘、自定义编号排列（最多 16 × 16 格），普通、行横移、列纵移及 1/2、1/3、1/4 错位；支持单图双排错位。
- 三栏为固定编辑视口、最小循环单元、连续平铺。左侧只显示显式图案元素，滚轮缩放、空白 / 空格 / 中键拖动平移，支持选中、连续拖动、X / Y 输入与重置；位置偏移为 ±32768 px。修复按单帧位移拖动导致移动困难和回跳。
- 参数变化自动后台更新，编辑图即时移动，结果更新期间保留上一帧并提示；最新结果就绪后才能导出。每个排列位置独立移动；排列变更或增删图案会重置位置。
- 横纵间距随相邻补齐图案边界的最小非负距离同步，无相邻元素的轴使用循环留白，重叠显示 0。手动修改全局间距会清除该轴手动偏移并重新计算，另一轴保留。
- 统一图案缩放 1%–400%、透明裁边、透明 / 纯色背景。图案透明补齐至 4 倍数，格距兼顾 4 与错位分母；自动尺寸下移动越界扩展输出区域，按完整周期生成最小 4 对齐单元，避免对齐补白破坏循环。
- 可自定义循环宽高，从左上角裁剪或扩大补背景，尺寸向上对齐 4，不缩放图案；固定尺寸之外不会导出，也不会继续自动扩展。提取模式无更小循环的原图回退不额外做 4 对齐。
- PNG 另存仅写新路径，不覆盖源图或其他现有文件，不修改 Unity meta。中间预览、右侧平铺和导出使用同一结果缓冲；边框开关在左侧工具栏，另存在中间预览上方，列表按最长编号文件名宽度居左显示。
- 限制：输出单边最多 8192 px、总计 16777216 px；制作图案总像素同限。编辑纹理最长边 1024、结果预览最长边 2048，导出完整尺寸。不自动修补接缝，无近似判重、斜向晶格输出、撤销、旋转或逐图案缩放；矩形命中不穿透透明区域。

## 九宫格精简修复

- 按精简方向处理中心 4 对齐；未精简方向仅外补透明，对应 Border 为 0，奇数多出的补白放右 / 下。
- Repeat 保留完整周期；包含外补后的方向尺寸必须严格小于原尺寸，否则保留该轴原始循环区，不为对齐增加尺寸。
- Stretch 中心默认保留 4 px，额外 1–3 px 计入右 / 下 Border；手动中心保留值继续生效。

## 其他调整

- 材质 / Shader 的 2D / 3D 切换使用主题 Tab；修复 Tab、背景 / 模型 / Cull / Blend 下拉控件与菜单随节点缩放的问题。
- 共享原生弹窗先定位到主窗口中心，再按中心所在或最近显示器的 Windows 工作区修正越界；计入标题栏、边框和任务栏，过大时缩小，兼顾多 DPI 与副屏负坐标。首次打开、重开和明确唤醒时修正，稳定后保留拖动位置；嵌入式回退不包含此 Win32 修正。
- 启动自动检查更新每 24 小时最多尝试一次，失败也计入，跨重启保存；记录不可写时跳过自动检查，手动检查不受每日限制，仍遵守服务端退避。
- README 中英与关于摘要七语言同步；关于默认显示 1.2.5 / 1.2.4，1.2.3 及更早版本置于默认收起的历史区域，重开恢复折叠。
