## 1. 图片查看与预览清晰度

- 普通图片使用最近邻纹理采样，放大后保留像素块，减少线性插值造成的模糊。
- 四方连续图修复预览生成阶段把小图插值放大到固定大尺寸、非方图被拉伸的问题：小图保留原始 RGBA；超限图按比例最近邻缩小。编辑预览上限 1024，结果预览上限 2048，不改变导出结果。
- 普通图片与连续图高倍预览按源像素对齐棋盘格：每个源像素显示宽高达到 8 个界面单位时一格对应一个像素；低倍保持固定格大小。连续平铺按实际重复次数计算倍率。
- 图片、九宫格及连续图背景改用无羽化网格，减少独立矩形边缘抗锯齿导致的细缝。
- 修正普通图片拖动按整段累计位移重复叠加的问题，改为每帧位移。

## 2. 统一背景设置与主题控件

- 普通图片、SVG、九宫格、连续图三栏、场景 / Prefab 2D / 3D、独立模型及 Spine 共用棋盘格 / 灰色 / 自定义背景选择。
- 背景模式与自定义 RGB 颜色持久保存到软件记录目录的 preview_background.json；首次仍为棋盘格，自定义颜色初始为黑色。其他视口同步重绘；保存失败显示提示。清缓存保留该文件。
- 自定义选色器只在选择自定义时显示。预览背景不修改源资源、制作输出背景、透明度或导出图片。
- 图片通道 R / G / B / A / RGB / RGBA、各背景选项及静态预览排序轴 X / Y / Z 使用现有主题 Tab 样式。
- 辅助线开关改为紧凑布局，紧随排序轴，不再占满整行。

## 3. 四方连续图与九宫格导出 / 布局

- 四方连续图另存 PNG 支持在保存对话框确认后覆盖已有文件，不再强制仅新建；PNG 编码先在内存完成，再打开目标写入。
- 九宫格另存支持覆盖 PNG；目标存在同名 .meta（包括仅有 .meta）时额外提示，确认后保存，取消不写入。
- 九宫格另存保留目标现有 .meta、GUID 和 Border，不自动同步 Border，并提示既有 Border 可能与新图片不匹配。原位替换路径的同步行为保持原样。
- 上述覆盖不创建备份，也不是事务式替换；磁盘写入失败仍可能留下不完整目标文件。
- 九宫格上 / 下边界标签分别放到图片左 / 右侧，并为翻译文字预留空间，避免挡住切分线。
- 连续图背景选择移至提取 / 制作模式之后，标签最终仍为背景色；三栏统一标题区域。
- 另存为按钮采用绿色白字，最小 120 × 40、字号 16，紧跟中间预览标题和尺寸两行文字，整体垂直居中。长翻译可扩宽。
- 普通图片移除 50% / 100% / 200% 固定倍率按钮，保留适应窗口、滚轮缩放；重载 / 九宫格 / 连续图入口移到文件名后。

## 4. 音视频信息展示

- 详细信息分为文件、视频、音频、字幕四组，长列表限高滚动。
- 文件：容器、大小及精确字节数、时长、音轨数、内封字幕数；存在时展示标题、艺术家、专辑、专辑艺术家、作曲者、曲目号、流派、日期和版权标签。
- 视频：编码、profile、codec tag、源分辨率、真实探测平均帧率、码率、像素格式、位深、像素 / 显示宽高比、动态范围、传递特性、颜色空间 / 原色 / 范围、场序；GIF 保留调色板说明。
- 音频：逐轨语言 / 标题、编码、profile、采样率、声道 / 布局、采样格式、已知位深、默认标记、码率。
- 字幕：内封轨道语言 / 标题、编码及当前显示支持情况。
- 视频顶部仅保留基础视频 / 音频摘要，两行末尾均可直接打开详细信息；右键入口保留。
- 纯音频顶部按当前选中音轨显示摘要并提供详情及轨道切换；新入口的轨道切换接入实际播放重启逻辑。
- 缺失的视频帧率不再用播放器默认 30 fps 冒充探测结果；未知参数不猜测，有损音频的解码采样格式不当作源位深。

## 5. 字幕样式与透明媒体显示

- 字幕字体自由输入改为可搜索的 Windows 已安装字体家族列表，保留系统默认项；使用 Windows API 枚举，进程内缓存，安装新字体后重启刷新。
- 字幕样式窗口默认宽度 320；应用 / 取消 / 重置位于底部居中，至少 88 × 32、字号 16，长翻译可扩宽。
- 播放器在画面范围内绘制固定棋盘格，透明 GIF 与解码后保留 Alpha 的视频可透出棋盘格，普通 / 全屏、播放 / 暂停 / 定位共用；棋盘格不写入帧缓存或导出。
- 透明 MOV / WebM 等仍依赖素材编码及 FFmpeg 解码链保留 Alpha。本次没有新增专门的透明 WebM 解码器选择，不能声明所有透明视频均验证支持。
- 内封文字字幕、外挂字幕及样式渲染在 v1.2.5 已有实现，本次是样式界面改进，不应写成新增加字幕显示支持。图片字幕仍不支持播放器显示。
