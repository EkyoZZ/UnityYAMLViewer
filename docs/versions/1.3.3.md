## 当前限制

- 网络播放仍依赖站点、会话、签名有效期和网络情况；面向点播，直播未实现。不支持抖音视频提取。自动慢网预取已移除，缓存需显式触发。
- 编辑、合成及缓存转换依赖 FFmpeg，提取依赖 yt-dlp。合并不支持图形字幕、GIF 或 PNG 序列，可改用队列导出；不提供自由多轨时间线。
- 工程通常不包含原始素材或外加音轨/字幕，移动、删除后需要恢复路径再打开，暂不提供重新定位向导；不持久保存撤销/重做历史。Windows 工程文件关联保留已有默认程序及 UserChoice，必要时需在系统设置确认。
- 后台导出及工程保存暂无百分比和取消支持；具体任务以实际可用操作为准。
