## 视频编辑与输出

- 独立单视频编辑窗口：左侧预览，右侧可调宽导出面板延伸至底部；范围操作位于预览上方，绿色另存为固定右上角，修复面板被输入框撑宽的问题。
- 独立编辑时间轴，上方帧刻度、中间保留 / 移除区、下方时间；支持鼠标锚定缩放、横向浏览、播放跟随、范围拖动及跳转。索引就绪后范围吸附实际帧位置，限制过度放大；橙色游标与倒三角在深浅主题一致，绿线贯穿时间轴，移除区与背景区分。拖动游标平滑显示，释放时提交跳转。
- 叠加画面裁剪框，支持移动 / 调整大小、X / Y / W / H 像素输入和初始比例预设。“画面大小”可单独或叠加裁剪启用，百分比 / 像素 Tab、宽高锁链，支持等比或独立调整；输出尺寸显示，预览同步宽高比。奇数输出尺寸补齐偶数。
- 十种容器：MP4、WebM、MKV、MOV、AVI、FLV、MPEG-TS、3GP、NUT、GIF。封装与后缀独立，允许 .bytes 等后缀，不覆盖已有文件。
- 视频按容器筛选并隐藏不兼容编码：H.264、H.265 / HEVC、VP8、VP9、未压缩 RGB24、MJPEG、MPEG-4 Part 2、ProRes 422、AV1、MPEG-2；GIF 专用流程。
- 可选质量 / 目标码率、相应 CRF 或 q:v、目标码率、源帧率或常用固定帧率。默认 1 pass；目标码率下 H.264、VP8、VP9、MPEG-4、MPEG-2 支持 2 pass，H.265 / AV1 暂无双遍。
- 音频按容器独立筛选 AAC、Opus、PCM16、MP3、AC-3、FLAC、Vorbis、E-AC-3；默认 48000 Hz，可选 44100 Hz 等兼容值，Opus 当前仅 48000 Hz。所选音轨统一编码、采样率和双声道。
- GIF 提供 4–256 色调色板、五种抖动及 Bayer 参数，无音频并无限循环。
- 依赖本地 FFmpeg / FFprobe 和所需编码器，导出前检查能力。新编码 / 扩展 FLV 的播放兼容性取决于播放端；预览尺寸变化不等同输出重采样画质预览，不保证 HDR / 原色彩精度及所有元数据保留。

## 多音轨、软字幕与播放器

- 源文件音轨和字幕异步读取后默认加入导出列表，可追加外部文件、勾选、移除、设置语言，保留默认 / 强制标记。无源音轨不生成音频。
- 按容器检查轨道数量和字幕支持；FLV 最多一条音轨，GIF 无音轨 / 字幕。不兼容的所选轨道提示并阻止导出，不静默丢弃。
- 文字字幕按选段裁剪、时间重定位并转换：MP4 / MOV / 3GP 用 mov_text，WebM 用 WebVTT，MKV 用 SRT；可能丢失样式。MKV 可复制 DVD / PGS，MPEG-TS 可复制 DVB 图像字幕；图像字幕边界精度待验证。
- 播放支持内嵌文字字幕和外挂 SRT / ASS / SSA / VTT。字体默认系统，可设字号、颜色、边距，描边 / 投影独立或组合启用。
- 字幕自动跟随音轨语言；无法唯一匹配提示手动选择，支持手动选择、关闭或恢复跟随。依赖 libass / subtitles 滤镜，暂不显示图像字幕、不提供 OCR；复杂 ASS 内联样式可能影响覆盖。
- 播放样式保留在当前文件会话，不写入软字幕输出，不烧录到最终画面。外挂轨道以同一源时间线处理，无逐轨偏移、混音或外加音轨编辑预览。

## CSV / TSV / PSV 表格

- 分别按逗号、Tab、竖线解析，支持 BOM、CRLF / LF、引号内分隔符和换行、双引号转义、空字段、不等长记录；错误回退原文，不自动探测其他分隔符。
- 列标 A–Z、AA…，行 index 从 0 开始，地址如 E15；列宽可调、双向滚动、文字复制、截断全文悬浮提示。右侧 / 底部滑条常显且独立占位，使用高对比颜色。
- 编辑模式复用 Inspector 的保存 / 放弃、事务保存、外部修改检查、关闭未保存提醒、单文件撤销步数及 Ctrl+Z。修改高亮；顶部地址 / 内容栏与单元格双向同步，位于内容分隔线上方。
- 仅编辑已有单元格；无行列增删，原文只读并显示修改。按字段范围替换，保留未修改字段、分隔符、换行及 UTF-8 BOM，保存 UTF-8；输入框为单行。
- 类型检查默认跳过首行，先采样 3 行，不确定扩展 5 行，短表按已有记录检查。至少两个非空样本，明确一致或扩展样本至少 80% 一致才推断，否则视为文本。
- 识别整数、有限数值、true / false 布尔值、JSON 对象、数组、文本；类型不符标红，显示错误单元格数及上一个 / 下一个循环定位。空值与缺失字段不报类型错误，不阻止保存；不校验日期、业务规则、JSON 必填键、数组长度或元素类型。
- Ctrl+F 聚焦查找，大小写不敏感子串搜索，匹配单元格计数与循环定位。淡绿匹配底、当前项描边；类型错误红底优先并以绿框标匹配，修改的匹配项保留暖色底线。
- ≤10,000 格且≤1,000,000 UTF-8 字节实时查找；≤50,000 格且≤5,000,000 字节停止输入 250 ms 后查找；其余回车 / 按钮后台执行。格数按行数 × 最大列数。后台单任务，丢弃取消结果，编辑 / 撤销按最近已提交查询更新。
- 大表加载、预解析、类型检查及编辑快照仍有界面线程开销；后台查找不保证任意大表无卡顿，阈值尚未性能实测。

- 制作模式含原图最多 16 个图案，可追加或移除；提供单图案、A/B 交替、棋盘预设，或按编号自定义矩形排列（最多 16 × 16 格）。自定义只使用引用的图案，添加图案后需选择预设或修改编号；移除后编号顺次重排，非法编号阻止生成。
