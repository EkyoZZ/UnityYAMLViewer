## 单视频编辑窗口

- 初始 1100×640、最小宽 800；左侧黑底等比预览、右侧可调宽导出面板、底部固定范围和播放控制；右侧说明可滚动。
- 点击预览播放 / 暂停；底部支持播放、暂停、选段播放、停止归零、独立音量和时间轴跳转；绿色起止标记、数字范围、当前位置标记、重置与边界跳转。
- 接通独立视频帧显示与帧索引；索引就绪后支持暂停跳转预览，首次索引可能耗时，沿用现有帧索引与解码限制。
- 编码可选 H.264 / AAC → MP4、VP8 / Opus → WebM、VP9 / Opus → WebM；可调 CRF 和音频码率 64～320 kb/s。H.264 默认 CRF 18，VP8 / VP9 切换后默认 32；音频默认 192 kb/s。VP8 采用 2 Mb/s 目标码率加 CRF，VP9 为 CRF 模式，不同编码器 CRF 不可直接比较。
- 导出前后台检查所选视频 / 音频编码器；FFmpeg 缺少编码器时报告失败。仅主视频和当前音轨，无字幕、附加流与元数据；统一 yuv420p，奇数尺寸补齐为偶数，不保证 HDR / 原色彩精度。拒绝覆盖已有文件。没有硬件编码、分辨率 / 帧率调整、预设或批量队列。

## 编码扩展、独立音频、GIF 与裁剪后缩放

本节为最新实际支持范围，替代前文阶段记录中四种编码、九种容器及固定音频编码的描述。AWS MediaConvert 资料仅参考编解码结构，不照搬其输入 / 输出服务限制。

- 视频编码新增未压缩 RGB 24位、MJPEG、MPEG-4 Part 2、ProRes 422、AV1、MPEG-2。容器仍筛选已接入的兼容编码，不兼容项隐藏；导出时检查本机所需编码器。
- MP4：H.264 / H.265 / VP9 / MPEG-4 Part 2 / AV1 / MPEG-2；WebM：VP8 / VP9 / AV1；MKV：除未压缩 RGB 外的其余九种视频编码（不含 GIF）；MOV：H.264 / H.265 / 未压缩 / MJPEG / MPEG-4 Part 2 / ProRes 422 / MPEG-2；AVI：H.264 / H.265 / VP8 / VP9 / 未压缩 / MJPEG / MPEG-4 Part 2 / MPEG-2；FLV：H.264 / H.265 / VP9；TS：H.264 / H.265 / MPEG-2；3GP：H.264 / MPEG-4 Part 2；NUT：全部十种视频编码。扩展 FLV 与 AVI 新编码仍有播放器兼容性限制。
- 未压缩采用 AVI BGR24、MOV / NUT RGB24；ProRes 固定 422 标准档、10位 yuv422p10le，不含 alpha；MJPEG 为 yuvj422p；其他压缩编码为 yuv420p。RGB 与色度转换不保证还原源精度 / HDR。未压缩输出不是源文件无损直通，体积可能很大。
- H.264 / H.265 / VP8 / VP9 / AV1 使用 CRF；MJPEG / MPEG-4 / MPEG-2 使用 q:v 2～31；未压缩与 ProRes 隐藏这些参数。MPEG-2 可选 24 / 25 / 30 / 50 / 60 fps，默认 25，必要时复制或丢弃帧。ProRes 固定档位，AV1 使用 libsvtav1 preset 8；没有新增硬件编码。
- 音频编码独立选择并按容器筛选：MP4 为 AAC / Opus / MP3 / AC-3 / FLAC / E-AC-3；WebM 为 Opus / Vorbis；MKV / NUT 为 AAC / Opus / PCM16 / MP3 / AC-3 / FLAC / Vorbis / E-AC-3；MOV 为 AAC / PCM16 / MP3 / AC-3 / E-AC-3；AVI 为 AAC / PCM16 / MP3 / AC-3；FLV 为 AAC / MP3；TS 为 AAC / MP3 / AC-3 / E-AC-3；3GP 为 AAC。切换容器保留兼容选择，否则回退 AAC（WebM 回退 Opus）。
- 视频导出音频统一 48 kHz 双声道，仅当前选中音轨，未选音轨时不生成音频。PCM16 / FLAC 隐藏码率，其他编码使用 64～320 kb/s 目标；编码器可能取近似值。尚未提供音频采样率、声道数或位深选择。
- 新增 GIF 为第十种容器，专用 GIF 编码，无音频，默认无限循环；沿用选段与画面裁剪 / 缩放。调色板最多颜色数可选 256 / 128 / 64 / 32 / 16 / 8 / 4，使用完整所选片段生成全局调色板、不预留透明色；这是颜色上限，不保证每种颜色都被使用，也不代表 GIF 物理调色板槽位数。
- GIF 滤波 / 抖动可选无、Bayer、Floyd–Steinberg、Sierra2、Sierra2 4A，默认 Sierra2 4A；Bayer scale 0～5，默认 2。此项是调色板量化抖动，尚未提供独立的图像缩放滤镜选择、透明 GIF 或循环次数设置。输入增加时长限制，避免全局调色板扫描选段之后的内容；长片段高分辨率 GIF 处理可能耗时并占内存。
- 裁剪后增加 1%～400% 等比缩放，默认 100%，快捷 25 / 50 / 100 / 200%；不依赖启用裁剪，未裁剪时缩放完整画面。顺序为裁剪 → Lanczos 缩放 → 偶数补齐，源画面上的裁剪坐标仍按源像素。右侧显示最终编码尺寸；整数取整和偶数补齐可能造成约一像素比例差异。预览不额外展示导出缩放结果。

## 等比缩放输入模式

- 缩放提供百分比 / 像素两种模式，共用同一缩放倍率，切换模式不改变导出结果。像素模式分别输入宽度和高度；修改任一项时按当前裁剪区域（未裁剪时为完整画面）的宽高比更新另一项。比例范围沿用 1%～400%，像素输入限制在对应范围；没有自由拉伸模式。
- 输入值为取整后的缩放像素，输出尺寸另显示偶数补齐结果；补齐可能使输出比输入宽高多一个像素。关于七语言缩放摘要仍适用，新增输入标签同步七语言。

## 多音轨 / 多字幕导出与播放器文字字幕

本节替代前文“仅当前音轨、不保留字幕”的阶段限制。

- 导出设置异步读取源文件全部音轨与字幕，默认列出并勾选保留；允许多文件追加音轨或字幕、取消勾选与逐条移除。只修改导出会话，不修改原视频。每条轨道通过下拉菜单设置语言，复用现有音轨语言识别与七语言名称；未知语言代码保留为可选项。
- 容器控制能力：GIF 不输出音轨 / 字幕；FLV 最多一条音轨且不输出字幕；其他九容器中的非 GIF / FLV 容器允许多音轨。MP4 / MOV / 3GP 的文字字幕转 mov_text；WebM 转 WebVTT；MKV 文字字幕转 SRT，并可原样封装 DVD / PGS 图像字幕；TS 仅允许已有 DVB 字幕原样封装；AVI / FLV / NUT 不提供字幕导出。这里仅列出本应用接入范围，并非容器所有能力。
- 选择了不受容器支持的轨道或超过数量上限时禁用另存为，并明确提示取消选择或切换容器，不静默剔除；GIF 自身明确无音频 / 字幕。容器切换保留轨道选择，重新兼容后恢复。各音轨使用当前公共音频编码、码率与 48 kHz 双声道设置，未提供逐轨编码参数、混音或同步偏移。
- 外挂字幕可多选添加，转换为独立内嵌软字幕，不烧录至导出画面；文字字幕在后台转为 SRT 中间内容，按选段裁掉首尾事件并将时间归零，再转换到输出格式。所选区间完全没有某条字幕内容时报告错误，需手动取消该轨道，不生成假字幕。图像字幕不做 OCR，仅在兼容容器中复制，跨边界事件的精确裁切尚未验证。外部音轨 / 字幕使用与原片相同的时间起点，不提供延迟校正。
- 字幕文字转换不承诺保留 ASS 特效、字体、定位与附件。轨道标题与语言写入输出；尽量保留 forced 标记，并在已有默认轨中选择首个默认轨；无默认音轨时默认第一条，无默认字幕时不强制设置默认。MOV 某些语言代码可能丢失，AVI 不可靠保留语言标签，界面提示优先用 MKV / MP4。

- 播放时默认跟随音轨识别出的语言选择文字字幕；唯一匹配或同语言候选中的唯一默认轨时自动选择。未识别、无匹配或歧义时清除自动字幕并在界面提示手动选择。手动选字幕 / 关闭字幕会关闭语言跟随，可在菜单重新开启。外挂字幕尝试从文件名中的语言代码识别，否则需手动选择；并未建立容器内强制音轨-字幕绑定，不保证其他播放器采用同一联动策略。

## 视频目标码率、帧率与两遍编码

- H.264 / H.265 / VP8 / VP9 / MPEG-4 Part 2 / AV1 / MPEG-2 可在质量模式与目标码率间切换。质量模式仍使用 CRF 或 q:v，目标模式只传入目标视频码率（32～200000 kb/s，默认 6000），不叠加 CRF / q:v。目标码率不是严格 CBR，不保证实际码率或输出体积精确等于目标；未接入峰值码率 / 缓冲区、文件大小估算或编码速度预设选择。
- 帧率提供跟随源视频与 23.976 / 24 / 25 / 29.97 / 30 / 50 / 59.94 / 60 fps，分数帧率使用准确的 24000/1001、30000/1001、60000/1001。固定模式输出 CFR，会复制 / 丢弃帧，无光流插帧；默认不强制固定帧率，MPEG-2 因编码限制取消跟随源选项、默认 25 fps。GIF 也可选输出帧率，但 GIF 时间单位为 1/100 秒，不保证每帧间隔精确等于设定值。
- 默认 1 pass。目标码率模式中，H.264 / VP8 / VP9 / MPEG-4 Part 2 / MPEG-2 提供 2 pass；第一遍只分析视频并写统计日志，第二遍按相同滤镜、码率与帧率输出完整选中音轨 / 字幕。统计文件按任务使用独立路径，正常完成或失败时尽力清理。无进度百分比或中途取消；两遍处理耗时增加。
- H.265 / AV1 目前只接入单遍目标码率；CRF 模式、未压缩、MJPEG、ProRes、GIF 不提供两遍选项，不代表其底层编码器绝对没有其他多遍能力。切换后不兼容选项隐藏，旧的两遍选择不影响不兼容编码导出。
