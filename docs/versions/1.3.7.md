## 主要改动

- 新增像素 Tile 编辑器：矩形／平面菱形／带高度模式、多格独立内容、平面边缘回绕；画笔、橡皮、取色、直线、矩形、填充，RGBA／HEX、笔宽、平移缩放、笔刷范围与撤销重做。
- Tile 图层与工程：缩略图、显隐、锁定、排序、重命名／删除；格式 3 保存分层并兼容旧工程。坐标选格、导入／清空、网格预设、逐格透明 PNG 导出，三列布局及独立循环预览。
- 新增独立 Photoshop UXP 插件和 EXE 安装器：单 Tile、多文档 Slot 和单文档菱形网格，新建／扩展文档、中心区域、错位／子组预览、切片导出，独立设置与预览面板、背景拾色、缩放及会话设置记忆。
- PS 图层绑定与回落：多层累计绑定、绑定即启用、未绑定层暂停；手动回落、paint 事件和历史兜底、周期边界同步及子组笔迹合成。改进空白历史读取、辅助网格恢复、面板焦点和统一提示，普通提示五秒清除，隐藏后台统计。
- 录屏倒计时初始化与三秒起点修正，数字改为居中加粗矢量；准备绿框、首帧后红框、停止后绿框且保持鼠标穿透，重新选区恢复调整。
- 视频编辑支持内嵌／外部音轨波形与切换试听、时间戳和尾部静音修正、录屏进入编辑默认音轨修复；音轨／字幕连续编号，独立选择预览或无音轨／无字幕，工程保存预览状态。播放页字幕选择框收窄。
- 图片平滑预览修正预乘 Alpha 插值及透明边缘亮边；独立图片缓存计入预算并随淘汰释放。
