### 相对于 1.1.4 的新增与改进

- **Spine 3.8 资源预览**：支持直接打开骨骼 JSON / 二进制及 SkeletonDataAsset，只读资源页签中提供动画、皮肤、多轨播放、暂停、循环、速度与时间轴。按 GUID 查找 SkeletonDataAsset / AtlasAsset 引用，支持骨骼与图集异名；场景 / Prefab 合成初始静态姿势。
- **模型预览**：新增 FBX（含二进制）/ OBJ 只读模型页签，显示主贴图与材质颜色；支持实体、实体+线框、线框模式，顶点 / 三角面统计、自定义背景、左键旋转、右键平移及围绕鼠标缩放。
- **场景 / Prefab 2D 与 3D 切换**：2D 支持网格静态合成，3D 提供可旋转正交视角，合成模型与 Sprite / Tilemap / Spine 静态贴图平面；替代旧的 50% / 100% / 200% 按钮，保留适应窗口及增加 3D 重置视角。UI Canvas 使用 2D 查看。
- **模型显示修复与质量改进**：修正宽高比例失真、FBX 导入单位与 globalScale / useFileScale、重复变换和场景观察深度方向；按 Prefab 骨骼层级和绑定权重显示 SkinnedMeshRenderer 保存的静态姿态；支持 Unity 内置 Quad。模型预览加入 2 倍超采样和线框覆盖率抗锯齿，缩小时收细线框。
- **Hierarchy / 预览双向选择**：2D 预览点选定位普通及展开的嵌套 Prefab 节点，自动展开祖先并滚动定位；Hierarchy 选节点时为自身可显示组件绘制蓝色选中框。默认展开前三层，手动展开状态保留。
- **页签与最近记录**：打开页签支持拖拽排序、插入提示及让位动画，保存顺序且保持当前资源与编辑内容；最近文件上限由 10 条增加至 30 条。
- **Inspector 与编辑交互**：新增 SkinnedMeshRenderer 结构化属性；模型 / Spine 导航按钮置于组件标题右侧，组件收起时也可使用，蓝色按钮与标签底色分离；向量分量通过 x/y/z 标签拖拽调整，输入框恢复文字框选，保留精调 / 加速与撤销合并。
- **预览布局**：Spine 轨道面板与底部缩放 / 播放浮层紧凑化，修复浅色主题轨道文字对比度；模型增加底部缩放比例浮层、适应窗口与完整视角复位。

### 最终限制与暂缓事项

- 本版不执行任意 Unity Shader、不模拟粒子、不播放场景整体动画；材质 / 片元近似实验已全部删除，待后续统一渲染系统实现。
- Spine 仅支持 3.8.x（保留 Runtime 对 3.8.75 的拒绝）；特殊混合、完整 SkeletonGraphic 缩放及 Unity Mask / RectMask2D 未完整还原。
- 3D 未接入 Hierarchy 点选联动及 UI Canvas 图形；模型不支持 Blend Shape、Unity Mesh.asset、FBX 子网格 fileID 精确选择和完整 Unity 材质效果。2D 模型之间交叉穿插仍按对象排序合成。
- 预览仍有资源、贴图、三角面与缓存预算限制；抗锯齿增加 CPU 渲染开销，不保证所有项目与 Unity 完全一致。
