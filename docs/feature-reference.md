## 中文

### 功能详情

- **弹窗定位**：共享原生弹窗首次打开或明确唤起时，先以主窗口中心定位，再检查所在 Windows 显示器的可用工作区并修正越界，避开任务栏；窗口过大时自动缩小，计入标题栏和边框，并兼顾多屏负坐标及 DPI 缩放。定位稳定后保留用户拖动的位置。

- **连续图图案拖放**：可从文件管理器将多张本地位图拖入四方连续图编辑窗口，自动切换制作模式、加入图案列表并追加到排列每一行。也可使用“添加图案”选择文件。重复路径跳过，含原图最多 16 个；支持 PNG / JPG / JPEG / WebP / BMP / TGA，不递归导入目录。列表按最长“序号＋文件名”统一宽度并居左显示，超出可用宽度时截断，悬停显示完整路径；支持逐项移除，删除位置改用原图，其余编号自动更新；保存期间暂不接受拖入，完成后可重试；预览更新期间仍可编辑和添加。

- **四方连续图**：图片预览中可打开独立工具，按完整 RGBA 提取能整除原图尺寸的最小矩形循环；没有更小循环时直接以原图预览和平铺，保持原像素和尺寸，或用最多 16 个图案制作连续图。提取 / 制作和排列方式使用统一主题 Tab；支持单图案、交替、棋盘及编号自定义排列，横纵间距、统一缩放、裁去透明边缘、透明或纯色背景，以及逐行横移 / 逐列纵移的 1/2、1/3、1/4 错位。三栏布局：左侧实时编辑，中间为最小循环单元预览，右侧为 3×3 连续平铺；左侧为固定大小的虚拟编辑视口，滚轮缩放、空白处拖动或空格拖动平移，仅绘制独立编辑元素，不显示自动循环副本；中间按周期窗口裁剪并提取 4 对齐最小单元，右侧循环该单元。参数区下方独立滚动，三块画布保持可见，不另设原图预览。自动尺寸时中间使用实际导出的 4 对齐最小单元，右侧以同一单元平铺。普通及错位排列均可启用自定义循环宽高：从左上角裁剪或扩大补背景，尺寸向上对齐 4，不缩放图案；固定尺寸下超出区域的部分不会导出，取消自定义恢复自动尺寸。“显示单元边框”位于左侧编辑工具栏，“另存为 PNG”位于中间预览上方。默认进入制作模式，打开、修改参数、增删图案或拖动位置均自动预览，无需生成按钮；更新期间保留上一帧并提示，完成最新预览后才能导出。支持在左侧编辑画布选中每个排列位置并独立连续拖动，或输入 X / Y 和重置位置；移动超出画布时自动扩展对应边缘并保持宽高为 4 的倍数，左 / 上扩展会同步平移画布原点，拖动换算比例固定，三栏自动刷新；间距输入显示相邻补齐图案边界的最小非负距离，无对应相邻图案的方向使用循环留白，重叠显示 0；数值随移动同步，手动修改间距则清除该方向的手动偏移并按输入重新排列计算；“单图双排错位”使用同一图案生成两排，第二排默认横移半格，可单独移动。修改排列或增删图案会重置位置。图案缩放、裁边后用透明留白补齐宽高至 4 的倍数，不拉伸图案；间距按最大图案的统一格子计算，格距自动向上对齐 4 与错位分母的公倍数（最多额外增加 11 px），显示实际格子间距。导出提取最小周期并按完整周期重复至宽高均为 4 的倍数，保持无缝。另存新 PNG，不覆盖已有文件、不修改 Unity meta；不自动修补原图接缝。循环单元单边最多 8192 像素、总计 16777216 像素；预览最长边最多 2048 像素，导出保留实际尺寸。

- **第三方支持**：设置提供独立管理窗口，集中显示 FFmpeg / FFprobe 的安装状态和检测路径，继续通过 WinGet 安装。PDFium 提供 Windows x64 不带 V8 组件的按需下载、SHA-256 校验、版本 / 路径显示、重新检测和移除；来源为 bblanchon/pdfium-binaries，解压依赖 Windows tar。组件保存在 `%APPDATA%/UnityYAMLViewer-components`，位于软件缓存扫描范围之外，不会被缓存清理删除；FFmpeg 由 WinGet 管理。LibreOffice 同样提供 WinGet 安装、版本 / 路径检测和手动选择程序，可能需要管理员确认，安装文件由系统管理。打开窗口仅检测，点击下载或安装才联网安装。FFmpeg 在第三方窗口打开时检测；安装后的检测和“重新检测”完成后同步主窗口并重试失败的媒体预览，关闭窗口不触发额外检测。

- **PDF 预览**：通过第三方支持下载并校验 PDFium 后，支持多页只读预览、多页 PDF 在文件名后提供自动翻页开关（单页及页数未加载时隐藏相关设置）与 1–3600 秒间隔（默认 5 秒，全屏继续；秒数后可切换循环，默认关闭，开启时末页回到第一页，否则末页停止）；循环后提供过渡下拉菜单，默认“无”，可选淡入淡出、左右滑动、推页、擦除、缩放淡入，动画 0.25 秒且全屏同样生效。底部页码 / 缩放浮层与圆形矢量上一页 / 下一页按钮、方向键翻页、黑底全屏查看（重载后的“全屏”按钮或 F11 进入，F11 / Esc 退出）、适应窗口 / 宽度、固定倍率、滚轮缩放、拖动与重载。缺少组件可直接打开管理窗口，安装后校验检测及“重新检测”完成后同步结果并自动重试失败预览，也可手动重试；关闭管理窗口不触发刷新。100% 采用 96 DPI 逻辑像素基准并叠加系统 DPI，页面按物理像素对齐，使用屏幕文字抗锯齿。文件最大 128 MiB，按当前页与 DPI 后台渲染，单边最大 4096 像素；翻页时保留上一页直到新页完成，等待超过 1 秒才显示加载转圈。白色页面背景，不执行脚本或表单交互，加密文档暂不支持。

- **SVG 与 GIF 预览**：SVG 支持只读预览、棋盘格 / 灰色 / 自定义背景（沿用 Prefab 预览控件）、适应窗口、50% / 100% / 200%、滚轮缩放、拖动浏览与重载；缩放时后台重新渲染，单边最大 4096 像素，文件最大 16 MiB。支持渲染器可识别的静态路径 / 图形；文字需转轮廓，不加载外部资源或内嵌位图，不执行脚本或动画。GIF 隐藏音量、音频信息和音轨菜单，显示全局 / 局部调色板最大容量（非实际使用颜色数）。GIF 通过外部 FFmpeg / FFprobe 使用媒体控件播放、暂停、停止与定位，复用视频 UI，时间轴按实际时长分布并显示“0:00:00.000(f00)/0:00:00.000(f00) · 0.030 s/f”（f / s/f 固定不翻译，时长索引未就绪时显示 — s/f），悬停查看对应帧，空间允许时显示帧边界；支持按文件设置、播放一次、无限循环或指定总播放次数。按文件设置识别 NETSCAPE / ANIMEXTS 循环扩展，0 表示无限，未声明时播放一次；正值沿用 FFmpeg 的总轮次含义。暂停保留轮次，停止归零并重置轮次。SVG 隐藏通道切换与九宫格入口，背景设置仅用于预览、不写回文件，重载保留背景设置。SVG / GIF 不支持九宫格或编辑，GIF 暂不提供通道切换；SVG 编辑后续扩展。
- **文件页签**：相同后缀名（忽略大小写）超过 3 个文件时折叠为下拉页签，显示组内最近激活的文件名；菜单沿用“最近打开”的自适应宽度与最大宽度限制，文件名左对齐、单行截断，悬停显示完整路径；高亮当前文件，使用无边框按钮与矢量文件堆叠 / 关闭图标，文件堆叠图标后显示组内数量，每项带 ×，底部提供“关闭全部”。资源 / 播放列表存在未保存修改时提醒，取消会停止剩余批量关闭；逐项关闭减至 3 个及以下时，在原组位置按组内顺序展开为单成员页签；单成员页签显示 ×，不显示下拉菜单。“关闭全部”期间不因数量降至 3 个而解散，直到关闭结束；取消后恢复自动展开。普通页签与折叠组均支持拖拽排序，折叠组整体移动并保留组内顺序；独立音视频编辑窗口沿用原有生命周期。
- **文件定位**：页签、堆叠菜单内的文件项及图片 / PDF / 媒体预览文件名可右键打开文件所在目录（资源管理器选中文件），或复制完整文件地址；缺失文件禁用定位。网络缓存文件定位实际缓存位置。
- **资源查看**：打开 Prefab、Scene、Material 等文本资源，显示 Hierarchy 与 Inspector，支持搜索、引用定位和多标签页。
- **弹窗定位**：首次打开或通过程序按钮唤醒时对齐主窗口；鼠标点击、切换窗口等普通焦点恢复保留用户摆放的位置。
- **分隔文本表格**：CSV、TSV、PSV 默认按逗号、制表符、竖线显示表格，列标采用 A–Z、AA 等字母，行号从 0 开始；编辑模式顶部显示当前单元格地址（如 E15）和同步内容输入框，支持进入编辑模式修改已有单元格、高亮未保存修改、Ctrl+Z 撤销，以及与 Inspector 一致的保存编辑／放弃编辑；可调整列宽、滚动、选择复制文字、悬停查看完整内容并切换原文。支持引号内分隔符与换行；首行保留为数据，不自动识别标题或其他分隔符。类型检查默认跳过首行，先用前 3 行推断列类型（整数、数值、布尔值、JSON 对象、数组、文本），不确定时扩展至前 5 行；可切换表头选项，短表按已有行检查；类型不符单元格标红，显示错误数并支持前后定位，编辑和撤销后更新；空值不报错，扩展采样仍无至少 80% 类型一致或不足两个非空样本的列按文本处理，检查结果仅作提示，不阻止保存。Ctrl+F 聚焦查找输入框，可直接输入，按表格规模自动选择实时、250 ms 延迟或回车触发的后台查找：单元格数与文本 UTF-8 大小同时不超过 1 万／1 MB 时实时，不超过 5 万／5 MB 时延迟，其余回车或点击查找；右上方支持不区分大小写的单元格文字查找，显示匹配单元格数量，上一个／下一个循环定位；匹配单元格标淡绿，当前定位项描边，类型错误优先保留红底。
- **图片编辑**：在独立系统窗口中逐像素比较完整 RGBA，参数在左上，右上显示尺寸、面积收益与可展开详情，下方同屏对照带删除标记的裁剪方案和结果，不另设原图展示；四区左右保持 1:1 等宽，窗口缩放不改变列宽比例，超宽文字换行；预览随窗口增高，像素尺寸居中显示在图片下方的圆角底衬中，紧接边界距离标记，说明与操作位于底部；裁剪图用半透明底色和稀疏斜纹标出移除区，默认从候选色自动选对比色，可切换半透明红色；重复模式白框标出保留循环，虚线标最小循环边界；“同时 / 横向 / 纵向”和“拉伸 / 重复”使用主题切换样式，与自动识别放在同一行；左上设置不设内部滚动条，顶部高度跟随设置内容，右上信息超高时独立滚动；原始 Border 叠加开关放在左上设置中；自动识别比较六种组合，按实际对齐后面积选择，逐方向解释不能精简的原因；实际保留尺寸、诊断、循环和方案比较默认收起，详情区分可精简区、保留与移除像素；点击状态旁“查看详情”展开，重新打开窗口恢复收起。拖动参数时保留上次预览，更新完成前禁用保存；没有可读 `.meta` 时，底部按钮整体居中；有元信息时，底部信息在左、放大的绿色原位替换和蓝色另存为按钮在右垂直居中排列，右侧预留滚动条空间；独立精简窗口内容超出可视区域时，滚动条常显且占用独立空间，不覆盖内容。重复模式识别连续区域的最小循环，可设置横向 / 纵向保留倍数。边界四项成组，按上 / 下、左 / 右分两行排列，“边界:”标签相对两行输入垂直居中，px 紧邻输入框右侧，与下一组方向文字留出 12 px 间距；中心宽高默认 4 px、允许手动调整；默认保留透明边缘、将宽高对齐到 4 的倍数；标注实际保留中心、循环倍数、节省面积和补白；结果尺寸与面积变化用底色突出，节省为绿色、增加为橙色、无变化为灰色。裁剪图可叠加已读取 `.meta` 的原始 Unity Border（绿色），与本次切分线（黄 / 蓝）分别标明来源。确认后原位替换、不创建备份，并重载页签；可另存 PNG。仅在成功读取同位置单 Sprite `.meta` 时显示同步操作，写入 Border / Full Rect 并保留 GUID。
- **属性编辑**：编辑已识别的属性、颜色、向量和列表，支持校验、撤销与保存。
- **材质预览**：Material / Shader 使用 **Node-based UI**，支持节点内临时调参、拖图换纹理、主题 Tab 样式的 2D / 3D 输出切换与 Cull / Blend 调节；常见公式拆成100 点宽运算节点，颜色预览按需展开，可见时约 60 帧/秒更新，支持左键选择 / 框选（不受输出节点可见性影响）、统一选框的节点与组多选拖动、右键平移、带框折叠 / 展开和眼睛预览按钮（含 R/G/B/A 单通道及其运算）的可拖动函数分组及具名边界接口与 10%～175% 缩放。
- **场景与动画**：预览受支持的 2D / UI、Spine 和模型资源，查看 Animator 状态图、编辑动画曲线。
- **音视频播放与编辑**：视频 / GIF 支持点击预览播放 / 暂停，播放列表、波形、全屏和进度记忆。播放列表编辑时可直接退出编辑，保留未保存修改供手动保存；保存成功后自动退出编辑，失败则保留编辑状态。顶部“剪切/格式转换”打开独立编辑窗并停止来源播放；弹窗可独立播放和调节音量，切换或关闭来源页签仍保留，同文件复用已有窗口。视频编辑提供预览叠加裁剪框、X / Y / W / H 像素输入、比例初始范围、独立开关的 1%～400% 缩放（可单独使用或叠加裁剪，百分比 / 像素模式；锁链亮起时宽高等比联动，关闭后分别设置，左侧预览同步宽高比例变化），以及可缩放的时间 / 帧编辑轴（限制单帧过度放大，保留区与剔除区分色）。容器支持 MP4、WebM、MKV、MOV、AVI、FLV、TS、3GP、NUT、GIF，视频 / 音频编码按容器兼容性筛选；支持质量或目标码率模式、跟随源视频或常用固定帧率，兼容编码可选 2 pass（默认 1 pass）；已接入 H.264、H.265、VP8、VP9、未压缩 RGB24、MJPEG、MPEG-4 Part 2、ProRes 422、AV1、MPEG-2。音频可按容器选择 AAC、Opus、PCM16、MP3、AC-3、FLAC、Vorbis、E-AC-3，各音轨按所选采样率导出为双声道（默认 48000 Hz，支持 44100 Hz 等编码兼容选项，Opus 当前限 48000 Hz）；原有内嵌音轨和字幕默认列出并勾选，可多选追加外部音轨 / 字幕、取消或移除，并通过下拉菜单设置语言。多轨数量和字幕格式按容器检查，不支持的已选轨道会阻止导出。音频与视频导出结束均弹窗提醒，成功显示保存路径，失败显示原因。GIF 无音频，可选 4～256 色上限与五种抖动方式，默认无限循环。容器与文件后缀独立，可保存为 .bytes；奇数输出尺寸补齐偶数。导出依赖本机 FFmpeg 对应编码器，部分新编码 / 扩展 FLV 的旧播放器兼容性有限；没有 MXF / Ogg、批量队列或硬件编码。FFmpeg 可从“设置 → 第三方支持”安装 / 检测。
- **播放器字幕**：视频右键“字幕”可选择内嵌文字字幕、加载 SRT / ASS / SSA / VTT 外挂字幕及设置样式。可指定字体（空白为系统字体）、字号、颜色、边距，独立或组合开启描边 / 投影并设置其粗细 / 距离与颜色。默认按音轨语言匹配字幕，唯一匹配或唯一默认匹配时自动选择；未识别、缺失或歧义时提示手动选择，手动选择后可在菜单恢复语言跟随。需要 FFmpeg 的 libass / subtitles 滤镜；播放器暂不显示图像字幕，复杂 ASS 内联样式可能影响覆盖效果，设置仅保留在当前文件会话。播放样式不写入软字幕导出，外挂文字字幕可转换为容器支持的内嵌字幕轨；转换可能丢失原样式，图像字幕不做 OCR。
- **音频剪切与转换**：头尾 / 区间使用主题切换式 Tab，旁边显示区间时长，区间模式另显示删除选区后的时长。头尾模式保留中间；两种模式都左键设起点、右键设终点，区间模式点击“剪切”删除两条边界之间的部分并拼接两端，波形和时间轴同步缩短。区间边界允许交叉，实际范围按两者较小值至较大值计算，淡入淡出也使用该范围；绿色边界可拖动，删除区域为 30% 不透明黑色遮罩，黄色游标仍可定位。淡入 / 淡出弹窗默认采用当前选区可用时长，可修改，通过下拉列表提供线性、平滑、等功率、二次、三次、平方根、更平滑七种曲线；下方曲线图支持圆形锚点及方形贝塞尔手柄，拖动手柄调整曲率，点击添加、右键删除中间锚点，端点时间固定，淡入起点 / 淡出终点可上下拖动调整幅度，另一端固定 100%，最多 8 个锚点，修改后显示“自定义”，按分段三次贝塞尔曲线处理；手柄时间顺序限制在各段内，幅度限制 0–100%，重新选择预设会替换编辑结果。音量(dB)弹窗调整当前选区增益，未选范围时调整剪切后当前时间轴整段；淡入、淡出和音量(dB)参数窗保持置顶，按内容设置最小宽度，说明可换行，应用 / 取消居中。设置时预览波形，确认后刷新音频与实际波形。Ctrl+Z / Ctrl+Y 和撤销 / 重做按钮按窗口独立维护步骤，沿用设置中的撤销步数。中间版本使用临时目录的浮点 PCM，无重复有损编码；另存为输出当前已提交的完整时间轴，支持 MP3 / WAV / FLAC / M4A（AAC），按格式显示采样率、声道、位深或码率，不覆盖已有文件。入口与窗口标题使用“音频编辑”，视频对应“视频编辑”。主窗口音频与音频编辑波形均支持鼠标位置锚定的滚轮缩放，最小显示全长，最大约 10 毫秒主刻度；放大后在刻度下方拖动水平滑条浏览；主窗口与音频编辑窗播放时，停止缩放操作 0.1 秒后黄线居中跟随，开头 / 结尾受时间轴边界限制，暂停不跟随。播放控制固定底部；停止返回 0:00，暂停保留当前位置。波形使用 8 kHz 解码峰值、每声道最多 400 万点，长音频细节受峰值上限限制，不支持采样点编辑。处理期间等待后台任务完成；增益可能削波，中间缓存占用磁盘，关闭窗口尽量清理，崩溃可能残留。不含交叉淡化、批量转换或自由多轨编辑。
- **日常使用**：最近文件、标签恢复、深浅主题、七种语言和在线更新（启动自动检查间隔至少 24 小时，手动检查不受此限制）；GitHub 接口限流时提示等待重试，也可打开发布页手动更新。

### 当前限制

- 多视频合并尚未实现：后续支持多选加入、逐条追加和调整合并顺序。

- PDF 暂不支持编辑、文字选择、搜索、缩略图和密码输入；Office 与苹果办公文档预览 / 编辑未实现。

- 拉伸只删除完整 RGBA 一致的连续行列；重复只提取通过完整行列像素验证的连续周期，不做近似采样。取消透明边缘保留时，仅沿所选方向裁去 Alpha 为 0 的外圈（会丢弃其中隐藏 RGB、改变留白）；全透明图默认不裁。4 倍数对齐优先多保留重复像素 / 完整循环，不足时每轴补 1–3 个透明像素：1 加右 / 下，2 两侧各 1，3 左 / 上 1、右 / 下 2；补白不计入 Unity Border，可能增加尺寸；实际倍数可能高于输入值或受区域大小限制。原位支持 PNG / TGA / BMP / WebP；JPEG 和动画需另存静态 PNG。输出为 8 位 RGBA，不保留附加图像元数据。多 Sprite 或其他纹理类型不支持原位替换；未读到 `.meta` 时不显示修改提示或创建它。Unity 需重新导入，UI Image 需手动选择 Sliced / Tiled；不承诺具体网格数量。输入上限为单边 8192 像素、256 MiB 解码分配；节省面积不等于压缩文件或显存节省。
- Unity 二进制序列化资源暂不支持；未知类型、原始 YAML 和 fileID 引用保持只读。
- 场景、Spine 和 Shader 为部分兼容，不能完整替代 Unity 渲染；URP / HDRP、多 Pass、复杂 Shader 与完整光照仍有限制。
- 节点界面目前用于预览，不支持创建节点、编辑连线或生成 Shader；函数快照限可唯一定位到阶段调用处的数值参数函数，复杂调用只展示拆分；不支持的表达式保留为源码语句。

### Feature details

- **Dialog placement**: Shared native dialogs center on the main window when opened or explicitly recalled, then correct overflow against that Windows monitor's work area, excluding the taskbar. Oversized dialogs shrink to fit, accounting for the title bar, frame, negative monitor coordinates and DPI scaling. Once placement settles, manually moved positions are retained.

- **Drag motifs into the repeat editor**: Drop local bitmap files from a file manager into the seamless-repeat window to switch to composition mode, add them to the list and append them to each layout row. The Add motifs file picker uses the same behavior. Duplicate paths are skipped; up to 16 motifs including the source. Supports PNG / JPG / JPEG / WebP / BMP / TGA files, without directory recursion. List rows use the longest numbered filename width with left-aligned text; long names truncate to available width and show full paths on hover. Remove added motifs individually; their positions revert to the source image and other motif numbers update automatically. Drops during saving show a retry message; preview updates allow continued editing and additions.

- **Seamless repeats**: A separate tool in bitmap previews extracts the smallest complete rectangular repeat using exact RGBA comparison; when no smaller repeat exists, it previews and tiles the original with unchanged pixels and dimensions, or composes repeats from up to 16 motifs. Extraction/composition and arrangement modes use themed tabs. Supports single, alternating, checkerboard and custom numbered layouts; horizontal / vertical spacing, shared scale, transparent-margin trimming, transparent / solid backgrounds, and progressive row / column shifts of 1/2, 1/3 or 1/4. Three panes show live editing on the left, the smallest repeat tile in the middle, and the 3×3 repeated result on the right. The left is a fixed virtual viewport with wheel zoom and empty-space or Space-drag panning. It draws only explicit elements without automatic repeat copies. The middle crops the repeat window and extracts the 4-aligned smallest tile; the right repeats that tile. Controls scroll separately below the visible canvases; there is no separate source-image pane. With automatic sizing, the middle shows the actual 4-aligned smallest export tile and the right repeats it. Straight and staggered layouts also support custom repeat dimensions: crop from the top-left or expand with background padding, rounding up to multiples of 4 without scaling motifs. Fixed sizes exclude out-of-area parts from export; disable custom sizing to restore automatic sizing. Show tile boundaries is in the left edit toolbar; Save as PNG is above the middle preview. Composition opens by default and previews update automatically on edits, additions, removals and dragging, with no Generate button. The previous frame remains visible while updating; export requires the latest preview. Select and continuously drag each layout placement independently in the left canvas, or edit X / Y and reset its position. Moving beyond the canvas automatically expands the relevant edges to multiples of 4; left/top expansion shifts the canvas origin. Dragging keeps a fixed pixel-to-pointer scale, and all three panes update automatically. Spacing inputs follow the smallest nonnegative distance between neighboring padded motif bounds, using repeat padding on axes without neighbors and 0 for overlap. Manual spacing edits clear manual offsets on that axis and request a new layout calculation. The single-motif two-row preset shifts the second row by half a cell and allows independent row movement. Layout changes and motif additions/removals reset positions. Scaled/trimmed motifs receive transparent padding to multiples of 4, without stretching. Uniform cell pitch rounds up to a common multiple of 4 and the shift denominator, adding at most 11 pixels and displaying effective cell spacing. Export extracts the smallest period and repeats complete cycles until both dimensions are multiples of 4, preserving seamless repetition. Entry points and titles use Audio Editor / Video Editor. Main audio playback and the audio editor support mouse-anchored wheel zoom, from the complete timeline to roughly 10 ms major ticks, with a horizontal browsing thumb below the ruler when zoomed. During main-window and Audio Editor playback, 0.1 seconds after zoom input stops, the waveform follows the centered playhead, clamped at the timeline ends; paused playback does not follow. Playback controls stay at the bottom; Stop returns to 0:00, while Pause keeps the current position. Waveforms use 8 kHz decoded peaks capped at four million points per channel; long recordings have reduced detail, and sample-level editing is not supported. Processing runs in the background; gain may clip, caches consume disk space and cleanup is best-effort, with possible leftovers after a crash. Crossfades, batch conversion and unrestricted multitrack editing are not supported.
- **Everyday tools**: Recent files, restored tabs, light / dark themes, seven languages and online updates (automatic startup checks are at least 24 hours apart; manual checks remain available); when GitHub rate limits checks, wait before retrying or open the release page to update manually.

### Current limitations

- Multi-video merging is not implemented. Planned operations include adding multiple videos at once, appending individual videos and reordering before merging.

- PDF editing, text selection, search, thumbnails and password input are not supported. Microsoft / Apple office document preview and editing are not implemented.

- Stretch removes only consecutive identical full RGBA rows or columns; Repeat extracts exact contiguous periods without approximation. Disabling edge preservation trims Alpha-zero margins on selected axes, discarding hidden RGB and changing whitespace; fully transparent images are preserved by default. Alignment retains extra pixels or whole cycles first, then pads each axis by up to 3 transparent pixels if needed: 1 on right/bottom; 2 split evenly; 3 as 1 on left/top and 2 on right/bottom. Padding is excluded from Unity Border; dimensions may grow and actual cycle multiples can differ from input. In-place replacement supports PNG / TGA / BMP / WebP; JPEG and animation require exporting a static PNG. Output is 8-bit RGBA without auxiliary image metadata. Multiple-Sprite sheets and other texture types cannot be replaced in place. No metadata hints or creation without a readable companion. Unity must reimport; select Sliced / Tiled on UI Image manually. Actual mesh count is not guaranteed. Input decoding is limited to 8192 pixels per side and 256 MiB; saved area does not equal compressed file or GPU memory savings.
- Unity binary serialization is unsupported. Unknown types, raw YAML and fileID references remain read-only.
- Scene, Spine and Shader compatibility is partial and does not reproduce Unity rendering completely. URP / HDRP, multiple passes, complex shaders and full lighting remain limited.
- The node interface is for previews; creating nodes, editing connections and generating shaders are unsupported. Helper snapshots require a unique direct stage call with numeric parameters; complex calls are display-only. Unsupported expressions remain source statements.

## 图标资源 / Icon assets

图标生成：安装 Pillow 后运行 `python assets/generate_icons.py`，优先使用 1024 源图，否则使用 512，两者缺失时报错；两次双线性缩放生成 16～256 PNG，覆盖小尺寸图标。

Icon generation: install Pillow and run `python assets/generate_icons.py`. It prefers the 1024 source, falls back to 512, and errors if neither exists. Two bilinear passes regenerate and replace the 16–256 PNG icons.
