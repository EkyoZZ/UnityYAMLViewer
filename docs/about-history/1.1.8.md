# 1.1.8

## zh-CN

- 场景接入有限 Built-in Sprite Shader GPU 预览；URP 与复杂 Shader 暂不支持
- GPU 网格按材质槽绘制，支持同一子网格多材质叠加
- 支持单蒙皮 FBX 静态导入姿态，骨骼覆盖与动画暂未还原
- 修正静态 FBX 轴向及可唯一确认的根骨骼缩放
- 静态模型兼容 PF3D2 材质颜色与透明度，保留多材质槽
- Tilemap 材质接入 GPU，空网格不再误报缺失
- 场景与独立 Spine 接入受限 GPU Shader，特殊效果保留回退
- 场景与 Prefab 支持基础粒子播放、暂停和重播，复杂模块仍有限制
- Prefab 根节点可打开源资源，基础粒子支持有限预热
- 项目索引磁盘缓存优先加载，每次启动后台刷新一次
- 场景点选嵌套 Prefab 自动定位 Hierarchy 节点
- 提高 Prefab 展开预算；GPU 首次渲染后离焦冻结，返回恢复
- 修复夜色参数绑定；预览增加悬浮 FPS 与鼠标位置缩放
- TEXCOORD1/2 输入暂填零，粒子顶点流数据待接入
- 对象名称的 Unicode 转义显示为实际文字
- Prefab 展开限制详情支持一键复制

## en

- Limited Built-in Sprite Shader GPU scene preview; URP and complex shaders are not supported
- GPU meshes render material slots, including multiple materials on one submesh
- Static imported poses for single skinned FBX meshes; bone overrides and animations remain unsupported
- Correct static FBX axes and unambiguous skeleton-root scaling
- Static models support PF3D2 colors and alpha with multiple material slots
- GPU Tilemap materials; empty meshes no longer report missing resources
- Scene and standalone Spine use limited GPU shaders with fallback for special effects
- Scenes and Prefabs support basic particle play, pause and replay; complex modules remain limited
- Prefab roots open source assets; basic particles support bounded prewarm
- Load cached project indexes first and refresh once per launch
- Scene picks of nested Prefabs reveal their Hierarchy nodes
- Higher Prefab budgets; GPU previews freeze off focus after their first render and resume on return
- Fix night color binding; add floating FPS and zoom at the pointer
- TEXCOORD1/2 inputs use zeros; particle vertex stream data remains unsupported
- Decode Unicode escapes in object names for display
- Copy Prefab expansion diagnostics with one click
