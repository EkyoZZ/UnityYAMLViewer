# 1.1.0

## zh-CN

- 属性与表格编辑，显式保存与放弃，修改整行高亮和逐项还原
- 支持已识别的数值、字符串、布尔值、枚举、向量、颜色和渐变关键点编辑
- 支持 Transform / RectTransform、材质字段和列表 / 数组元素编辑
- 每个文件独立撤销记录，默认 200 步，可在设置中调整到 50～1000
- 保存后保留撤销历史，Ctrl+Z 自动进入编辑模式；关闭文件或放弃编辑后清空
- 切换标签保留暂存修改，保存或放弃前阻止关闭编辑中的文件和应用
- 属性类型验证与引用保护；原始 YAML 保持只读
- 保存前检查外部改动，精确写回值片段并保留未修改文本与换行
- 设置弹窗整合关于、主题和撤销步数，记住用户设置

## zh-TW

- 支援已識別的數值、字串、布林、列舉、向量、顏色與漸層編輯
- 支援 Transform / RectTransform、材質欄位與清單 / 陣列編輯
- 每個檔案獨立復原紀錄，預設 200 步，可調至 50～1000
- 儲存後保留復原歷史，Ctrl+Z 進入編輯模式；關閉或放棄後清空
- 切換分頁保留暫存修改，儲存或放棄前阻止關閉
- 屬性類型驗證與引用保護；原始 YAML 維持唯讀
- 儲存前檢查外部變更，僅寫回修改值並保留文字與換行
- 設定整合關於、主題與復原步數，記住使用者設定

## en
