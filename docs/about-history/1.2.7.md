# 1.2.7

## zh-CN

- 新增序列工具：按行列拆分图片，多图排序合并并导出 PNG
- 制作与拆分均支持取色去底、容差遮罩、柔化与去色边，预览和 PNG／GIF／视频源一致
- 制作和拆分序列支持撤销／重做及 Ctrl+Z／Ctrl+Y
- GIF 复用视频编辑转视频，GIF 与视频均可按选区、裁剪、缩放和帧率导出 PNG 序列
- 音视频和 GIF 导出允许覆盖同名文件，编码成功后再替换，失败保留已有文件
- 第三方支持可分别指定 FFmpeg、FFprobe 和 PDFium 路径，优先使用并保存，无需修改 PATH
- 去水印入口暂时关闭，保留实现供后续完善或测试；序列去底色继续可用

## zh-TW

- 新增序列工具：按行列拆分圖片，多圖排序合併並匯出 PNG
- 製作與拆分皆支援取色去底、容差遮罩、柔化與去色邊，預覽和 PNG／GIF／影片來源一致
- 製作和拆分序列支援復原／重做及 Ctrl+Z／Ctrl+Y
- GIF 共用影片編輯轉影片，GIF 與影片皆可按選區、裁剪、縮放和幀率匯出 PNG 序列
- 音影片和 GIF 匯出允許覆蓋同名檔案，編碼成功後再替換，失敗保留現有檔案
- 第三方支援可分別指定 FFmpeg、FFprobe 和 PDFium 路徑，優先使用並儲存，無需修改 PATH
- 去水印入口暫時關閉，保留實作供後續完善或測試；序列去底色繼續可用

## en

- Sequence tool: split grids, reorder images and compose PNG sheets
- Composition and splitting support color picking, tolerance masks, soft edges and decontamination, consistent across previews and PNG/GIF/video sources
- Sequence creation and splitting support undo/redo and Ctrl+Z/Ctrl+Y
- GIF uses video editing for video conversion; GIF and video export PNG sequences with time range, crop, scale and frame rate
- Audio/video and GIF export can replace existing files after encoding succeeds, preserving them on failure
- Third-party settings accept separate saved FFmpeg, FFprobe and PDFium paths without changing PATH
- Watermark removal entry is hidden pending improvements or testing; sequence background removal remains available
