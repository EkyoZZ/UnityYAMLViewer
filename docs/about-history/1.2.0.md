# 1.2.0

## zh-CN

- 材质与 Shader 共用节点预览，分别载入材质输入与 Shader 默认值
- 材质与 Shader 通过统一预览开关打开独立节点面板
- Property 节点内直接编辑，RGBA / XYZW 逐行显示并按上下文展示分量连接
- 交互参考 Amplify Shader Editor，模块内输入与重置，输出模块可切换 2D / 3D 并拉伸
- 预览输入可临时调整与重置，不写回文件；渲染限受支持的 Built-in Shader

## zh-TW

- 材質與 Shader 共用節點預覽，分別載入材質輸入與 Shader 預設值
- 材質與 Shader 透過統一預覽開關開啟獨立節點面板
- Property 節點內直接編輯，RGBA / XYZW 逐行顯示並依上下文顯示分量連線
- 互動參考 Amplify Shader Editor，模組內輸入與重設，輸出模組可切換 2D / 3D 並調整大小
- 預覽輸入可暫時調整與重設，不寫回檔案；算繪限支援的 Built-in Shader

## en

- Shared material and shader node preview using material inputs or shader defaults
- Materials and shaders use the shared preview toggle to open a separate node panel
- Edit inside Property nodes, with RGBA / XYZW rows and contextual component connections
- Amplify-inspired module inputs and reset; resizable output module with 2D / 3D modes
- Temporarily adjust and reset preview inputs without writing files; rendering supports a limited Built-in shader subset

- Property ノード内で編集。RGBA / XYZW を各行に表示し、文脈に応じて成分を接続
- Amplify を参考にモジュール内で入力・リセット。出力は 2D / 3D 切替とサイズ変更に対応
- ファイルを書き換えず入力を一時調整・リセット。描画は対応する Built-in Shader に限定
