# 1.3.0

## zh-CN

- 文本与代码可保存字号及间距；Markdown 支持常见 HTML 排版、图片缓存、链接与代码着色
- Windows RTF 直接只读渲染，支持缩放和复制全文；复杂排版仍有限制
- 图片显示源位深、大小与 DPI；完全不透明 PNG 可去 Alpha，iTXt 可清理并支持会话撤销
- 内置下载器替代 Scoop／WinGet，按需安装 FFmpeg GPL Shared、LibreOffice，保留 PDFium 直接下载
- 组件安装状态与操作同排，提供下载进度、校验与错误地址；托管 FFmpeg 可加入用户 PATH
- 手型仅限制预览选中；修复固定行号分割线，CSV／TSV／PSV 行号从 1 开始
