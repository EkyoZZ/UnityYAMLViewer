# 1.0.0

## zh-CN

首个正式版本。
- 支持 Unity YAML 资源的层级与 Inspector 浏览
- 支持搜索、多标签页、GUID / FileID 复制和编码识别
- 提供动画、材质、动画控制器等常见资源的结构化展示
- 只读浏览资源，不写入原始文件
