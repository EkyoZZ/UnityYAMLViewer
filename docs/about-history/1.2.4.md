# 1.2.4

## zh-CN

- 播放列表菜单可退出编辑，保存成功后自动退出编辑
- CSV / TSV / PSV 支持单元格编辑栏、撤销、检查与查找
- 音频与视频导出结束弹窗提醒，成功显示路径、失败显示原因
- 视频导出可选质量 / 目标码率、帧率及兼容编码的 2 pass，默认单遍
- 视频导出支持多音轨与字幕、语言设置和音频采样率选择
- 播放器支持文字内嵌 / 外挂字幕、字体与独立描边投影样式；字幕可跟随音轨语言，无法匹配时提示手动选择
- 导出补充未压缩、MJPEG、MPEG-4、ProRes、AV1 与 MPEG-2，音频按容器独立选择
- 画面大小支持宽高独立或锁定比例，预览同步变化；GIF 可选颜色数与抖动
- 编码列表按容器兼容性筛选并隐藏不兼容项，新增 H.265 导出
- 视频编辑轴精简为上方帧刻度、中间选区、底部时间；范围操作在预览上方，另存为在右上角
- 视频预览叠加像素裁剪框，可拖动、输入坐标与尺寸；导出支持十种容器和自定义后缀
- 单视频编辑新增预览与底部范围操作，支持 H.264 / VP8 / VP9 导出；批量暂缓

## zh-TW

- 播放清單選單可退出編輯，儲存成功後自動退出編輯
- CSV / TSV / PSV 支援儲存格編輯列、復原、檢查與搜尋
- 音訊與影片匯出結束彈窗提醒，成功顯示路徑、失敗顯示原因
- 影片匯出可選品質 / 目標位元率、影格率及相容編碼的 2 pass，預設單遍
- 影片匯出支援多音軌與字幕、語言設定及音訊取樣率選擇
- 播放器支援文字內嵌 / 外掛字幕、字型與獨立描邊投影樣式；字幕可跟隨音軌語言，無法匹配時提示手動選擇
- 匯出補充未壓縮、MJPEG、MPEG-4、ProRes、AV1 與 MPEG-2，音訊依容器獨立選擇
- 畫面大小支援寬高獨立或鎖定比例，預覽同步變化；GIF 可選色彩數與抖色
- 編碼列表依容器相容性篩選並隱藏不相容項，新增 H.265 匯出
- 影片編輯軸精簡為上方影格刻度、中間選區、底部時間；範圍操作在預覽上方，另存為在右上角
- 影片預覽疊加像素裁剪框，可拖動、輸入座標與尺寸；匯出支援十種容器和自訂副檔名
- 單影片編輯新增預覽與底部範圍操作，支援 H.264 / VP8 / VP9 匯出；批次暫緩

- 内蔵・外部の文字字幕、フォントと独立した縁取り・影に対応。音声言語へ追従、不明時は手動選択を案内

- コンパクトな動画編集軸：上にフレーム、中央に選択範囲、下に時間。範囲操作はプレビュー上、保存は右上
- 動画上の切り抜き枠をドラッグ、座標・サイズをピクセルで指定。10 種の出力コンテナと独自拡張子に対応
- 単一動画のプレビューと下部範囲操作、H.264 / VP8 / VP9 出力に対応。バッチ処理は保留

## ko

- 재생목록 메뉴에서 편집 종료, 저장 성공 후에도 자동 종료
- CSV / TSV / PSV 셀 편집 표시줄, 실행 취소, 검사 및 찾기
- 오디오 / 동영상 출력 완료 팝업에 저장 경로 또는 실패 원인 표시
- 동영상 출력에 품질 / 목표 비트레이트, 프레임 레이트 및 지원 코덱의 2패스 제공. 기본은 1패스
- 동영상 출력에 다중 오디오 / 자막, 언어 설정 및 오디오 샘플 레이트 선택 지원
- 내장 / 외부 텍스트 자막, 글꼴 및 독립 윤곽선 / 그림자 지원. 오디오 언어에 맞춰 선택하며 불일치 시 수동 선택 안내
- 비압축, MJPEG, MPEG-4, ProRes, AV1, MPEG-2 출력 및 컨테이너별 오디오 선택 추가
- 화면 크기 개별 / 비율 잠금 조절을 미리보기에 반영. GIF 색상 수 및 디더링 선택
- 컨테이너와 호환되는 코덱만 표시하며 H.265 출력 추가
- 간결한 동영상 타임라인: 위쪽 프레임, 가운데 선택 영역, 아래쪽 시간. 구간 제어는 미리보기 위, 저장은 오른쪽 위
- 영상 자르기 오버레이 드래그 및 픽셀 좌표 / 크기 입력, 컨테이너 10종과 사용자 확장자 지원
- 단일 동영상 미리보기 및 하단 구간 제어, H.264 / VP8 / VP9 출력 지원. 일괄 처리는 보류
