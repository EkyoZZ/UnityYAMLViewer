# 1.3.2

## zh-CN

- 新增 pngopt 指令，批量优化 PNG 并输出逐文件结果。指令用法随界面语言切换。
- RTF 支持独立窗口编辑、插入静态图片和另存为，保存当前文档后自动刷新预览。
- 打开 URL 支持 HLS 点播，页签可显示链接或媒体内嵌标题。
- HLS 点播可下载为 MP4，遇到个别损坏数据包时可继续。
- HLS 导出 MP4 时可修正倒退的时间戳。
- 常见 HLS 点播在暂停时继续缓存，齐全后可本地播放和保存 MP4。
- 音视频可用方向键跳转和调整音量。
- 网页视频可选清晰度和音轨，下载可取消，并可定位已保存文件。
- 第三方支持可按需安装 yt-dlp，并手动检查更新。
- 减少窗口重绘时重复更新图标和位置。重绘时复用 Markdown 预处理结果。
