# 1.3.4

## zh-CN

- Windows 支持由独立油猴脚本嗅探 HLS 并唤起软件播放。
- 第三方支持提供油猴助手安装引导与脚本页面入口。
- 打开 URL 可查找网页源码中的 HLS，多个结果可逐项选择播放。
- 播放页缓存进度使用紧凑文字显示，并可取消。
- 粘贴链接时还原 Unicode 转义，保留百分号编码。
- 打开 URL 无法识别文件时尝试提取视频，成功后自动播放。
- 方向键调音量时显示居中百分比提示，松键后 0.2 秒消失。
- 视频直链和网页提取共用播放页，可选清晰度及不同编码、码率的音轨。
- 播放页可定位本地缓存，完成的缓存任务也可定位文件。
- 网页视频播放携带提取到的会话信息，并优先复用已下载文件。

## zh-TW

- Windows 支援由獨立油猴腳本偵測 HLS 並喚起軟體播放。
- 第三方支援提供油猴助手安裝引導與腳本頁面入口。
- 開啟 URL 可尋找網頁原始碼中的 HLS，多個結果可逐項選擇播放。
- 播放頁快取進度使用精簡文字顯示，並可取消。
- 貼上連結時還原 Unicode 跳脫，保留百分號編碼。
- 開啟 URL 無法辨識檔案時嘗試擷取影片，成功後自動播放。
- 方向鍵調整音量時顯示置中百分比提示，放開後 0.2 秒消失。
- 影片直連和網頁擷取共用播放頁，可選畫質及不同編碼、位元率的音軌。
- 播放頁可定位本機快取，已完成的快取工作也可定位檔案。
- 網頁影片播放攜帶擷取到的工作階段資訊，並優先重用已下載檔案。

## en

- On Windows, a separate userscript detects HLS and launches the app for playback.
- Third-party Support provides userscript installation guidance and a link to the script page.
- Open URL finds HLS in page source and lets you choose among multiple results.
- The player shows compact text cache progress with cancellation.
- Pasted links decode Unicode escapes while preserving percent encoding.
- Open URL tries video extraction when file loading fails and starts playback on success.
- Arrow-key volume adjustments show a centered percentage hint that disappears 0.2 seconds after release.
- Direct links and extracted web videos share a player with quality and audio codec/bitrate options.
- Reveal local cache files from the player or completed cache tasks.
- Web video playback passes extracted session information and prefers downloaded files.

## ja

- Windowsでは独立したユーザースクリプトでHLSを検出し、アプリを起動して再生できます。
- サードパーティサポートにスクリプトのインストール案内とページへのリンクを追加。
- URLを開くとページソース内のHLSを検出し、複数の結果から再生する項目を選べます。
- 再生ページのキャッシュ進行状況を簡潔なテキストで表示し、キャンセルできます。
- リンク貼り付け時にUnicodeエスケープを復元し、パーセントエンコードを保持します。
- URLでファイルを開けない場合は動画抽出を試み、成功すると自動再生します。
- 矢印キーで音量を調整すると中央に割合を表示し、キーを離して0.2秒後に消えます。
- 動画の直リンクと抽出した動画は同じプレーヤーで再生し、画質や音声のコーデック・ビットレートを選べます。
- 再生ページや完了したキャッシュ処理からローカルキャッシュの場所を開けます。
- ウェブ動画の再生に抽出したセッション情報を渡し、ダウンロード済みファイルを優先します。

## ko

- Windows에서 별도 사용자 스크립트로 HLS를 감지하고 앱을 실행해 재생할 수 있습니다.
- 타사 지원에서 스크립트 설치 안내와 페이지 링크를 제공합니다.
- URL 열기에서 페이지 소스의 HLS를 찾고 여러 결과 중 재생할 항목을 선택할 수 있습니다.
- 재생 페이지에서 캐시 진행률을 간결한 텍스트로 표시하며 취소할 수 있습니다.
- 링크를 붙여 넣을 때 Unicode 이스케이프를 변환하고 퍼센트 인코딩은 유지합니다.
- URL 열기에서 파일을 열지 못하면 동영상 추출을 시도하고 성공 시 자동 재생합니다.
- 방향키로 음량을 조절하면 중앙에 백분율이 표시되고 키를 놓은 후 0.2초 뒤 사라집니다.
- 직접 링크와 추출한 웹 동영상은 같은 플레이어에서 화질 및 오디오 코덱·비트레이트를 선택할 수 있습니다.
- 재생 페이지나 완료된 캐시 작업에서 로컬 캐시 파일 위치를 열 수 있습니다.
- 웹 동영상 재생 시 추출한 세션 정보를 전달하고 다운로드한 파일을 우선 사용합니다.

## de

- Unter Windows erkennt ein separates Userscript HLS und startet die App zur Wiedergabe.
- Drittanbieter-Unterstützung bietet eine Installationsanleitung und einen Link zur Userscript-Seite.
- URL öffnen findet HLS im Seitenquelltext und bietet mehrere Ergebnisse zur Auswahl.
- Der Player zeigt den Cachefortschritt kompakt als Text mit Abbruchmöglichkeit.
- Eingefügte Links dekodieren Unicode-Escapes und behalten die Prozentkodierung bei.
- URL öffnen versucht bei Ladefehlern eine Videoextraktion und startet bei Erfolg die Wiedergabe.
- Die Lautstärkeanzeige erscheint mittig bei Pfeiltastenbedienung und verschwindet 0,2 Sekunden nach dem Loslassen.
- Direkte Links und extrahierte Webvideos nutzen denselben Player mit Auswahl für Qualität, Audiocodec und Bitrate.
- Lokale Cachedateien lassen sich im Player oder über abgeschlossene Cacheaufgaben finden.
- Webvideos werden mit extrahierten Sitzungsinformationen abgespielt; heruntergeladene Dateien werden bevorzugt.

## fr

- Sous Windows, un script utilisateur distinct détecte les flux HLS et lance l’application pour les lire.
- Le support tiers propose un guide d’installation et un lien vers la page du script utilisateur.
- Ouvrir une URL recherche les flux HLS dans le code source et permet de choisir parmi les résultats.
- Le lecteur affiche la progression du cache sous forme de texte compact et permet son annulation.
- Les liens collés décodent les échappements Unicode et conservent l’encodage en pourcentage.
- Ouvrir une URL tente une extraction vidéo si le chargement échoue et lance la lecture en cas de succès.
- Le réglage du volume par les flèches affiche un pourcentage centré, qui disparaît 0,2 seconde après le relâchement.
- Les liens directs et les vidéos extraites partagent un lecteur avec choix de qualité, de codec audio et de débit.
- Retrouvez les fichiers en cache depuis le lecteur ou les tâches terminées.
- La lecture des vidéos web transmet les informations de session extraites et privilégie les fichiers téléchargés.
