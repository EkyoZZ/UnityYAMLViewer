## zh-CN

- 第三方支持集中管理 FFmpeg、PDFium 和 LibreOffice，组件不参与缓存清理

- 页签、堆叠文件项及预览文件名支持右键定位文件和复制地址
- GIF 进度显示时间、帧号与每帧秒数，固定使用 f 和 s/f
- PDF 过渡菜单提供无、淡入淡出、左右滑动、推页、擦除和缩放淡入
- PDF 翻页保留上一页直到新页就绪，加载超过 1 秒才显示转圈
- 多页 PDF 支持定时与循环翻页，单页隐藏相关设置
- PDF 修正 DPI 与像素对齐、文字抗锯齿，消除重载按钮渲染闪烁
- PDF 支持黑底全屏查看，F11 切换、Esc 退出
- PDF 底部悬浮显示页码与缩放，圆形矢量按钮及方向键翻页
- 第三方组件标题按深浅主题使用蓝色，便于识别分区
- FFmpeg / PDFium 安装后检测及重新检测完成时同步预览状态
- 新增 PDFium 多页只读预览，支持翻页、缩放与拖动；暂不支持编辑
- SVG 支持棋盘格 / 灰色 / 自定义预览背景，隐藏通道与九宫格入口
- GIF 隐藏音量与音轨界面，显示全局及局部调色板的最大容量
- GIF 复用视频控件，支持文件循环设置与自定义次数，时间轴显示帧数及逐帧时长
- 新增 SVG 只读缩放预览与 FFmpeg GIF 播放，禁用九宫格与编辑操作
- 逐项关闭至 3 个时在原位展开；关闭全部期间保持成组，取消后恢复自动展开
- 页签支持整组拖拽与文件堆叠数量，修复选中或悬停时页签栏高度变化
- 相同后缀超过 3 个文件自动折叠为下拉页签，支持逐项关闭、关闭全部与未保存提醒
- 淡入淡出支持预设及贝塞尔手柄，淡入起点 / 淡出终点幅度可调，参数窗置顶
- 选择模式旁显示区间时长，区间模式另显示剪切后时长；停止播放回到零点
- 主窗口与音频编辑支持波形缩放、水平浏览与播放居中跟随
- 剪切窗独立播放，打开即停止来源页签；支持多文件弹窗，切换或关闭页签仍保留
- 音频统一左右键选区，剪切 / 淡入淡出 / dB 可按区间处理；未选范围的 dB 作用于当前整段
- 音视频剪切：视频另存 MP4，音频可选 MP3 / WAV / FLAC / M4A 及适用参数；需 FFmpeg

- モード横に選択区間の長さ、区間モードでは切り取り後の長さも表示。停止で先頭に戻る
- メイン画面と音声編集で波形の拡大縮小、横スクロール、再生位置の中央追従に対応
- 独立したトリミング再生。開くと元タブを停止し、複数ファイルのウィンドウはタブ切替・終了後も保持
