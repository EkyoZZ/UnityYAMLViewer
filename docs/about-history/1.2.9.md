# 1.2.9

## zh-CN

- XLS／XLSX／ODS 固定行列编号；冻结表头开启时优先沿用可读的 XLSX 设置，否则固定首行；修复冻结区域分割线与滚动内容遮挡
- 办公文档新增“在LibreOffice编辑”，直接打开原文件；保存后可重载预览
- 第三方支持新增 WinGet／Scoop 主题 Tab，Scoop 独立按需安装并显示同行状态
- LibreOffice 防止重复安装，已确认的下载阶段可取消并重试，安装中或状态不明时保留任务
- Word／演示文档支持只读分页预览，依赖 LibreOffice 与 PDFium；电子表格使用独立数据视图
- 转换为 PDF 预览的办公文档支持另存完整 PDF，复用预览结果
- 启动自动更新关联名称与独立文件图标，默认打开程序仍由用户选择
- 多图切换保留旧画面，预加载相邻图片并限制额外缓存预算
- 电子表格支持多工作表底栏、查找复制、公式／缓存结果及可选必填检查，不重算公式

## zh-TW

- XLS／XLSX／ODS 固定列欄編號；凍結表頭開啟時優先沿用可讀取的 XLSX 設定，否則固定首列；修正凍結區域分隔線與捲動內容遮擋
- 辦公文件新增「在LibreOffice編輯」，直接開啟原檔；儲存後可重新載入預覽
- 第三方支援新增 WinGet／Scoop 主題 Tab，Scoop 獨立按需安裝並顯示同列狀態
- LibreOffice 防止重複安裝，已確認的下載階段可取消並重試，安裝中或狀態不明時保留工作
- Word／簡報文件支援唯讀分頁預覽，依賴 LibreOffice 與 PDFium；試算表使用獨立資料檢視
- 轉為 PDF 預覽的辦公文件可另存完整 PDF，重用預覽結果
- 啟動自動更新關聯名稱與獨立檔案圖示，預設開啟程式仍由使用者選擇
- 多圖切換保留舊畫面，預載相鄰圖片並限制額外快取預算
- 試算表支援多工作表底欄、尋找複製、公式／快取結果與選用必填檢查，不重算公式

## en

- XLS/XLSX/ODS keep row/column coordinates fixed; Freeze header uses readable XLSX panes, otherwise the first data row; fix frozen-region separators and scrolling-content clipping
- Office documents add “Edit in LibreOffice” to open originals directly; reload previews after saving
- Third-party Support adds themed WinGet/Scoop tabs; Scoop installs separately on demand with status on the same row
- LibreOffice prevents duplicate installs; confirmed downloads can be cancelled and retried, while installing or unknown tasks are preserved
- Word/presentation documents use read-only page previews via LibreOffice and PDFium; spreadsheets use a separate data view
- Office documents converted for preview can save the complete PDF using the preview result
- Startup updates the app name and separate file icon registration; users choose defaults
- Image switching keeps the previous image, preloads neighbors and limits the extra cache budget
- Spreadsheets offer worksheet tabs, search/copy, formulas/cached results and optional required-cell checks; no recalculation

## ja

- XLS／XLSX／ODS の行列番号を固定。見出し固定は読み取り可能な XLSX 設定を優先し、なければデータ先頭行を固定。固定領域の区切り線とスクロール内容のクリップを修正
- Office 文書に「LibreOffice で編集」を追加。元のファイルを直接開き、保存後にプレビューを再読み込み可能
- サードパーティサポートに WinGet／Scoop のテーマ付きタブを追加。Scoop は必要時に別途インストールし、同じ行に状態を表示
- LibreOffice の重複インストールを防止。確認済みのダウンロードはキャンセルして再試行でき、インストール中や状態不明の処理は継続
- Word／プレゼン文書は LibreOffice と PDFium でページプレビュー。表計算は専用データ表示
- PDF に変換してプレビューする文書は、変換結果を利用して PDF 全体を保存可能
- 起動時に関連付けの名前と専用ファイルアイコンを更新、既定のアプリはユーザーが選択
- 画像切替中は前の画像を維持し、隣接画像を先読みして追加キャッシュを制限
- 表計算はシートタブ、検索・コピー、数式・キャッシュ結果、任意の必須入力検査に対応。再計算なし

## ko

- XLS/XLSX/ODS 행/열 번호 고정. 머리글 고정 시 읽을 수 있는 XLSX 설정을 우선하며 없으면 첫 데이터 행 고정; 고정 영역 구분선 및 스크롤 내용 잘림 수정
- Office 문서에 LibreOffice에서 편집 추가. 원본을 직접 열고 저장 후 미리보기 다시 로드 가능
- 타사 지원에 테마와 일치하는 WinGet/Scoop 탭 추가. Scoop은 필요 시 별도 설치하며 같은 행에 상태 표시
- LibreOffice 중복 설치 방지. 확인된 다운로드는 취소 후 재시도 가능하며 설치 중이거나 상태가 불명확하면 작업 유지
- Word/프레젠테이션은 LibreOffice와 PDFium으로 읽기 전용 페이지 미리보기, 스프레드시트는 별도 데이터 보기
- PDF로 변환해 미리 보는 문서는 변환 결과로 전체 PDF 저장 가능
- 시작 시 앱 이름과 별도 파일 아이콘 등록 업데이트, 기본 앱은 사용자가 선택
- 이미지 전환 시 이전 화면 유지, 인접 이미지 미리 로드 및 추가 캐시 제한
- 스프레드시트 시트 탭, 검색/복사, 수식/캐시 결과, 선택적 필수 값 검사 지원. 수식 재계산 없음
