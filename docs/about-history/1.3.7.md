## en

- Canvas options move into collapsible Settings; Show Slots and left-hand selection share row-major numbers without changing exports. Selected Slots highlight in the view. Sidebar headings share one size; materials can collapse and a 1×1 preset hides single-cell Slot controls.

- The toolbar can be dragged within the canvas, remembers its last position and stays within resized bounds.

- Add layered Pixel Tile editing with rectangular, diamond, pointy/flat hexagonal and raised previews, drawing, wrapping, connected-color filling, projects and per-cell PNG export.
- Single- and multi-cell projects keep BaseLayer and a thumbnail material library with imports, external drops, composite capture and context-menu removal. Pinned BaseLayer holds cell materials beneath independent drawing layers; the library travels with the project. Native-window drop coordinates and visible import results are corrected.
- Drawing and repeat previews share one view: Q bounded, W unbounded, H center without changing zoom; V move, Z zoom and layer controls remain available. View switching uses joined tabs matching the theme controls. Improve vertical alignment of the top controls.
- Fix centered vector recording countdowns, red outlines after the first frame and green mouse-transparent outlines after stopping. Editing gains embedded/external audio waveforms, audition, independent subtitles and saved preview selections.
- Fix bright transparent edges in smooth image previews. Add a standalone Photoshop plugin and installer for grids, slicing, layer binding and wrapping; soft-brush seams and undo interactions remain limited.
- PS plugin discovery is manual, with verified downloads, installer launch, file location and collapsed diagnostics. Versions are independent, with no automatic checks; new UI behavior still needs runtime verification. Downloading and launching the installer from the main app has passed user verification.
