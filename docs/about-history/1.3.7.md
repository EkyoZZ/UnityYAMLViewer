# 1.3.7

## zh-CN

- 像素 Tile 新增 PS 插件手动更新查询与安装引导；主程序与插件版本独立，无自动查询。

- 新增分层像素 Tile 编辑、多格菱形回绕、逐格 PNG 导出及独立循环预览。
- 新增独立 Photoshop Tile 插件和安装器，支持网格预览、切片、图层绑定与自动回落；插件保持 0.1.0 测试版，软笔接缝和撤销交互仍有限制。
- 修正录屏倒计时，增加录制红框与停止后鼠标穿透；编辑器支持外部音轨波形、切换试听及独立字幕预览。
- 修正图片平滑预览透明亮边；新版本界面及 PS 实际效果仍待运行验证。

## zh-TW

- 像素 Tile 新增 PS 外掛手動更新查詢與安裝引導；主程式與外掛版本獨立，不自動查詢。

- 修正圖片平滑預覽透明亮邊；新版介面與 PS 實際效果仍待執行驗證。

## en

- Pixel Tile adds manual PS plugin update checks and installation guidance, with independent versions and no automatic checks.

- Add layered Pixel Tile editing, multi-cell diamond wrapping, per-cell PNG export and detached repeating previews.
- Add a standalone Photoshop Tile plugin and installer with grid previews, slicing, layer binding and automatic wrapping. Plugin remains at test version 0.1.0; soft-brush seams and undo interactions remain limited.
- Fix recording countdowns, add a red recording outline and mouse passthrough after stopping. Editing supports external audio waveforms, track audition and independent subtitle previews.
- Fix bright transparent edges in smooth image previews. New-version UI and actual Photoshop behavior still need runtime verification.
