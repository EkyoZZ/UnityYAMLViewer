## zh-CN

- 矩形支持内部填充，清空／删除图层增加确认，启用样式的对象显示fx标记。

- 图层组支持拖入／拖出及组内顶层新增；眼睛固定在前，文件夹与箭头区分展开／收起。 组右键使用组专用文字，组与调整层隐藏剪切新层。 收紧行内间隔，普通图层不预留组箭头空位。 父组隐藏时眼睛灰显，继承锁采用BaseLayer禁用样式，保留自身状态。

- 绘Tile支持矩形、菱形、六边形的分层绘制、独立素材库、单格／多格与子组回绕、工程预览和逐格导出；高度工程暂只读。

- 铅笔保持像素硬边，画笔支持抗锯齿、软硬度、流量、间距与8种预设；Windows Ink压力支持大小／不透明度／流量，Wacom压力大小已有用户验证。 外侧笔尖同步显示软硬度。

- 四种选区支持增减、持续剪切移动及选区内复制／剪切新层，撤销恢复选区；BaseLayer受保护。 多边形首点即预览连线，起点圆圈提示闭合；套索保持原样。 选区栏提供颜色／不透明度，Alt+Enter填充并保留选区，支持撤销。

- 图层支持嵌套组、多选链接、独立锁定、混合与像素／剪贴蒙版、基础样式和四类调整；曲线可编辑贝塞尔控制点与手柄。效果按格裁切，非完整PS功能。 调整箭头与fx点击选中对象并展开参数框，再点或切层收起。 亮度／对比度新增同步滑条，范围分别为-150～150／-50～100。 色阶新增输入直方图与输入／输出滑块，色相／饱和度／明度增加彩色滑条。 参数框统一曲线绘图区宽度，标题简化，高度随内容收缩。

- 移动支持按实际选择移动和自动选层／组；图标与内容／蒙版目标高亮统一，工具选项随工具切换，浮动工具栏支持横竖及边缘约束。 工具选项栏统一高度，切换时画布不再上下跳动。 缩放工具增加常用比例下拉，与顶栏倍率实时同步。

- 工程预览静默限频更新，放弃修改恢复已保存内容，打开工程前提示未保存修改；绘Tile背景独立使用棋盘格／自定义Tab。新图层交互仍待运行验证。

- 图片预览共用缩放模式、采样和通道选择，默认适应窗口只在启动时初始化；修正透明边缘亮边。

- 录屏修正中央矢量倒计时，首帧后显示红框，停止后恢复绿框并保持鼠标穿透。视频编辑增加内嵌／外部音轨波形与试听、独立字幕预览及工程预览状态保存。

- 修正图片平滑预览的透明亮边。新增独立 PS 插件与安装器，提供网格、切片、图层绑定和回落；软笔接缝及撤销交互仍有限制。

- PS 插件支持手动版本检查、校验下载、打开安装器与定位文件，并提供折叠下载诊断。插件与主程序独立版本，无自动查询；新功能实际界面仍待验证。 用户已实测主程序下载并启动安装器成功。

## en

- Rectangles support interior fills; layer clear/delete actions require confirmation, and styled objects show fx.

- Groups support drag-in/out and top-of-group insertion; eye icons stay aligned and folders/arrows show expansion state. Group menus use group labels; groups and adjustments hide cut-to-layer. Rows are more compact; ordinary layers no longer reserve empty disclosure space. Parent hiding grays child eyes; inherited locks use BaseLayer’s disabled style and preserve individual states.

- Tile Painter supports layered rectangular, diamond and hexagonal drawing, a project material library, cell/subgroup wrapping, project previews and per-cell export. Raised projects remain read-only.

- Pixel-hard pencils and antialiased brushes include hardness, flow, spacing and eight presets. Windows Ink controls size, opacity and flow; Wacom pressure size has user verification. The compact tip also reflects hardness.

- Four selection modes support add/subtract, persistent cut-move, copy/cut to layers and selection-aware undo. BaseLayer stays protected. Polygons preview from the first point and show a closure ring; lasso behavior is unchanged. Selection options include color/opacity and Alt+Enter fill with selection-preserving undo.

- Layers include nested groups, multiple selection, links, separate locks, blending, pixel/clipping masks, basic styles and four adjustments. Curves have editable Bezier anchors/handles. Effects are clipped per cell; this is not full PS compatibility. Adjustment arrows and fx select their objects and toggle parameter panels, which close on layer changes. Brightness/Contrast adds synchronized sliders with ranges −150…150 and −50…100. Levels adds an input histogram and input/output handles; hue, saturation and lightness gain colored sliders. Parameter panels share the curve width, shorter titles and content-sized heights.

- Move uses selected objects or automatic layer/group picking. Icons and content/mask target borders are unified; contextual options and horizontal/vertical toolbars stay within canvas edges. Tool options use a uniform height to keep the canvas from shifting during tool changes. Zoom presets now share the live percentage shown in the top bar.

- Project previews refresh silently at a limited rate. Discard reloads saved contents; opening with unsaved changes requires confirmation. Tile backgrounds use independent Checkerboard/Custom tabs. New layer interactions still need runtime verification.

- Image previews share zoom mode, sampling and channels; default fit initializes only at startup. Transparent-edge halos are corrected.

- Fix centered vector recording countdowns, red outlines after the first frame and green mouse-transparent outlines after stopping. Editing gains embedded/external audio waveforms, audition, independent subtitles and saved preview selections.

- Fix bright transparent edges in smooth image previews. Add a standalone Photoshop plugin and installer for grids, slicing, layer binding and wrapping; soft-brush seams and undo interactions remain limited.

- PS plugin discovery is manual, with verified downloads, installer launch, file location and collapsed diagnostics. Versions are independent, with no automatic checks; new UI behavior still needs runtime verification. Downloading and launching the installer from the main app has passed user verification.

- 사각형 내부 채우기, 레이어 비우기/삭제 확인, 스타일 사용 객체의 fx 표시를 추가했습니다.

- 그룹으로 드래그해 넣거나 빼고 맨 위에 새 레이어를 추가할 수 있습니다. 눈 아이콘을 고정하고 폴더와 화살표로 펼침 상태를 구분합니다. 그룹 메뉴는 그룹 명칭을 쓰고 그룹과 조정 레이어에서 새 레이어로 잘라내기를 숨깁니다. 행 간격을 줄이고 일반 레이어의 빈 펼침 열을 제거했습니다. 부모 숨김은 눈을 회색 표시하고 상속 잠금은 BaseLayer처럼 비활성화하며 개별 상태는 유지합니다.
