# 1.2.8

## zh-CN

- 新增目录浏览：多个根目录、按需展开、独立忽略规则，目录与规则自动保存
- 目录预览固定首位并显示根目录名，修改后保留普通页签，同目录切图复用缓存
- 新增多图浏览：固定底部缩略图、方向键切图、位置计数与透明棋盘背景
- 图片默认多图与适应窗口可设置，补充 ICO 与受限 PSD 只读预览
- 优化缩放比例菜单、图片边界与目录滚动布局
- Spine 默认动态播放，普通预览默认预乘 Alpha，修复路径并优化工具栏与提示

## zh-TW

- 新增目錄瀏覽：多個根目錄、按需展開、獨立忽略規則，目錄與規則自動儲存
- 目錄預覽固定首位並顯示根目錄名，修改後保留一般頁籤，同目錄切圖重用快取
- 新增多圖瀏覽：固定底部縮圖、方向鍵切圖、位置計數與透明棋盤背景
- 圖片預設多圖與符合視窗可設定，補充 ICO 與受限 PSD 唯讀預覽
- 最佳化縮放比例選單、圖片邊界與目錄捲動配置
- Spine 預設動態播放，一般預覽預設預乘 Alpha，修正路徑並最佳化工具列與提示

## en

- New folder browsing: multiple roots, on-demand expansion, independent ignore rules and automatic saving
- Folder preview stays first with the root name; modified files become regular tabs and same-folder image switches reuse caches
- New image browsing: fixed bottom thumbnails, arrow-key navigation, position counters and checkerboards for transparency
- Configurable default image browsing and fit-to-window; read-only ICO and limited PSD previews
- Improved zoom menus, image edges and folder scrolling layout
- Spine animates by default with premultiplied alpha in ordinary preview; path fixes and clearer controls and notices

## ja

- フォルダー表示を追加：複数ルート、必要時の展開、個別の除外規則と自動保存
- ルート名のプレビューを先頭に固定。変更したファイルは通常タブに保持し、同じフォルダーの画像切替はキャッシュを再利用
- 複数画像表示を追加：下部固定サムネイル、矢印キー切替、位置表示と透明部分の市松模様
- 複数画像表示とウィンドウ合わせの既定を設定可能。ICO と制限付き PSD の読み取り専用表示を追加
- 拡大率メニュー、画像の境界とフォルダーのスクロール配置を改善
- Spine は既定でアニメーション再生、通常表示は乗算済み Alpha。パスを修正し操作部と通知を改善

## ko

- 폴더 탐색 추가: 여러 루트, 필요 시 펼치기, 개별 숨김 규칙 및 자동 저장
- 루트 이름의 폴더 미리보기를 첫 탭에 고정; 수정 파일은 일반 탭으로 유지하고 같은 폴더 이미지 캐시 재사용
- 다중 이미지 탐색 추가: 하단 고정 썸네일, 방향키 전환, 위치 표시 및 투명 체크무늬 배경
- 기본 다중 이미지 및 창 맞춤 설정 지원; ICO와 제한된 PSD 읽기 전용 미리보기 추가
- 확대 비율 메뉴, 이미지 가장자리 및 폴더 스크롤 배치 개선
- Spine 기본 동적 재생 및 일반 미리보기 프리멀티플라이드 알파; 경로 수정과 도구 모음 및 안내 개선

## de

- Neue Ordneransicht: mehrere Stammordner, Aufklappen nach Bedarf, eigene Filter und automatisches Speichern
- Ordnervorschau steht mit Stammnamen zuerst; geänderte Dateien bleiben normale Tabs, Bildwechsel im selben Ordner nutzt Caches
- Neue Bildübersicht: feste Miniaturen unten, Pfeiltasten, Positionsanzeige und Schachbrett für Transparenz
- Bildübersicht und Fensteranpassung als Standard einstellbar; schreibgeschützte ICO- und eingeschränkte PSD-Vorschau
- Verbesserte Zoommenüs, Bildkanten und Ordner-Scrollanordnung
- Spine startet animiert mit vormultipliziertem Alpha in normaler Vorschau; Pfadkorrekturen und klarere Bedienelemente und Hinweise
