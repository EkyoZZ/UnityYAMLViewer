# v0.1.0

Photoshop 等距 Tile 插件首版，独立于 UnityYAMLViewer 主程序安装和更新。

## 支持能力

- 单 Tile 重复、多文档 Slot 和单文档菱形网格预览，支持错位排列与子组循环。
- 新建网格文档、在大画布中心定位 Tile、扩展网格并逐格导出透明 PNG。
- 绑定多个绘画图层，支持手动及收笔后自动回落、周期边界同步和子组联动。
- 独立设置与预览面板，支持缩放、背景颜色、网格／编号显示及会话内设置记忆。
- 独立 Windows x64 安装器，支持安装／更新和卸载；更新不需要先卸载。

## 安装

需要 Windows x64、Photoshop 24.4.0 或更高版本。

1. 下载 PS-Tile-Installer-v0.1.0-windows-x64.exe。
2. 关闭 Photoshop，运行安装器并点击“安装／更新”。
3. 重新启动 Photoshop，从“增效工具 → Isometric Tile Preview”打开“Tile 设置”或“Tile 预览”。

安装器只部署到当前用户的 UXP External 目录，不申请管理员权限。部署成功不等于 Photoshop 已加载；不同 PS 版本的加载支持受宿主影响。卸载时关闭 PS，再运行安装器选择“卸载插件”。

## 已知限制

- 软笔在已有不透明内容上叠画仍可能出现接缝。遇到问题可撤销该笔，在新建透明图层绑定绘制，确认后再合并；不保证所有原生笔刷效果精确跨边同步。
- 自动回落仅适用于符合条件的 RGB 8 位普通像素层，不支持组、智能对象、蒙版和效果等复杂图层；不支持对边橡皮同步及恢复画布外未记录笔迹。
- 为排除辅助网格，预览读取使用临时显隐及历史恢复；撤销／重做可能回到网格隐藏状态，可手动重新显示。
- 路径网格创建试验已撤回；已有路径文档可读取，但不能扩展。
- 绑定与部分设置只在插件会话内保留。预览针对收笔后刷新，不保证持续落笔期间实时刷新。

## 验证范围

安装器及内嵌文件已进行版本、大小和 SHA-256 核验，插件 Node 模拟回归检查通过。已有 PS 实测反馈仍包含上述限制，不代表所有宿主环境及笔刷全面验证通过。
